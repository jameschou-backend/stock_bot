# 課程衍生動能組合研究

本研究將愛德恩課程中可用日資料表達的多方條件組成一個候選聯集，自訂動能公式、進出場與資金規則。這不是作者專有公式的逆推，也不是上漲機率模型。使用者已選定日線多方波段範圍；當沖、放空與無歷史證據的主觀題材判讀不在本版。

## 原則與來源

課程整理來源為使用者授權保存的 `/Users/james.chou/Downloads/愛德恩課程整理_20261028/選股規則.json`，原講義、字幕仍在同資料夾。下表提供單元與講義頁碼以便回查；報告不附整套課程檔案。

[CMoney 課程說明](https://www.cmoney.tw/learn/course/edwintsai/topic/3692) 提及成交金額、漲跌幅、乖離率與相對強弱；未取得確切權重、期間與轉換方式。故動能參數是研究假設，不能將本研究的 80 分等同作者的 7.5。

| 篩選器 | 單元 / 講義頁 | 本版定義與改編 |
|---|---|---|
| 量大動能 | 585 / 3 | M ≥ θ |
| 投信剛買準突破 | 586 / 3 | 距前 40 日最高價 ±2%，近 3 日任一日投信買超 |
| 投信動能連買 | 587 / 3 | M ≥ θ，投信連續 2 日買超 |
| 外資剛大買 | 588 / 3 | M ≥ θ，外資當日買超且前日未買超 |
| 外資投信同買 | 589 / 4 | M ≥ θ−10，外資估計買超金額 ≥5,000 萬、投信 ≥2,000 萬 |
| 價量創新高 | 600 / 3 | 收盤突破前 400 日最高價，量不低於前 9 日最大值；由當沖篩選改編日線 |
| 突破邊緣 | 609 / 3 | 距前 40 日最高價 ±2%，沒有法人買超要求 |

「前」表示不含當日。法人金額以淨買股數 × 當日原始收盤價估算。近 3 日買超不是連買 3 天。等號、窗口、權重、θ−10、盤中改收盤皆有明確研究定義，未宣稱等同作者原始實作。

七項取聯集，沒有「同時符合越多就按次數加分」的機制。部分條件互為子集合，不能將七次上榜視為七份獨立證據。候選是否實際上漲仍需另做機率校準，本版僅比較持倉帳戶結果。

## 動能與共同限制

先在當日資料完整、歷史身分可用且前一交易日**實際成交金額**大於 5 億元的股票中，計算三項橫斷面百分位（同分用平均名次）：

1. 20 交易日還原報酬。
2. 還原收盤價 / MA20 − 1。
3. 當日成交金額 / 前 20 日平均成交金額。

M 是三項百分位的加權平均。24 組固定搜尋：權重 40/40/20、60/20/20、30/30/40；θ 為 70 或 80；出場 MA5 或 MA10；進場只有突破或突破加回檔。定義記於 `docs/prereg_course_bundle_20261028.json`，輸入封存含規格雜湊，研究程式拒絕封存後改規格。

所有候選須 20 日報酬為正、收盤站上 MA20，並有完整的必要價格、量及近 3 日外資／投信資料。缺法人資料不補零。0050 僅作市場代理與比較：收盤高於 MA5 且 MACD(12,26,9)柱狀值增加時才產生新進場訊號。這不等同原課程對加權與櫃買兩市場的人工判讀。

排序 = 0.7 × M + 投信當日買超 10 分 + 外資當日買超 10 分 + 當日量 ≥ 前 20 日均量 × 1.2 的 10 分。股票同分依代號排序；前後期一律相同。

## 進場與風控

突破：收盤突破前 40 日最高價、收紅 K、成交量至少前 20 日均量的 1.2 倍。

回檔：最低價碰到 MA10 的 1.02 倍以下、收盤位於 MA10～1.03 倍 MA10、收紅 K、收盤比前日高且 MACD 柱狀值增加。只在選定「兩種進場」的參數中啟用。

收盤確認後下一交易日開盤估算成交，跳空在 ±3% 外不買。最多 5 檔，每次以**前一日**淨值的 1/5 為預算上限，現金不足則縮小，不借款、不加碼；100 萬僅為可比較本金。不是每日強制等權再平衡，也不是看到五檔就必須買滿。

固定 7% 停損從買入當日生效：開盤低於停損價以較差開盤價計，再扣滑價；其餘用當日低點是否穿越停損價估算。單一價位、無量或已知停牌不假設成交，觸發但未成交的停損保留到下一個可交易日。跌破選定均線則隔日開盤出場，未成交繼續保留。停損收入不能回頭資助當日已結束的買進階段。

費率：雙邊手續費各 0.1425%，最低 20 元；股票賣出稅 0.3%、ETF 賣出稅 0.1%；雙邊滑價各 0.1%。固定參數另跑每邊 0.3% 滑價壓力情境。這些是本次模型假設。期末部位扣估計清算成本、保留未平倉狀態，沒有捏造交易或勝率。

## 時間切割與結果判讀

資料區間為 **2021-10-25～2026-10-22**，使用封存行情的共同終點。模型先載入 420 個交易日暖身；本機較新 DB 日期不直接混入封存研究。

- 2021-10-25～2023-12-29：訓練 24 組；至少 20 筆平倉，依 CAGR − 0.5 × 最大回撤絕對值選 5 組。
- 2024-01-02～2024-12-31：選最高扣費報酬；同分依較小回撤、較低周轉、參數名稱排序。
- 2025-01-02～2026-10-22：選定後獨立本金起算，不參與調參。完整五年則是選定參數的連續回溯。

此專案其他研究曾用過這些歷史期間，所以不得宣稱專案層面的全新未見測試。訓練、驗證不強制報酬為正，只是固定的比較程序；若全數虧損，仍完整呈現，不能把「選定版本」解讀成合格策略。

另比較同期間扣費的 0050 持有，以及固定動能基準（40/40/20、70 分、MA10、兩種進場，僅 M 篩選與排序）。後者使用同一完整資料母體以便控制比較，但因參數不同，不能將差額全部歸因於多篩選器的效果。年度報酬由同一連續五年淨值相乘計算，2021 與 2026 不滿一年。驗證段獨立本金與五年連續帳戶的分年度報酬不必相同。

## 資料限制與修正紀錄

行情、還原價、歷史身分來自既有封存 bundle；法人來自目前 DB 歷史值；實際成交金額經專案 FinMind 共用節流及快取抓取。任何 token 與密碼均不寫入產物。2076 檔中 48 檔來源回傳空值，保留缺值，不補成零成交。

成交金額只採用與封存行情的原始收盤、成交量一致的座標。回報含每日覆蓋，以及不一致、缺法人等排除數；不能宣稱每日完整覆蓋全台股。歷史下市股票母體及法人首次發布時間未全部核證，存活者偏誤與資料修訂風險仍存在；不同時間段的品質可能不同。

首次計算遇 1760 寶齡富錦 2022-02-22 官方停牌，增加「只對有證據的整日停牌延續估值」處理。歷史 6247 停牌區間與 69 個實際有價量日衝突，維持不可用；若持倉遇到則中止，不擅改舊身分檔。

0050 在 2025-06-11～17 分割停牌、6/18 恢復，依[證交所元大基金公告](https://www.twse.com.tw/zh/ETFortune/announcement?company=A00005&date=20250617&fund=0050&seq=1&type=other)補齊估值。只接受官方期間內零價量或缺報的非交易日，不對未知缺價通用前填；還原價已處理分割，不再重複乘 4。此修正只影響基準持倉估值，組合全期與測試結果和修正前完全相同。資料修正與中止 log 均保留在研究快取，未根據收益調整參數。

模型使用可分割還原單位，隱含公司行動收益再投入；沒有處理真實整數股數、股利付款日與配股交付。當日完整日 K 的可交易性檢查依賴事後價量，不能代替開盤委託或證明停損流動性。沒有逐筆排隊、成交量容量或市場衝擊驗證。這些限制使結果只能作研究，不具自動實盤資格；沒有替換既有 POC 或改成交帳本。

## 重跑與檔案

在既有 stock_bot 環境、原始封存 bundle 與本機研究輸入都保留的條件下：

```sh
python scripts/prepare_course_bundle.py
python scripts/research_course_bundle.py
python -m pytest tests/test_course_bundle.py -q
```

輸入固定於 `.cache/course-bundle-20261028`。prepare 已封存時只核對，不重新抓取；研究依輸入、規格、程式碼及證據 hash 建立不同結果目錄。已有完整結果時逐檔驗證輸出 hash。`latest.json` 指向最近完成結果，失敗不發佈完整結果。

Git 保存程式、規格與精簡研究產物，不上傳大量私人資料庫快照或課程影片。只複製程式到另一台電腦不足以重現原資料，必須另外保留 hash 對應輸入。報告含全部 24 次訓練、5 次驗證、8 種完整案例、每日淨值、交易、選股決策、來源 hash 與限制。
