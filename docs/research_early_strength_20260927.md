# 剛轉強與第一根後確認：六組實測

2026-09-27。**這次沒有找到更會抓飆股的充分條件。等三天或等回測支撐，降低進場後很快跌回原點的比例，但同時漏掉大量急漲；「五日相對強度由弱轉強」只有後段小幅改善，前段與60日結果不一致。六組均不採用為實盤策略。**

這是按固定規則完成的事件研究及既有帳戶引擎嘗試，不是新的已獲利策略。價格事件結果尚未扣費、不保證成交，不能當成100萬元帳戶報酬。帳戶缺資料的狀態獨立保留。

## 固定設計與樣本

規格在結果產生前提交：`docs/prereg_early_strength_20260927.md`，commit `5d3f2fb`。沒有因為結果不理想而重新挑門檻。沿用既有第一根：前期整理、當天兩倍量且漲至少2%、高檔收紅、前10日無同類訊號、同股21交易日冷卻，行情及流動性限制不變。

- 研究期間2022-01-03～2026-09-09，共6,357事件。指定十檔及藥華藥合計108事件只列案例，主母體6,249事件；使用現有1974家公司快照，有歷史名冊與存活者限制。
- 篩選分為全部第一根，以及**T−1的最近5日相對0050報酬>0、前一個不重疊5日<=0**。這是「由弱轉強」假說，不保證位置低、不要求籌碼集中。
- 進場分為第一根T確認後T+1、連續守住3天後T+4，以及5天內第一次量縮回測啟動價收回後的次日。三者都不能在尚未知道結果的當天成交。
- 三天确认：每天未收破T−1收盤，第三天收盤不低於T收盤、三天平均量低於T量。回測支撐：盤中低價碰到或低於T收盤，收盤回到其上且不低於開盤、量低於T量；前面先跌破或缺資料就不能跳過去找成功日。
- 20日急漲：從T+1到T+21收盤至少漲30%，且超過0050至少20百分點。60日標籤為至少漲50%、超過30百分點。未達門檻不等於虧損。
- 各組共用T+21/T+61終點，確認組投入天數較短；另計各自實際參考進場日至終點的0050報酬。2022–2024按結果終點分組，2025–2026按訊號日分組，跨界另列。這是已見歷史分段，非未見驗證。

## 2025–2026：降低假起漲，也漏掉多數急漲

主母體這段有2,065事件，1,860個第一根20日結果可判斷，其中108個符合急漲定義。表內平均與命中率只對**實際觸發且價格結果可判斷**的事件計算；「捕捉原急漲」則看原108事件中有多少曾發出該組進場訊號，不表示較晚買入仍保有同樣漲幅。

三個「剛轉強」組另有83事件因事前0050窗口不完整而無法判斷；其中原急漲有2例，保留未判定，不算漏選。三天確認及首次回測各捕捉27/108，都是25%，但未必是同27例。基準之外的訊號也可能因更好的買點達到門檻，所以「捕捉原急漲」與「進場後仍急漲」是不同指標。

進場後接續五個交易日，收盤跌破T−1收盤的比例：全部第一根 **27.95%（1,989已知）**、三天確認 **12.06%（481已知）**、首次回測 **14.79%（622已知）**。這不是停損率，更不是確定虧損率；等待條件本來就排除一些早期下跌，不能把這個下降單独當成預測優勢。

把同一事件未觸發者留現金0、未知保留未知，在共同可配對的1,860事件中，三天確認較直接進場平均少1.94百分點、首次回測少1.77百分點。這仍是等權事件機會比較，沒有有限資金與重疊持倉約束，不能加總成帳戶損益。

「剛轉強＋回測」看似最接近0050，但只有180個已知結果，而且股票、日期與其他組不同；沒有足夠證據認定其改善來自篩選本身。不能挑這一格就宣布勝出。

2025–2026的60日比較，全部第一根平均+7.99%、相對0050−7.53百分點；剛轉強＋第一根平均+6.30%、相對−8.23百分點，沒有重複20日的改善方向。剛轉強＋回測平均+5.86%、相對−7.11百分點，也没有領先基準。每年度與全部六組60日結果保存在`annual.csv`及`statistics.csv`，沒有只保留較好區間。

本研究的覆蓋率只針對「已符合第一根定義」的急漲，**不是全市場所有飆股的召回率**；早先沒有整理或沒有兩倍量的急漲，本來就不在此母體。這是這套觸發器本身的研究界限。

| 藥華藥訊號 | 第一根次日到共同20日終點 | 三天確認 | 首次回測 | 剛轉強篩選 |

| 2026-05-08 | +31.16% | +18.41% | 未觸發 | 不通過；前兩段都落後0050 |

5/8前一天，近五日相對0050為−5.80百分點、前段為−5.10百分點。也就是**相對強度還沒變正，個股後來仍可能大漲**；不能把相對強度翻正設成所有題材股的硬門檻。1/16未達本研究20日「30%且超額20百分點」定義，不表示它沒有大漲。

昇達科2025/8/1第一根到共同20日終點+13.16%，三天確認未觸發、回測組+12.99%；11/12第一根+24.49%，三天確認未觸發、回測組+28.05%。案例顯示等待的效果不同，但這些已知使用者指定股票沒有參與主統計或帳戶選股。

## 可重跑工具與驗證

`skills/early_strength.py`把當時特徵、逐日確認、次日訂單與未來結果分開。`scripts/research_early_strength.py`提供一鍵離線研究及兩輪一致發布。全部決策、未觸發、未知、逐年結果、指定案例與帳戶原因均留存，並登錄試驗紀錄。

```bash
python scripts/research_early_strength.py --output .cache/early-strength-independent-a
python scripts/research_early_strength.py --output .cache/early-strength-independent-b
python scripts/research_early_strength.py --publish .cache/early-strength-independent-a .cache/early-strength-independent-b
```

輸出目錄必須全新；保留原規格與來源指紋。不需要每次回測重新拉資料。第一輪開發執行在未來截斷檢查遇到「未來有缺值使nullable欄位dtype改變」而停止，已統一明確nullable/數值型別並加回歸測試；該次沒有產生報酬，沒有為此改選股規則。

正式輸出：`.cache/early-strength-20260927-v2/`與`v3/`，包含`events.csv`、`decisions.csv`、`outcomes.csv`、`statistics.csv`、`annual.csv`、`entries.json`及28份帳戶結果。每輪約141.30／167.14秒，包含六組因果檢查與帳戶嘗試，並非只計單一回測；執行時另有專案驗收程序。兩輪全部資料表、訂單與帳戶輸出指紋一致，發布索引為`artifacts/forward_simulation/early_strength_20260927.json`，另附SHA256。

驗收：12個針對性測試，完整`make test`為3,862通過、35項既有警告，約106.61秒。最初沙箱驗收受本機連線限制而未通過，最終在允許本機服務的環境重跑成功。`make pipeline`保留既有TWSE来源暫停guard，exit 0；暫停的HTTP步驟沒有取得資料，不能解讀為歷史來源補齊。`make api`因8000已有服務而退出，改驗既有服務四個規定端點，health/picks/models/jobs均HTTP 200。日誌保留在`.cache/early-strength-*-20260927.log`及對應API JSON。
