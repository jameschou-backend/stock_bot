# 2026 每日選股訊號與 K 線

本頁將既有三檔策略的全部候選訊號整理成可離線開啟的 HTML。它是訊號日誌，沒有把每日前三名當成實際買進，也不重算或改動策略。

輸出：`artifacts/reports/signal_explorer_2026.html`。用瀏覽器開啟即可，不需登入、資料庫、FinMind 連線或外部圖表 CDN。

## 使用方式

1. 按月份與交易日，由前往後查看每天的候選股票。
2. 點股票名稱／代號，在 K 線圖查看它的股價、成交量與訊號位置。
3. 預設圖表只顯示到選定訊號日；切換「查看後續走勢」後才顯示後來的行情。
4. 可切換圖表範圍，以及查找股票或篩看當日前三名。篩選僅改變畫面，保留原始名次。

箭頭是「收盤形成的選股訊號」，不是成交紀錄。原策略下一交易日才嘗試買進，且受現金、三個主要持股名額、成交量與價格限制。日誌不判定當天是否真的買得到，也不顯示未來損益作為當日選股依據。

## 資料範圍與來源

固定來源是 `.cache/all-signals-2019-20261002/inputs` 的封存行情，以及 `.cache/signal-rank-20261003/rank-v2` 已核對的逐訊號排名。2026 年涵蓋 **2026-01-02 至 2026-10-02，共 181 個交易日、4,612 筆訊號、771 檔股票**。資料日期不是電腦當日日期，不會自動延伸尚未取得的行情。

本年度封存的每個交易日剛好都有訊號；程式仍保留沒有訊號的交易日，該行為另用合成資料驗證。圖表包括年初以前的暖機行情，便於看突破前背景，但標記僅限本次選定的 2026 訊號。

圖表採還原價格；同一天的開、高、低、收均用同一個「還原收盤÷原始收盤」比例換算，避免混用原價蠟燭與還原價指標。原價可由圖表資訊查看。缺少有效行情不補成虛構 K 棒。訊號使用前 60 日最高還原收盤，不是最高盤中價。

既有資料限制保留：歷史市場身分與還原價不是全量官方認證，9/10 後行情是 FinMind 延伸。這個 HTML 的完成代表視覺化與對帳完成，不代表策略已取得實戰資格或真實成交證據。

## 重建與維護

- 資料輸出工具：`scripts/export_signal_explorer.py`。
- 頁面模板：`ui/signal_explorer.html`。
- 資料驗證：`tests/test_signal_explorer_data.py`。
- 研究母體及排名解釋：[research_signal_rank_20261003.md](research_signal_rank_20261003.md)。

產生頁面時重用封存快取，不抓取資料、不訓練模型、不寫交易帳本或資料庫；所有資料與畫面程式內嵌在同一個 HTML。修改模板後重新輸出 HTML 即可。

在專案根目錄執行：

```sh
python scripts/export_signal_explorer.py \
  --output artifacts/reports/signal_explorer_2026.html \
  --payload .cache/signal-explorer-20261003/payload.json \
  --receipt .cache/signal-explorer-20261003/receipt.json
```

來源快取需完整保留；工具驗證封存雜湊，不會遇到缺檔時偷偷改用其他資料。HTML 約 23.2 MB；僅在切換個股時展開該股行情物件，不一次建立全部股票的 K 線物件。
