# 名額拒單與佳世達停牌補件

本次 31 組帳戶比較的 Bollinger 帳戶，在 2025-09-17 出現一筆開盤前已規劃、後續因名額鎖定而拒絕的揚博（2493）買單。舊執行稽核只接受零規劃拒單或正式停牌，因而將這筆正規劃量的資源拒單誤報為缺少停牌證據。

當日原有 2002、3702 兩個活躍部位。3645 的舊餘股賣出後，同日新訊號仍保留原本的零買單拒絕；既有保守資源規則仍鎖住這次嘗試的名額和未用預算。2493 的開盤前規劃量為 2,089 股，資源層剩餘預算所算委託量為 670 股，名額已滿而整筆拒絕；實際成交與支出均為零。

`all_entry_resource_rejections.py` 只補充稽核分類，不改帳戶交易、現金、持倉、訊號或名額規則。封存主程式先由既有獨立稽核重建持倉、公司行動、名額與現金，再核對拒單的委託、資源計畫與名額紀錄；拒單必須沒有成交、買入支出或新建批次。所有原規劃的時間、數量、法定限價、現金保留檢查仍執行。僅未送出的拒單子單不要求不存在的成交帶，且獨立揭露其數量，不冒充停牌、缺資料或成交。

此外，佳世達 2025-08-04 公告明示減資停止買賣為 2025-09-25～2025-10-03，新股自 2025-10-07 交易。來源沿用 [佳世達補件](all_entry_2352_completion_20261011.md) 的封存公告轉載與期交所公告副本。`all_entry_capital_halt.py` 僅在這段已公告的完整停牌期間補入不可成交的零活動觀測，供既有成交量均值與停牌辨識使用；未知日期保持未知，候選清單與選股參數不變，原檔不覆寫。

補件重播入口為 `scripts/research_all_entry_accounts_resource_audited.py`，保留既有資本減少結算及零買單修正。前次完整走完但未通過稽核的帳本保留，較晚補件結果無論成敗都替換前次，不按績效挑選版本。

針對有效拒單、虛構名額、遺失資源紀錄、隱藏成交、新建批次、錯誤限價、數量和現金保留，以及原本正常／資料排除帳戶的稽核一致性，專項測試 39 項通過。另以實際 Bollinger 帳本定位到唯一正規劃量的名額拒單：2025-09-17／2493。

## 仍無法取得的逐筆資料

6914／2024-06-06 與 8045／2025-02-06 的必要逐股逐筆查詢回傳空資料。另依 FinMind 官方技術文件，以共用持久配額保護、最多兩個日期且不重試，檢查 `storage_objects` 整日 Parquet 管道。第一筆收到 HTTP 400，供應商確認現有方案為 Sponsor，該管道要求升級；因此停止第二筆。這不證明升級後兩檔資料必然存在，也未購買或修改方案。

請求前規格與去識別回執保存在 `.cache/all-entry-accounts-20261011/storage-probe-v1/`。舊的空資料回執保留；未將空資料替換成推估成交量，也未自動重試或切換成交模型。
