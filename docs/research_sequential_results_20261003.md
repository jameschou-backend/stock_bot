# 五項方向依序研究結果

2026-10-03。**四項完成固定規則實測，一項確認證據尚不足；沒有任何新規則通過本輪事前設定的晉級條件。** 原策略與2026訊號HTML未被替換，沒有下單、啟用排程或宣稱已可實戰。

固定30,188筆2019年至2026-10-02原始訊號，當日資料完成後判斷、下一市場交易日以HL2假設成交。以下是含原比例成本的**每個訊號一份等額預算之平均淨報酬**，不是三檔帳戶的累積／年化報酬，也不能拿這個平均直接與0050累積報酬比。

|順序與固定研究|同組比較|結果|
|---|---|---|
|1. 同群轉強＋群體成交占比增加|17,952個可判讀且已完成機會，原+1.059%→篩選＋現金+0.170%|覆蓋不足、三段平均均退步；原≥30%贏家只留24.72%|
|2. 早期催化→獲利落地|26事件、8檔，0事件具合格歷史公開時間與完整階段證據|不能計算可信策略收益；沒有把未知當成無題材|
|3. 法人買超且股價較強|29,637個可判讀且已完成機會，原+0.899%→篩選＋現金+0.665%|勝率33.54%仍不足以補回漏失機會；原≥30%贏家只留65.28%|
|4. 半倉入場，第3日確認再加|29,749個相同已完成機會，原+0.948%→+0.745%|最差5%平均−19.96%→−15.70%，但上漲收益也被減少|
|5. 滿5日未賺，有更強訊號換股|29,446個相同已完成機會，原+0.990%→+1.024%|僅改善0.033百分點；2023年後兩段均退步，最差5%平均惡化至−26.66%|

每列母體不同，因此已列出相同母體原策略對照，不能將右列的最高數字視為策略排行。篩選排除的已知機會保留現金零報酬；未知不當零。換股另外有303個原已完成機會變未知或尚未平倉，沒有偷偷刪除後宣稱完整績效。完整原始樣本還有259持有中、7待出場、152資料未知、21尚無下一交易日。

法人與群體條件交叉也未改善；T−3法人延遲敏感度同樣未通過，所有結果保留。這輪得到的是具體的排除證據：**增加看似合理的門檻，可能提高部分交易勝率，卻漏掉大贏家；換股可能增加勝率，卻擴大虧損尾端。** 沒有只挑最好看的單一年份或平均數。
