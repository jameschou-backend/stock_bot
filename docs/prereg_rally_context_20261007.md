## 固定16項條件

| ID | 條件（全部T收盤可算，另註外部延遲） |
|---|---|
| not_extended | 還原收盤/20日均線 ≤ 1.10 |

| market_above60 | 0050 T還原收盤 > 60日均線 |
| market_breadth | T具日期資格、有效60日均線的普通股中，站上60日線比例 ≥ 50%；有效分母/當日具資格母體需≥80%，且至少500股，否則未知 |
| peer_breadth | 封存歷史價格共振同儕的 peer_above_ma20_fraction ≥ 0.5 |
