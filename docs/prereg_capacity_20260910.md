# 部位容量與大盤校正排序：固定研究規格

2026-09-10，新方法收益計算前固定。使用者同意先測部位配置與殘差動能；本轮先將殘差動能限定為既有領先事件爭取同日名額的排序，不重選群內領先股，不將此實驗稱為完整殘差動能選股或論文複製。

## 共同條件

- 沿用已封存 diffusion 與 regime-switch 的兩價格版本、原始可成交旗標、每月群組、領先事件和0050趨勢狀態。不下載資料，不重新挑群組或突破門檻。
- 共同比較期間 2022-01-03～2026-06-23，新領先訊號截止2025-12-31。只接受訊號日0050高於最近120次有效收盤均值的既有領先事件；UNKNOWN及OFF不接受。全段歷史已使用，沒有未見測試。
- 訊號後下一交易日收盤模擬成交；額外延遲組再晚一交易日，排序仍用原訊號日資訊，持有期仍從實際進場起算63個交易日。不得用成交日行情重新排序或選替代股。
- 初始NAV為1；最大同時部位為3或6，每事件最多轉出當日NAV／名額數的0050市值，淨售款支付個股買入及成本。無槓桿，總起始資金相同。閒置資金持有0050，到期換回；沿用原重疊、額滿、整籃可成交及期末未清算規則。
- 手續費每邊0.1425%，股票賣稅0.3%、0050賣稅0.1%；滑價每邊基本0.30%、壓力0.45%。每次0050與個股轉換均扣費，不新增資金淨額交易或現金停泊規則。

## 殘差分數與時序

- 股票和0050使用當日及前一市場交易日的有效正收盤形成每日簡單報酬。不以估值前值補成行情；兩天任一天無有效收盤，該日報酬缺失。
- 訊號日含當日在內最近20個市場交易日作分數窗口。其前方不重疊126個市場交易日作估計窗口；用含截距OLS估計 `r_stock = alpha + beta * r_0050 + error`。
- 兩窗口全部146個必要股票／0050報酬都須有效。估計窗口0050報酬的母體變異數須大於1e-12，alpha、beta及分數均須有限。不足、缺失或退化明確拒絕，不回退原順位。
- 完整146日也檢查另一封存價格版本，股票與0050兩版本都須有有效報酬；任一版本絕對日報酬大於20%，或兩版本日報酬差的絕對值大於0.005，拒絕評分。這個新增窗口比原領先訊號的126日品質窗長，不能省略。原價格的上市前遮罩維持有效；兩個matched臂同步排除，原兩臂不改。
- 新分數固定為20日 `sum(r_stock - alpha - beta*r_0050)`，不除以波動、不加分數正負門檻。此為以0050作单一市場代理的短期殘差分數，與學術多因子、不同期間的方法並不相同。[研究動機](https://repub.eur.nl/pub/22252)
- 保留每事件原priority、新分數、alpha、beta、兩窗口起訖與拒絕原因。輸入股票、原始領先日期及原成員不改，只替換事件priority。訊號後一日執行；同priority沿用event_id排序。
- priority改的是同日事件處理順序，沒有跨日排隊或取代現有持倉。即使名額足夠，每筆仍按前面成交扣費後的NAV計算，改順序也可能微幅改變权重；不得將所有差異都稱為額滿篩選效果。

## 四臂與兩個獨立主比較

1. `control3`：原趨勢進場、原priority、最多3個部位。完整重現前輪entry_only。
2. `capacity6`：同一事件與原priority，只有名額改成6、每筆預算相應為至多NAV／6。主比較為capacity6減control3。
3. `matched3`：只保留可評分的原趨勢事件，但仍用原priority、3個部位。用來分離資料缺失篩選的效應。
4. `residual3`：與matched3完全相同的事件、日期、成員與3個部位，僅priority改成殘差分數。主比較為residual3減matched3；另比較control3與0050，不掩蓋縮小事件池的代價。

不測6名額＋新排序的組合，也不加個股出場、同群限制、財報或新聞條件。四臂×兩價格×兩成本＝16；官方價格壓力成本四臂全部額外延遲一日＝4，合計20組方法，加4組同成本同價格0050持有。

## 判讀與驗收

- 先封存原始事件與評分、觀察可用率及同日排序有沒有真正改變，之後才計算新收益。若改排序幾乎不影響可成交選擇，報告檢驗力有限，不擴大規則來追逐效果。
- 容量實驗報買入數、額滿／重疊／不可成交拒絕、持倉及每日股票曝險。增加名額會稀釋贏家，也會改變選股路徑，不能只用事件數增加宣稱改善。
- 殘差實驗報可評分率、同日競爭與排序改變日期、實際共同及獨有事件、每個分數所用時間；matched3與residual3需同一候選池。
- 各臂報累積與年化扣費收益、最大回撤、年度收益、換手、成本、估值疑點及期末是否可清算。所有對照用相同起訖、價格與成本，不將敏感度比較當獨立驗證。
- 原control3的summary、曲線、逐筆成交、cohorts及rejections需與前輪entry_only完全一致。以合成案例測評分時序、未來資料改動不影響既有分數、缺資料拒絕及輸入不被修改。
- 再獨立稽核每日現金加部位等於NAV、每日市價損益減費用、逐筆交易可成交與稅費。可疑收益保留並標示，不因未來不利結果回頭排除。
- 目前名冊存活者偏差、合成還原單位與歷史價格核對、完整漲跌停和最小手續費限制仍在。結果維持 `research_only=true`、`live_qualified=false`、`valid_strategy_evidence=false`。
