# 2024 年起每筆訊號的獨立結果

使用者要求先排除本金與持股名額限制，檢查選出的股票是否獲利。固定使用 liquid_universe 原始訊號，訊號日自 2024-01-01 起，封存行情截至 2026-09-09。不重新選股或搜尋新參數。

每筆訊號獨立建立一個理想成交觀察，包含同股重疊訊號；另外報告每檔第一次入選，該子集只依訊號日期決定，不按結果挑選。不能把每筆報酬相加或相乘當成帳戶複利，也不能把重疊訊號當獨立統計樣本。

沿用 T 收盤選股、T+1 買進，買賣以該日普通交易高低價中點作代理；沿用入場日還原收盤基準下跌 12% 時，隔交易日賣出，最遲入場索引 +63 日賣出（前一收盤決策）。沒有獲利目標停利或新增等待期限。停損訊號先於期限。同一日賣出的實際盈虧與退出原因分開，期限出場仍可能虧損。

原始中點乘以當日還原收盤 / 原始收盤，計算調整後的價格相對報酬。估算扣費報酬 = 出場調整中點 × (1−0.1425%−0.45%−0.3%) / [進場調整中點 × (1+0.1425%+0.45%)] −1。這是單位投資的比例成本模型，未指定交易股數，因此不模擬最低 20 元手續費、整股捨入、股利支付時間、配股交付、現金再投資、零股逐筆成交及部分成交。還原報酬不是可提款的現金帳簿。

此研究刻意假設所有有效訊號均可成交，用於檢查選股品質；沒有取消或修改正式帳戶的容量、漲跌停、現金或交易限制。即使原始當日有量，也不能保證中點成交；平盤整日單一價格標記成交疑慮。不能把本研究勝率當成完整成交驗證。

檢查每筆持有路徑的雙來源還原行情、歷史身分及原始 OHLC；缺值、不合格身分、雙來源每日報酬差超過 0.5 個百分點、單日異動超過 20%、累計雙來源報酬差超過 2 個百分點均明列資料待核對，不能默默剔除。所有完整的正負結果均報告。

持有期最高漲幅使用入場當日到出場前一日的最高還原收盤，分母為進場調整中點；不使用退出當日收盤冒充退出前已經歷。未出場者按最後有效日收盤估值，假設清算的比例成本另標為未實現，不能混入已出場勝率。最後一天才出現退出指示時列待賣，不能當天成交。
