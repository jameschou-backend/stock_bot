# POC 原版出場前兆診斷

只讀正常成本原版帳本、已發布五段回撤及原封存行情；不重播帳戶、不產生新績效、不更換策略。全期 2024-01-02 至 2026-10-02 已經研究過，不是樣本外。

本輪在計算前固定三個診斷條件，不搜尋天數或幅度：

1. `two_black`：買入後連續兩個黑K，且每天還原收盤低於前一天，沿用原三黑K的單日判斷。
2. `below_ma20_two`：買入後連續兩個還原收盤低於各自當日20日均線。
3. `two_black_below_ma20`：兩黑K，第二天還原收盤也低於當日20日均線。

三者都加相同的獲利篩選：警訊日還原收盤高於首次買進日還原收盤。這是與原停損錨點一致的價格訊號，並非扣費獲利保證。均線含當日及前19個市場交易日，不補缺值。兩天條件的第一天不得早於買入日。

每一批次從進場後開始取第一次合格警訊，不在事後回撤高點重新開始。只把早於原版首次完整出場指令「決策日」的訊號算作提前；同日已觸發原出場不算。排除原出場指令後的殘股等待成交時間。收盤資訊最早下一市場交易日可用，不假定該日已成交。

檢查全部原版73個持股批次，五段回撤的舊持股及新買虧損另外對照。事後檢查警訊後、原出場決策前是否續漲及創持有期新高，揭露過早減碼風險；未出場批次另標右設限。不把這些描述統計稱作減碼績效或可避免損失。

若後續另外驗證部分減碼，三項各自獨立測試：首次警訊隔日提出賣出 floor(警訊時可交易股數/3)，保留至少一股；同批只觸發一次、固定剩餘目標、未成交部分續掛。原12%停損、63日期限及三黑K完整出場優先；餘部仍占原名額，沒有補買或自動加回，釋出現金依原版配置。公司行動按原帳務處理，不可把未交付權益當股數賣掉。費稅、滑價、整零股容量都沿用原版。此處只列待測規則，不執行回測。

不重跑已測的全數移動停利20/12、40%集中度減碼、四黑K、追高限制、波動配置、冷卻與大盤MA120新買減半。舊母體已做過MA20加相對弱勢全出及高點回落15%減半，也不包裝成新研究。本輪為原POC母體的價格前兆診斷及一次減三分之一候選。
