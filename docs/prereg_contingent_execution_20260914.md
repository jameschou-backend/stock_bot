# 賣出確認後再買進：研究規格 2026-09-14

本輪固定原成交金額排序研究，先稽核原帳戶一般13天、合併壓力15天的資金／名額依賴。不重選股票、不更動舊帳本、不產生缺資料的績效。原路徑的依賴日期只是事後定位樣本，不能當成完整前向候選。

新增獨立的單日事件控制器，供後續逐筆回放及紙上流程使用，未接券商或正式追蹤帳本。金額使用整數分、數量使用整數股；整張與零股可共用同一股票名額，尾數未清空不得釋放名額。

1. T日先固定T+1候選順序、每張委託的股數、限價與含費預算，以及賣出清單。不得把隔日收盤價回填為T日限價。前日收盤限價可作未來新實驗，但不是原日資料執行的一模一樣版本。本控制器只接受已明定的計畫，不代替策略生成計畫。
2. T+1先送固定賣單；買單按原計畫順序檢查。名額或整筆預算不足則等待，不跳過它事後找下一檔。09:01起至13:25前可送單；具體歷史撮合時間由對應盤別來源另行驗證。
3. 已確認的賣出才減少持股。部分成交剩下1股也仍占名額。賣款先記應收；只有另一筆帶有該成交識別碼的可用額度確認，才增加可用金額。不得假設所有券商都立即提供該額度，也不把股票間換倉等同於同股當沖。
4. 買單送出即預留全部預算；整張與零股委託分別預留，合計不得超過確認額度。成交只能發生在送單後，且在期限前。成交回報需唯一ID、價格符合限價、數量符合盤別單位與餘量、含費支出不超過預留。最後一筆成交釋放剩餘預留；到期限取消未成委託，本輪不模擬取消中的額度再利用。
5. 同一時間戳的事件保留來源先後，但新買單不可使用同時間戳行情作成交。資料缺成交時間、零股盤別或完整性時，完整歷史回放保持未完成，報酬為null；控制器的合成測試不等於歷史成交證據。

稽核輸出：每一依賴日的原買賣股數、當日流入缺口、清倉最後一筆渠道、零股需求、既有整張逐筆快取覆蓋、未確認事項及來源雜湊。只讀原封存來源、0次行情API，離線重跑逐欄一致。舊一般／壓力結果及0050比較沿用前份配對報告，這輪不另報新績效。券商額度與零股歷史資料取得前，不自動升級正式策略。
