## 已備妥的交付清單

執行 `python scripts/prepare_odd_lot_evidence_request.py --identity-overlay .cache/historical-universe-followup-20260925/report-final.json` 產生 `.cache/odd-lot-provider-request-20260925-v3/`：

- `stock_days.csv`：給供應方篩選的 market／date／stock_id／channel；股票代碼需以字串匯入，保留 `0050` 前導零。
- `stock_days.json`：同一清單，另保留涉及的研究帳戶與 dated 官方日表路徑。
- `request.json`：市場／月份分布、必要欄位、輸入 SHA-256 與限制。
- `manifest.json`：清單及產製程式指紋。`--verify` 重新離線計算並逐 byte 比較，禁止原地覆蓋既有需求包。

UI 可呼叫 `scripts.prepare_odd_lot_evidence_request.verify_request(directory)`，回傳 `odd_lot_provider_request_v1`；它會重新核對父稽核、案例 manifest／identity、用到的原始日表與所有匯出，不只驗一個 JSON。v3 另封存 `identity_overlay.path`／`sha256` 及其全部 `source_sha256`，驗證時重播同一份 overlay，不能偷偷換成較新的身分表。這是需求清單的完整性，`accepted_sessions` 固定是 0。v2 保留原檔與原 manifest 作歷史盤點，不覆寫；目前 UI 消費及 `--verify` 以 v3 為準。

### 檔案申請及費用範圍

TWSE 已路由需求跨 **57 個月（2022-01 至 2026-09）**；H4 商品按「每月全股」出售，即使一個月只缺少一檔一天，也不能按一股日價格估算。依先前本日封存官方頁每月內部使用 NT$1,500 及僅提供前兩個月底以前資料：截至 2026-09-25，2022-01 至 2026-07 的 **55 個月、923 股日**落在公開供應年齡窗口，列價推算 **NT$82,500**；稅額、折扣、交付及供應商接受個人用途仍待正式報價。此數字不是採購承諾，也不代表付了就能補完整歷史。

2026-08 的 22 股日及 2026-09 的 5 股日，共 **27 股日**不在該公開年齡窗口，須另問合法供應日期／管道。2026-04 起要按新格式解析。`request.json.procurement_plan.twse_h4` 保留完整 55 個候選月份及 2 個限制月份；市場逐月股日數在 `by_market.*.by_month`。

TPEx 已路由 **353 股日／51 個有需求月份**：56 股日在公開起點 2022-11-01 之前、59 股日在查詢日往前一年內、238 股日落在起點之後且距查詢超過一年。這是按公開限制做的供應詢問分組，仍須確認實際邊界、品項是否包含需要的盤中零股及價格。TWSE H4 與 TPEx 商品分開供應與報價。

市場路由只表示當日官方日表或經核驗 dated identity 找到該市場，並非全部上市／轉板身分歷史已驗證。需求涵蓋已知日模型的成交及未成交委託；真正逐次撮合重播若改變路徑，需求可能增加。20 個互斥研究帳戶不能把股數相加當成一個帳戶的下單需求。

## 可直接提供供應方的詢問規格（尚未送出）

需求用途為個人內部研究與回測，不轉售。請先回覆能否提供附件股日清單的 **TWSE／TPEx 盤中零股完整實際撮合及揭示買賣價量**；資料日期為 2022-01-03 至 2026-09-09。請不要提供普通交易 tick、單日 OHLCV、盤後零股或僅試算行情代替。

每檔每日須附完整 session 起訖、股票與市場識別、Asia/Taipei 時戳與精度、價格單位、成交股數單位、試算／實際撮合旗標、序號或重複處理規則、累計量與單筆量定義、原始格式版本、資料檔 hash 及正式來源。請提供每日獨立成交量／金額以驗證全場完整性；若完全無成交，請提供官方無成交或停牌狀態，不能只交空檔。若有買賣雙邊重複成交列，需給唯一成交識別及配對規則；每筆買卖雙邊不可重複加總。

如須估計限價委託的佇列成交，還需確認能否提供新增／撤銷／變更委託、優先序與完整事件；僅有撮合紀錄及五檔，仍不能保證模擬委託的實際成交。

請分開確認以下斷點及可供應日期，不先付款：

1. TWSE H4 的近期供應限制及 2026-04-01 前後格式版本；尤其 2026-08、09 月能否合法提供。
