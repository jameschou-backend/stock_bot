# 逐筆公司行動來源檢查 v1

本修正只在啟用時間後生效。原 capacity-v1 三帳本、所有繼承程式指紋、排序、限價、成本、TTL、風險參數與既有成交完整保留；不回填或追認先前撮合。原始與舊版帳本不執行。

新增獨立 source-guard-v1.sqlite3，封存本守門程式、入口與本文件的 SHA256、啟用時間、三帳本原有末筆雜湊及成交數。不同程式指紋拒絕繼續，不自動重封。這是前瞻執行檢查變更，不能當成整段使用同一版本的策略績效。

每一帳本、每一筆報價，呼叫原撮合器前重新檢查公司行動。檢查使用當時帳本與来源，記錄各來源雜湊和取得時間；阻擋時不呼叫撮合器。來源最早到期時間限制撮合器的每次時鐘讀取：判斷、成交及事件寫入時跨過期限或時鐘倒退，該次撮合交易全部回滾。到期定義沿用原本 0 <= age <= 3600 秒。缺資料只停止，不在同一輪額外更新或重跑。

檢查開始與結果寫在附加帳本；中斷只留下開始紀錄時不宣稱已完成。已存在的觀察不重複計為新成交。人工公司行動核對與結算規則沿用原版，守門檢查不代替人工核對，也不授權真實交易。

每輪共用最多 12 次公司行動查詢、FinMind 共用 5400/h 限流、兩輪 20 秒報價觀察不變。TLS 使用已核對 bundle；不修改 .env 或關閉驗證。啟用後既有排程改用 scripts/run_capacity_guarded.py run；不得同時執行舊觀察入口。非盤中流程仍經過完整父版本驗證後呼叫原版取消、資料更新、人工核對門檻、結算及計畫流程。
