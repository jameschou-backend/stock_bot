# 法人賣超而價格守住：固定廣母體實驗

2026-09-27，先固定資料範圍與規則，再產生結果。沿用封存2022-01-03～2026-09-09行情、1974家公司快照，每21個交易日一個固定觀察日，共55日。不要求第一根、兩倍量或突破。沿用廣母體的掛牌日期、120日連續有效還原行情、過去120日無單日絕對變化>15%、20日平均成交額至少5000萬元；這是現有公司母體，並非已驗證的歷史完整股票池。指定十一檔排除主統計與帳戶，另列案例。

## 假說與六組

訊號日T，主分析特徵截止S=T−1；另固定S=T−3作發布延遲敏感度。法人與价格使用相同五個交易日S−4..S，不混用尚未公布的T日法人。

- `flow_ratio` = 五日（外資含外資自營商＋投信）淨買股數 / 同期成交股數。自營商自行／避險不加入主訊號；各法人仍另存。資料含合併Dealer的非對應市場口徑、缺分類、缺交易日、無效股數都保留未知。淨買零是已知零。
- `sell_pressure`：flow_ratio <= −3%；`buy_pressure`：>=+3%。分母是同股成交股數，不能稱為持股集中或流通股占比。不是看到外資賣就推論看空。
- `resilient`：S相對S−5收盤不跌，同期不落後0050，且期間每個收盤不低於S−5的98%。只描述價格承受淨賣的表現，不認定特定主力吸籌或因果關係。
- 六組：`all_known`（價量法人均可判定對照）、`buy_pressure`、`sell_pressure`、`resilient`、`absorption`（sell_pressure且resilient）、`sell_weak`（sell_pressure且不resilient）。三值判斷，缺特徵不變成false。逐股保留未通過／未知，統計分母不因未來價格缺件改寫。

這些固定門檻只是可否證的操作定義，沒有搜尋最佳門檻。不加入新聞、持股集中、額外均線或再進場。核心比較為absorption對sell_weak，以及在價格已守住者中absorption對非sell_pressure，後者用來檢查法人訊息是否比單純價格強勢多帶來資訊。

另作同日期、同industry、同賣超強度區間（<=−10%、−10%..−5%、−5%..−3%）配對；在有對照時選20日動能与log成交額標準化距離最近的sell_weak，同值股票代碼排序，允許對照重複使用，無對照明示。只用事前資料配對，不能稱因果估計。按訊號日期區塊重抽1000次、seed=42估計均值差95%區間，不把重疊股／60日窗口當完全獨立；長窗口推論仍有限。
