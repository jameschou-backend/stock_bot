# 分點連買與知名分點：資料核對及固定樣本實測

2026-10-04。**比較值得保留的是多個分點持續淨買的行為特徵；這批結果不支持看到指定知名分點買超就進場。** 加入較嚴格的集中条件雖提高勝率，也可能刪掉後續大漲訊號，不能因此直接替換 POC 選股。

## 本輪真正測了什麼

使用既有 2022-01-03～2026-09-07 的 458 筆候選，行情截至 2026-09-09，完全離線，新增 FinMind 請求 **0 次**。不是只看事後飆股，也不以三檔帳戶有沒有空位決定樣本。442 筆分點表符合這次的平衡／內容檢查，15 筆不平衡、1 筆缺資料保留 unknown；平衡不代表市場揭露完整，不平衡也不直接判定供應商錯誤。

每筆訊號獨立試算：T 日盤後分點資料，T+1 高低中點代理買入；12%收盤停損或63日期限，後一交易日中點代理退出。沿用舊診斷工具，12%停損以**進場日還原收盤**為錨點，不是中點假定買價。每邊佣金0.1425%、滑價0.45%、股票賣出稅0.3%。持有期資料品質檢查、未出場與未知另外列。**這是條件診斷，不是有本金、容量與實際撮合的帳戶報酬。** 單筆平均不可相加／複利成帳戶績效，尚無新增策略勝0050的結論。

全部458筆中，443筆已出場、10筆仍持有、5筆行情／資格待核對。下面每項先限制到自己的完整分點資料樣本，再比較同覆蓋下通過與未通過者；不同列的樣本不可直接拼成策略排行榜。

## 為什麼還不能直接設成硬篩選

集中＋持續的已出場樣本中，曾上漲至少20%的比例為36.96%；同覆蓋未通過者反而有46.60%。它在這個樣本提高勝率，**也會漏掉部分大漲訊號**。若每股只取最早一次訊號，組合條件通過者平均單筆降到+1.48%，未通過者為+6.73%；勝率仍較高，但高勝率沒有自動變成較高報酬。

五日持續的每股最早訊號結果仍較好（115／28筆已出場，平均+4.91%／+0.33%），但對照很少，且沒有控制產業、行情年份、動能強弱與事件共振，不能當因果效應或穩定優勢。2023年度其勝率為55%對60%，也不是每年都改善。

此外，[舊分點帳戶研究](research_broker_persistence_20260924.md)已顯示：五日排序的正常累積報酬比同覆蓋對照少321.89個百分點，壓力情境只多5.03個百分點；五日硬篩選在兩種情境皆落後自己的對照。那些是不同舊帳戶與成交假設，不能搬來當本輪或POC績效。本輪獨立核對其14帳戶摘要、NAV／回撤算術和來源hash，未重新宣稱實盤資格。

## 截圖名單及權證的解讀

「竹科、嘉義、台中」都有多家券商分點，只有地名不能辨認，未擅自加入。五個可辨認分點的官方代碼分別為 `9A9g`、`9853`、`961F`、`7001`、`984K`。分點代碼大小寫必須保留；富邦公益 `961F` 在2024-04-29前名為中港，不能以改名前後兩個名字當兩家。[官方對應與更名證據](research_broker_branch_sources_20261004.md)

證交所說明這類買賣資料合計自營與經紀客戶。因此「分點連買」只代表通路淨流量，不能推定同一大戶在收籌碼、真實持股成本或尚未出貨。[TWSE 買賣日報說明](https://eshop.twse.com.tw/zh/category/sub/29)

權證資料可以作第二條獨立研究線，但必須區分認購、認售、發行人買回及母股避險，並按日期連結母股／到期日／行使比例；權證成交量不是庫存，權證發行也不是發行人的方向預測。目前沒有權證勝率實測，本輪股票結果不能替「永豐內湖權證勝率高」背書。[TWSE 權證教育](https://www.twse.com.tw/zh/products/securities/warrant/educate/qa.html)

FinMind Sponsor 已能取得股票分點（2021-06-30起）及權證分點（2023-06-21起）；全市場整日檔另限Sponsor Pro。股票分點文件寫盤後21:00；權證同頁有01:00／23:00差異，首次可用時間仍需版本證據，不能回填成當日盤中可知。已有 `SecIdAgg` 股票＋分點＋區間快取可重用，無須為連買重抓所有逐價資料。[FinMind 官方文件](https://finmind.github.io/tutor/TaiwanMarket/Chip/)

## 工具與資料稽核

本輪找到舊 ML 分點聚合的真實缺陷：把「分點×價位」列當成分點。抽查90個真實股票日，其分點數與Top5皆和正確先合併分點不同，46個案例重複選到同一家。1216在2026-07-06的3,106列實際只有711個分點；舊Top5淨買4,374,378股，正確為13,373,050股，另與五家區間聚合逐一核對一致。

本輪新增獨立、嚴格檢查的原始分點分析路徑，拒絕錯股／錯日期／非整數量與溢位，沒有讀取錯誤舊聚合。**舊ML聚合模組本身此次未修改**，以免改寫其他已封存研究；預設ML特徵已排除三個broker欄位，但全部歷史自訂模型尚未逐一稽核。現在POC／紅K／三黑K及每日POC機會都未使用這個舊聚合，沒有證據因此改變其結果。
