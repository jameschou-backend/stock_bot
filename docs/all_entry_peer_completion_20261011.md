# 同儕情境資料補齊紀錄

本輪 31 組帳戶準備期間，發現舊情境來源有 570 個 400 日價量母訊號標為 `coordinate_not_covered`。這表示舊研究未計算該座標，不代表歷史價格不存在。依使用者「缺資料就補齊」的要求，補算原定義，不改門檻、股票池或時序。

`scripts/complete_all_entry_peers.py` 重用原本的 `participation_features`。原同儕研究與本輪財務輸入的四份矩陣指紋完全相同。月份之前 120 日報酬建立同儕、至少 100 個共同觀測、相關係數至少 0.5、最多十檔且至少三檔，所有既有覆蓋與資料品質門檻保留。訊號日才計算截至 T 收盤的同儕特徵。

重新計算全部 2,157 個母訊號，原有 1,587 個座標的品質狀態與已知數值完全一致。補算 570 個原先未涵蓋的座標後，362 個可判定，208 個依原定義不足三個相關同儕，保留未知。總未知從 1,147 降至 785；符合「同儕強勢＋市場廣度偏弱」的可執行候選從 348 增至 479。其餘三十組候選檔案逐位元不變。

新輸入為 `.cache/all-entry-accounts-20261011/inputs-v3`，包含完整補算特徵、月內固定同儕、核對紀錄與來源指紋。補算程式不載入帳戶績效或未來標籤。輸入 v2 及其所有結果保留；最終比較必須以新候選重跑同儕組，不能沿用 v2 的同儕組績效。

`scripts/combine_all_entry_accounts.py` 只接受相同財務模型、期間與共享來源的明確後續回測；較後的執行結果一律取代較前版本，包括失敗結果。任何候選檔案改變的組別都必須重跑；無法以較好的報酬挑版本。
