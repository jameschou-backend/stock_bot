# 情境出場實測：2022–2026/9/9 一百萬元帳戶

七種預先固定的出場規則都完成逐筆帳本、現金與股數稽核，並與0050一起完整離線重現。結果是「原持有63日、增加12%停損」優於原版；其他五種新規則均未超越原版或0050。這段歷史已反覆研究，尚無未見期間驗證，不會自動替換正式策略。

## 目前保留的研究方向

「保留原63日持有、遇到明顯失敗才退出」是本輪值得往前驗證的假設。停損訊號是前一市場日的還原收盤，相對實際買入日還原收盤跌12%；次日才嘗試按實際價量及成本賣出。不是盤中跌12%即保證成交，也不是費後帳戶損失最多12%。沒有觸發時，原63日期限不變。

這組58個部位中，21個觸發停損、34個到63日退出，3個期末仍未觸發退出。原版45個部位、359筆買賣，停損版58個部位、478筆買賣。提早賣出會改變後來可買的股票與預算，不能把績效差異全歸於同一批股票的出場價。

逐年看，停損版並非年年更好；優勢主要出現在2024、2025，2022、2023、2026截至9/9都落後原版：

綜合情境切換有113個部位、829筆交易，60個首次退出因個股轉弱，25個因移動停利，15個因停損，6個因市場轉弱，4個因63日後不再強勢。它的總報酬只有43.70%，不支持「把更多出場規則疊在一起就比較好」。本輪沒有根據結果重調門檻；無法單憑此比較判定失敗完全來自過早賣贏家或交易成本，後續需固定已成交部位與預算再作歸因。

## 執行與公司行動限制

- 原固定63日及0050帳本與上一份封存結果逐欄完全相同；每案都只用前一市場日及以前資料決定退出。觸發後若無法成交，指令持續保留，配股晚到也承接原指令。
- 停損版279筆零股交易中，68筆大於當日最後揭示對手量。雖符合日量上限，仍欠歷史委託簿／零股撮合資料，不能保證實際都能成交；其他方案也有此限制。
- `market_weak` 與 `trend126` 持有華南金2880權利證書。本研究不模擬證書交易，2024-08-30發證書後等9/30換普通股才可售，期間普通股代理估值且占用名額。這會改變後續買入，偏差方向不確定；不稱為保守收益下限。其他五案未持有這筆受限權利。
- `market_weak` 期末有NT$4未核實付款／淨額的畸零股毛額應收；`trend126` 有NT$10。均包含在資產估值、未當作可用現金，相關費用與支付時間仍待實收證據。華南金現金股利另未模擬全體股東尾數分配，可能少計1元。
- 使用固定當前公司名冊，仍有存活者偏誤；未計個人所得稅、補充保費或匯費。沒有新期間或實盤證據，亦沒有發送券商委託。

公司行動證據與明示限制：[會計補充](exit_fractional_cash_20260910.md)、[2736](exit_corporate_sources_2736_20260910.md)、[2880](exit_corporate_sources_2880_20260910.md)、[2881](exit_corporate_sources_2881_20260910.md)。精確數值與全部日期參見 `exit_corporate_overrides_20260910.json`；公告轉載與直接公司文件已分別標明，未將未知項寫成已核實事實。
