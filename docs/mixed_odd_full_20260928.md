- 資料準備紀錄：`.cache/mixed-odd-authorized-20260928/receipt.json`，四組 `all_completed=true`，不發表準備階段報酬。
- 正式離線目錄：`.cache/mixed-odd-20260928/full-a`、`full-b`。發布檔 `artifacts/forward_simulation/mixed_odd_full_20260928.json` 及 `.sha256`，包含來源與程式雜湊、四份完整帳本、基準比較。
- 工作台「策略驗證 → 五檔次日限價實測 → 加入零股」已改讀完整版本，顯示淨報酬、最大回撤、期末資產及相對 0050 差距，可下載全部計畫與核帳。
- 最終 `make test`：**4,012 passed、36 warnings**，112.03 秒。新增 6 個安全範圍測試涵蓋缺恢復證據、重導／拒絕回應停止，以及不允許其他端點。
- `make api` 因既有 8000 服務占用而未另起程序；既有四個指定端點均 HTTP 200。

`odd_execution_evidence=daily_envelope_estimate`、`odd_tick_verified=false`、`unseen_validation=false`、`live_qualified=false` 保持不變。零股以自身日高／低及全日成交量估算，無法證明實際逐次撮合或排隊順位。因此「四組可以完整回測」與「可實戰或穩健贏大盤」仍是不同結論。

Pipeline 驗收：首次因 TPEx 公開行情傳輸的 `[USER] unknown error (_ssl.c:2578)` 失敗；維持 TLS 驗證及原設定重跑一次後 exit 0。其他 TWSE 更新仍由原 origin hold 阻擋，不把整個 pipeline exit 0 當成所有最新市場資料完整。兩次日志分別保留於 `.cache/mixed-odd-authorized-pipeline.log`、`.cache/mixed-odd-full-pipeline-retry.log`。
