## 現在採用的執行順序

沿用已封存的 [前向模擬 v1](prereg_forward_simulation_20260912.md)，計画首個進場日為2026-09-14：

1. T日收盤後、資料到齊才產生並保存訊號，建立T+1委託；不得倒填T日尾盤買進。
2. T+1只使用事前保存的股數與限價，以及當時取得的行情。最新快照與前一快照都要符合既有新鮮度規則；未觀察區間不補推成交。
3. 0050賣出尚未模擬入帳，不釋放依賴該筆資金的個股委託。新釋放委託仍受既有委託延遲與兩次行情規則限制；不能拿較早行情成交。
4. 當天剩餘買單取消；出場依既有決策保留並於下一交易日規劃。限價停損可能賣不掉，12%不是保證最大損失。
5. 每日核對成交／未成交、等待資金、來源時間、費稅與NAV。公司行動有待核對就停止結算。模擬與原始回報帳分開。

既有排程已負責此流程，本次不新增第二個排程。這是一套尚待交易日觀察的固定模擬，不能替代券商回報。

## 後續研究的通過條件

下一輪先回答「原訊號在固定委託規則下，能成交多少、未成交改變哪些後續名額與資金」，不先新增因子或調整參數追求更高歷史報酬。

- **資料時間**：同時記錄所屬日期、來源公布時間、系統取得時間。資料何時可用不明時，不算成當日可交易訊號。歷史新聞、財報及籌碼也必須遵守，不用資料所屬月份替代公布日。
- **決策隔離**：成交日行情只能決定事前委託的成交結果，不能回頭改候選、優先序或事前預算。日期檢查之外，保留未來資料變動及截斷測試。
- **撮合證據**：區分盤前委託、盤中成交、零股／整張與資金釋放時間。缺歷史盤中資料時只能報日線情境，不發布「嚴格可實現回測報酬」。
- **比較一致**：策略與0050用共同期間、相同費稅與撮合條件比較；缺共同完整NAV則不發布合格超額報酬。
- **樣本獨立**：2022年至2026/9/9已用於研究，不能重新命名為未見測試。新日期的結果保持規則凍結；若要改規則，另設版本，不承接舊版績效。
- **實戰證據**：前向模擬即使獲利，也只是模擬。沒有券商成交對帳、資料時點驗證與足夠新樣本，維持 `live_qualified=false`。本文件不設定「跑幾天必然可實戰」的門檻。

未來若另測T日尾盤進場，必須先固定決策時間，例如13:20，只使用當時可得資料，且只能以之後的行情模擬。那會是獨立策略版本，不能拿完整日K、全天成交量或盤後法人資料做同日進場。本次沒有啟用尾盤版本。
