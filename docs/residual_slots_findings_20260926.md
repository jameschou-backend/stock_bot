# 餘股與新部位名額：完成研究，尚未取得實戰資格

本輪只改「配股餘額占名額」及其必要風險預算，沒有改454個選股訊號、進場排序、63日／12%出場規則。期間2022-01-03至2026-09-09，共1136個市場日；100萬元複利、5個新部位名額、整張成交、閒錢現金，費用沿用封存成交引擎。0050使用同期間含配息再投入帳戶；滑價壓力對應調整，沒有股票策略的進出場訊號。

正常情境期末資產5,157,949.63元；全部壓力2,140,825.90元。每邊滑價正常0.45%、加壓0.90%，不是提高一次手續費。延遲在原本「訊號後次一市場日」時序上額外增加一日；出場延遲包含故障壓力，不是延遲停損建議。

八種情境只有兩種勝過0050；餘股名額改善全部八種結果，仍沒有解決對成交時點的依賴。正常情境885個滾動252日窗口的超額報酬為正比率56.72%，最差超額-38.14個百分點；全部壓力為21.69%，最差-63.94個百分點。窗口互相重疊，不能當成獨立樣本勝率。正常情境2024年仍落後0050約22.46個百分點。

正常情境前兩大獲利股票占所有正獲利24.07%；全部壓力28.15%。這是股票損益分解，包含期末資產與應收，並非扣除兩檔後重新配置的回測，也非已實現現金獲利。

## 帳務與風險

- 每日開盤前只用昨日帳本與估值。曾在更早市場日出場、股數加待交付整股權利合計1至999股，才可釋放名額；當日新產生餘股不立即釋放。同股票仍禁止重疊買進。
- 所有餘股、股利、待交付權利繼續留帳；權利合計恢復一張時重新占名額。配股交付前物理庫存為0，並不代表權利消失。
- 餘股超過昨日NAV的5%時擋新增買進；每筆含費預算最多（昨日NAV－餘股估值）／5，並受開盤可用現金、成交容量及未成交保留預算限制。5%上限不是從本次報酬挑選。
- 同日賣款、開盤持倉名額及失敗買單名額仍不重用。最多實際持有9檔含餘股，有效開盤名額仍不超過5。正常餘股最高曝險1.09%，各情境最高約2.44%，本次未觸及5%上限；另外以測試驗證超標會阻擋買進。
- 初次獨立核對在2024-08-14發現2880物理庫存已賣出、110股待交付時，核對器錯用8/12價格27.45，而引擎已用8/13的25.05估值。核對器改為從封存原始行情重建前一日價格，禁止使用本日或未來資料。未略過此差異，增加待交付期間價格變動與竄改來源測試後才重跑。

## 操作與下一個可驗證步驟

目前8502工作台側邊欄新增「餘股與名額」：比較8種情境、逐年與滾動報酬、資產曲線，下載每日資產／所有買賣／委託及失敗原因／每日持股。新增「券商紀錄核對」直接使用既有中文核帳表單，沒有新增下單能力，也未把餘股研究規則套入實際核帳限制。

使用者已有大戶投持倉或成交紀錄：先提供同一交易日的期初庫存、成交明細、期末庫存與可用買進額度；若有未成交、撤單、配股，再附相應紀錄。保留日期、代號、買賣、股數、價格、費稅，帳號與個資可遮蔽。只有成交清單也可先檢查股數與費用，但不能猜測當時額度、撤單時序或事前訊號。現有工具的來源SHA只識別提供的檔案，不自行證明真實性或完整性。

策略下一步應先診斷「進場多晚一天為何落後」：在同批訊號、同成本與保守資金規則下，分離首筆成交價格差與後續名額／資金改變；任何新進場規則先固定再測，不能為追求415.79%以上在同一段歷史反覆挑參。此段是後續研究方向，並未算成已完成或未見驗證。
