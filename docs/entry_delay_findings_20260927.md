# 下一步優化：先解決成交時序造成的部位差異

這次沒有新增指標或修改策略參數。沿用餘股名額版八份封存帳戶，把「進場額外晚一個市場日」的四組差額逐一核對回期末NAV。期間2022-01-03～2026-09-09，100萬元複利、整張成交、閒錢現金。診斷不使用使用者的大戶投持股、成交截圖或個資。

## 正常滑價、原出場規則：415.79% → 98.08%

兩條完整回測路徑的期末資產差額為-3,177,193.75元。以下是算術拆分，不是各因素單獨重新跑出的因果效果：

| 差額分類 | 延遲帳戶減正常帳戶 |
|---|---:|
| 正常帳戶獨有的34個進場事件消失 | -1,087,350.00元 |
| 延遲帳戶多出的37個進場事件 | -384,250.78元 |
| 共同57個進場事件的買進股數差異 | -1,503,228.06元 |
| 共同事件每股初始持股損益差異 | -202,364.91元 |
| 合計 | **-3,177,193.75元** |

正常版共91個有買進的事件，延遲版94個；這個落差並不是單純少交易幾次。兩邊的選股事件、可用資金與買進股數隨時間改變，複利也隨之改變。

共同事件的每股損益拆分中，買進價金項反而帶來+105,150元，賣出價金項-308,875元，費用差額+3,367.16元，其餘為股利與期末資產／應收。不能將整個317.72萬元落差解釋成「晚一天一定買貴」。也不能據此反過來建議延後進場，因為共同事件是兩條事後路徑的交集，存在選擇條件。

對稱拆分公式：P=Q×R，以兩邊初始買進股數Q之差乘平均每股損益R，另一項為R之差乘平均Q。股利、配股、減資與期末持股全留在原事件；不是把股票最後股數當成一開始投入股數。

## 具體案例

- **3105穩懋**：正常版2026/1/9買2,000股，4/22依63日出場，該事件淨利753,724元；延遲版1/12因名額已滿而未買進。
- **4958臻鼎-KY**：兩邊都有買進，正常版2,000股、延遲版1,000股；該事件總損益分別792,871.40元及373,196.70元。不能只比較成交單價而忽略投入股數。
- **2486一詮**：正常版2024/4/3買4,000股，7/5依63日出場；延遲版4/8買2,000股，4/23觸及固定12%出場規則。該事件損益差-306,263元，包含股數與出場路徑差異。
- **4971 IET-KY**：正常版2024/11/25買3,000股，次年3/5依63日出場；延遲版11/26買2,000股，次年1/16依12%規則出場。賣出成交價與觸發規則的判斷價不一定相同，不能僅用買賣成交價反推觸發條件。

這些案例是已驗證帳本的診斷，不代表事前能知道哪些股票後來成為大贏家，也不能以事後贏家安排名額。

## 下一步的優先順序

1. **名額與候補進場**：先比較訊號當日固定排序、訊號允許等待的期限，以及名額不足時明確的候補規則。不能用後來漲幅決定保留誰，也不能先假設撤單或賣出成功。每次只改一項，沿用同一組延遲與成本壓力。
2. **固定百分比出場的敏感性**：以事前資料定義的支撐或波動風險距離作候選，與目前12%規則單獨比較。實際成交、部位風險、假突破與缺口必須留帳，不能因事後看到上漲而延後停損。
3. **確認實際執行成本與完整帳務**：券商資料繼續作費稅及帳務核對，與策略研究可以分開推進。部分實際成交不會填補所有股票、所有歷史日期的零股逐筆證據，也不能將個人持股損益當成研究策略績效。

以上是依本次結果排出的研究優先級，不是已完成的三套新策略。已使用的期間仍屬歷史研究樣本，沒有把規則調到這段最好看就宣稱能實戰。
