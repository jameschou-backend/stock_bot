# 收斂突破在現行現金帳戶的固定檢驗

在新型態帳戶收益計算前固定。本輪沿用2026-09-10技術規格的唯一收斂突破條件，
不根據剛完成的支撐結果重新挑窗口或門檻。資料仍是2022-01-03至2026-09-09、
454個原候選、100萬元複利、5部位、整張、閒錢現金。這是已研究歷史的延伸，
不宣稱未見驗證。

原訊號日必須同時符合：收盤嚴格突破此前20個市場日最高價；此前10日高低區間
不超過再前10日區間的75%；當日量至少為此前20日均量的1.5倍。
窗口都排除訊號日，必需資料缺值不補、不買；仍只使用原候選，沒有另挑曾大漲股票。
延後成交不重算原訊號。未通過篩選的0股委託不占用資金或進場名額。

四組各8個既有壓力情境，形成相同底座的成對比較：

- 原12%停損／等額配置，重用已驗證的control帳戶。
- 原12%停損／等額配置，只加入收斂突破進場篩選。
- 支撐＋2%計畫風險，重用已驗證的support_risk2帳戶。
- 支撐＋2%計畫風險，只加入同一收斂突破篩選。

不挑哪個底座比較好才加篩選。16個既有對照的來源、結果及離線證明須核對，
快取重用不計成新執行；16個新增帳戶各真正離線跑兩次，所有執行入試驗紀錄。
完整核對原訊號、每項型態條件、0股不能占名額、原現金／成交／配股、出場指令，
以及改動未來價量不能改變過去篩選。無篩選模式須逐欄等同父引擎。

完整帳戶、32情境、因篩選拒絕或資料不足的紀錄全部保留。初步特徵檢查只計算
條件是否完整及通過數，不查看未來報酬。樣本稀少要明示，不放寬條件補交易。

仍要求8情境勝過同成本0050、最差回撤不超過50%、正常與全部壓力的252日
滾動勝率至少60%、2022–2025至少3年超額為正；即使通過也僅是歷史候選。
不加碼、不啟動排程、不下單、不擴大資料請求，不把日行情成交當成盤中排隊證據。
