# 保守五檔整股限定：事前規格

在第一次新帳戶績效計算前固定。目的為量測拒絕零股成交是否能減少尚未驗證的歷史零股成交依賴，不預設報酬會提高。這段歷史已見，不增加參數搜尋、不宣告樣本外或實盤資格。

既有 `intraday_limit_replay`／`prereg_intraday_limit_20260914.md` 已探索整股入場，但同時涉及限價與資金政策；本輪以最新保守五檔為母體，將买賣整股限定隔離為單一變因，不宣稱首次提出整股研究。

- 基準為封存 `.cache/conservative-diversification-20260924` 的五檔及0050帳戶；正常、combined各一，共四個控制。先驗證父來源／程式／結果SHA256，再重新執行，完整account逐欄相同才開始新案。任何hash不同立即停止，不繞過封存。
- 固定458候選、前20市場日成交金額排序、五檔、前日NAV除以五、訊號至少隔日下單、12%收盤停損與63市場日到期。100萬元複利、閒錢現金、2022-01-03～2026-09-09。開盤前現金、名義預算、開盤前名額與當日失敗嘗試名額全部鎖至收盤，C=U=R=F=1。
- 唯一新增變因為整股限定：在resource sizing完成後的 `_execute_order` seam，將可執行股數向下取1000股整數倍。買賣同規則，小於一張的請求明記 `board_only_below_one_lot`、其他零股餘數明記 `board_only_odd_remainder`；不得呼叫零股來源或產生零股成交。被拒零股不扣款、不產生手續費，不返還當日鎖定預算／名額。
- 配股／拆併股產生的非整張股數保持持股、每日估值、繼續占名額。出場只出售可成交的整張部分，零股餘數不清帳、不假造現金或零成交清倉。若後續公司行動令持股足一張，再依原已鎖定出場指令處理。期末NAV含尚未賣出的殘股及應收權益，不等同可用現金。
- 正常每邊45bps滑價；combined每邊90bps、原進出場延後一市場日與原其他壓力規則固定。佣金率／最低20元、證交稅、每日成交量及前20日均量容量上限不變。0050亦建立相同整股policy正常／combined帳戶，策略主要比較使用同policy0050，另展示原mixed0050，不能偷換基準。0050的原benchmark時序及現金再投入規則保持不變。
- 共八帳戶：四個mixed控制及四個board-only新案（五檔、0050各正常／combined）。來源僅用既有父研究快取，0網路、0新資料抓取、0 DB writes、0重訓；缺公司行動或feeds明確記blocked且保留，不當未成交、不fallback。
- 保存逐日NAV／現金／持股與應收、全部成交／拒絕、資源／名額／整股決策、獨立股數與金流對帳、收益／年化／最大回撤／成本／換手／年度及滾動252日超額比例。額外揭露零股成交數、被拒零股股數、小於一張零成交嘗試、殘股占名額日數及期末殘股價值。重疊窗口不是獨立樣本。
