# 藥華藥：大盤、族群輪動與領先股的差異

2026-09-27。**2026-05-08的大漲訊號沒有同時伴隨整個生技族群走強：當時大盤強、成交活躍度往半導體等電子類集中，生技同業偏弱，藥華藥卻是生技內成交活躍第一名、當天價格強度跳升的個股。2026-01-16較接近大盤與生技活躍度一起升溫；2025-02-12則是生技升溫、個股已偏離季線，但整體市場較弱。**

這些是已見歷史的描述，不是三種情境的勝率比較，更不能由一檔股票的結果反推固定進出場條件。外資、投信各自是多個帳戶的合計，方向不同只證明彙總淨額不同，不能據此認定刻意反向操作、對作或共同主力。證交所也把外資、自營商自行買賣與避險分項列示：[資料定義](https://eshop.twse.com.tw/zh/product/detail/c4c87ac184e44896a05fcab5a9d544ec)。

## 資料與口徑

- 沿用六次第一根訊號，保留未知／失敗結果；2025-02-12、2026-01-16、2026-05-08三次只是主要解讀，不排除另外三次。
- 本文「大盤近20日」使用本機**加權股價報酬指數TAIEX TR**，包含股息的報酬指數，與新聞的價格加權指數不同。快取範圍2016-01-04～2026-07-09，足以覆蓋本次六個訊號日，但不是最新完整大盤資料。0050另外列示，遇缺值不互相替代。
- 市場使用1974檔封存公司名冊、依當日上市日期過濾。生技採名冊產業22，含新藥、製藥、醫材等異質公司；不是精確新藥同業或官方生技指數。核心同業中位數與廣度**排除6446**，避免它自己漲就讓族群指標變強。
- 「成交額」均為收盤價×成交股數的**近似成交額**，非逐筆實際金額，更不是資金淨流入。近5日總額／同期全市場已觀測總額，對照此前20日（T−24～T−5）的占比。缺資料不填0，有效家數與覆蓋率均保存。
- 所有主表截至訊號日T收盤，只能用於之後的判斷；另完整保留T−1快照。沒有以訊號收盤、當天全部法人資料模擬已在當天盤中買到。
- 歷史產業分類、退市股、轉板前行情及第一次發布版本仍未完整驗證。尤其6446行情只從2024-01-25開始；本分析不增加對更早期間的證據。

## 龍頭：交易活躍、價格領先與產業地位不同

「交易活躍」按截至觀察日的近20日均成交額；「價格領先」按近20日價格變化，且當時20日均成交額至少5,000萬元，價格窗口完整。同值依股票代碼排序，全部用當時已知數據，沒有用事後漲幅找龍頭。以下為訊號日收盤排名，未確認為公司營收或市場占有率龍頭。

|---|---|---|

5/8的藥華藥20日均成交額約12.33億元、近20日+14.74%；康霈近20日−8.37%、美時+11.03%，兩者都仍在60日線下。因此不是最活躍三檔已一起站上季線。藥華藥近五日占本生技樣本成交額約27.32%，顯示交易集中於少數股票。2/12這個失敗案例同樣有藥華藥成交活躍第一、約27.80%族群占比，所以「成交龍頭」也不是充分條件。

睿生光電被名冊歸在生技醫療，不能因此假定它與藥華藥共享新藥催化；廣義產業排名不能直接當成精確題材鏈的領先股。全部已列領先股的觀察日前20日另做兩套還原價結果及單日大幅跳動檢查：沒有缺價、兩版本區間差超過5百分點或單日絕對跳動超過15%的旗標，但這仍不是完整公司行動認證。

## 對策略設計的意義與驗證

本輪支持把情境分開描述：市場廣度與權重指數、產業參與度與個股強度、季線附近首次轉強與已拉高後再出量。**沒有支持把「大盤多頭＋全族群轉強＋法人同買」通通串成必要條件**；那會漏掉5/8，但放寬也可能引入更多失敗，本輪未評估放寬後全市場扣費績效。

規格先提交 `b779852`，輸入與輸出都有SHA256；兩輪離線計算同樣12個快照、3張CSV（市場／全部產業／事前領先股）。3個固定截點各做截斷與改寫未來，共6組，歷史市場特徵與領先股排序不變。研究使用0新增FinMind請求、0 DB寫入，沒有下單／排程／策略資格變更。TAIEX TR凍結副本與來源SHA256保留；沒有繞過來源暫停補資料。

```bash
python scripts/research_pharma_context.py --prepare
python scripts/research_pharma_context.py --output .cache/pharma-context-independent-a
python scripts/research_pharma_context.py --output .cache/pharma-context-independent-b
python scripts/research_pharma_context.py --publish .cache/pharma-context-independent-a .cache/pharma-context-independent-b
```

使用全新目錄、兩輪依序執行；`--prepare`只複製／驗證本機TAIEX TR，不發出行情請求。正式輸出在 `.cache/pharma-context-20260927-v1/`、`v2/`，發布索引 `artifacts/forward_simulation/pharma_context_20260927.json`。

驗收：兩輪18.865／18.572秒，三張CSV完全一致；5個新增針對性測試、完整 `make test` 3,850項通過（35項既有警告）。保留TWSE來源暫停guard的 `make pipeline` exit 0；被暫停的TWSE步驟未發出HTTP，不能解讀為來源缺口已補齊。既有API的四個必要curl端點皆HTTP 200。
