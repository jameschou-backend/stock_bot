# 無獲利門檻的高點回撤 15% 停損

使用者指定：買入後追蹤持有期間最高價，價格 <= 高點 × 0.85 即觸發退出。無先獲利 20% 的限制；停損線只升不降；觸發後即使反彈也不取消退出。固定 15%，本輪不搜尋其他百分比、不新增買回或市場濾網。

主要需求是盤中觸發，必須知道買入成交時間、成交後價格先後順序、公司行動的價格基準及觸發後各交易通道的成交證據。原 HL2 帳本沒有買入時間，不能假設全日最高价都發生在買入後，也不能用全天 HL2 充當觸發後賣出價。先建立逐時觸發狀態機及日 OHLC 的確定／不確定分類；缺資料不發布盤中版報酬。

另做明確標示的日線對照：最高還原收盤價回撤 15%，收盤訊號 T、T+1 提出退出。取代原成本 12% 停損，保留 63 交易日上限；不能把日線對照當作盤中版本。持有期高點從進場日收盤開始，這是此對照的明示假設，不冒充實際進場後逐筆最高價。

期間固定 2025-01-02～2026-09-09，100 萬複利、三檔個股、閒置現金、原選股與排序、整股／零股 HL2、費用和流動性限制相同。不改已封存程式。control 必須精確重現原帳戶。正式輸出兩次離線核對，重建所有首次停損及到期日期，核對現金與交易量，保留來源雜湊與失敗紀錄。

固定原買入的日 OHLC 診斷只檢查觸發，非完整策略績效。入場當天不使用未知時序的高低價；其後以可能高點區間傳遞不確定性，遇缺行情／公司行動停止此診斷。逐筆快取盤點只代表原路徑資料覆蓋，不代表變更策略後所需全部資料。

所有結果維持 live_qualified=false、actual_fill_verified=false、unseen_validation=false。當日資料不會反向改變已下的單，盤中停損狀態機只產生退出意圖，不聲稱觸發價保證成交。
