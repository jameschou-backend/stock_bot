# 隔日限價逐筆回測：2026-09-14 事前規則

目的：驗證前日決策、隔日價位與成交量是否支持成交。沿用清理後 458 個候選、2022-01-03 至 2026-09-09、100 萬複利、3 個名額、loss12 / 63 日出場。此期間已研究過，不是未見樣本。

三帳戶：原排序現金、前 20 日成交金額排序現金、獨立 0050。每帳戶兩情境：normal（合格逐筆量及前 20 日均量各 1%、45bp 成本緩衝）、stress（各 0.5%、90bp 成本緩衝）。不重新訓練或調參；不切換正式策略。

本次為 **整張診斷**。FinMind TaiwanStockPriceTick 未提供可辨識的歷史零股盤別，不用普通交易替零股撮合。買進只取千股倍數；公司行動產生的零股保留估值，出場明記缺零股逐筆證據。因此不宣稱等同原零股版本，或通過實戰驗證。

- 開盤前固定候選、限價、股數、現金和名額。限價取上一市場日實際收盤價（公司行動參考價調整），買價向下、賣價向上取合法跳動單位。缺上一日行情不沿用舊價。
- 開盤前已有持股占用名額；當日賣掉才空出的名額隔日才能用。不用當日賣款、股利支付或未成交買單釋出的預留款加開其他買單。
- 僅計 09:01:00（不含）至 13:25:00（不含）逐筆，不估開收盤集合競價。限價買單只計嚴格低於限價的成交；賣單只計嚴格高於限價的成交。相同價位量不算，TickType 不作委託簿證明。
- 成交容量為上述累積量乘參與率、再向下取整張，且不得超過前 20 日均量乘參與率。每股每天最多一張研究委託，成交量不重用。逐筆價格不給有利改善，一律以委託限價估值；另收手續費、稅及成本緩衝。
- 買單當日餘量取消、不追買；出場觸發後鎖定原因，每日以昨日參考價重掛剩餘股數。0050 用前日現金每日嘗試整張再投入（含後续已入帳股利）。
- 完整逐筆回應保存原始順序、重複列、日期、資料雜湊；重複時間不擅自刪除真實成交。日期/代碼/價格/數量/時間格式不符或缺來源即阻斷整個案例，不當成零成交繼續算報酬。
- 上市上櫃逐筆單位依官方文件張轉股；與當日日線高低價及總股數比對，不容許超出。當前市場標籤與日資料對比仍不能完全證明歷史轉板身分或逐筆完整性，報告保留此限制。
- 共用 FinMind 限流（6000/h，保守有效 5400/h），本研究最多 1500 次新請求、零自動重試、逐股逐日永久快取、同資料跨案例共用；達額度或來源錯誤保留快取後停止。禁止全市場逐日掃描。
- 獨立重算現金、持股、成本及每日淨值；檢查事前股數/預留款、委託與訊號時序、限價、參與量及最後成交時間。完整離線重跑雜湊一致才標示可重現。
