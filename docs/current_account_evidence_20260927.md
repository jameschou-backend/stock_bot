# MCP與工作台的現行帳戶證據一致

問題：工作台已發布完整現金帳戶比較，`get_strategy_evidence`仍只回傳較早的
規則、族群及容量研究。不同資金、持股名額或成交設定的報酬容易被混在一起。

`/workbench/evidence`現新增`preferred_comparison=current_accounts`及
`current_accounts`。MCP沿用原本的本機HTTP介面，不變更工具參數、不下載資料。
新欄位使用工作台同一個報告載入器，檢查發布雜湊、兩輪重現證明、封存摘要及
5部位／整張／100萬元／同成本基準等範圍。每列保留正常、全部壓力、完成數、
8情境勝出數及可追到帳戶的雜湊。缺報告、內容變動或範圍不符時明確不可用，
不拿舊研究當作替代績效。舊欄位保留，另外註明其研究口徑可能不同。

實際MCP驗收已回傳出場機制、波動配置、候補有效期、支撐配置、收斂突破五組。
原現金帳戶正常淨報酬415.79%、全部壓力114.08%；同成本0050分別233.87%、
230.99%。期間2022-01-03至2026-09-09，閒錢現金，全部維持`live_qualified=false`。
情境勝出比例不是未來勝率。這個介面檢查發布證明與摘要，沒有在每次讀取時
重新雜湊全部歷史來源；完整重播仍會做全部來源驗證。

本機五組摘要讀取0.0198秒，約21KB。新增6項測試涵蓋缺報告、損壞內容、
錯誤帳戶範圍、未完成情境及實際HTTP路由回應。完整make test共3,567項通過、
30個既有警告、72.69秒；make pipeline及make api後四端點驗收通過，MCP實際
呼叫也核對新版欄位。Pipeline仍保留TWSE來源暫停，不能把成功退出解讀成
資料來源已恢復；本次驗收另有FinMind用量，讀取證據本身不消耗FinMind。

未更動策略規則、歷史帳本、排程或實際交易。加碼可行性探查仍是獨立的未完成
研究，沒有冒充正式加碼報酬發布。
