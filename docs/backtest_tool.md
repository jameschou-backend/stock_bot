# 可續跑的帳戶回測工具

此入口固定使用已封存的現金策略：本金 100 萬元、5 個個股名額、閒置資金保留現金、2022-01-03 至 2026-09-09、458 個既有候選。0050 是獨立比較帳戶。這次整理工具，不增加策略或調參，不將研究區間宣稱為未見驗證。

```bash
python scripts/run_verified_backtest.py --preflight-only
python scripts/run_verified_backtest.py
python scripts/run_verified_backtest.py --policy mixed --stress combined
python scripts/run_verified_backtest.py --fresh
python scripts/run_verified_backtest.py --mode strict --preflight-only
```

`--output` 可用相對或絕對路徑，限定專案 `.cache/backtest-tool` 下、不可變 `runs` 目錄外的 JSON，或合法的工作台結果路徑。預設報告 `.cache/backtest-tool/latest.json`；工作台每個背景工作另存報告。UI 位於「策略驗證」頁上方。整個工具不連網、不更新 DB、不訓練模型、不下單，也不啟用排程。

## 時間、成交與帳務

- 驗證訊號交易日及下一交易日進場、族群與趨勢資料日期、完整 20 日流動性及其可得日期；沿用已通過截斷／變造未來資料測試的訊號版本。這不補足歷史公司身分或財報修訂版本。
- 日資料模式沿用凍結的成交量、漲跌停、最低手續費、交易稅、滑價、開盤前資金限制及股利／配股帳務。它是估算，不證明盤中指定買點與排隊成交。
- 完整案例必須覆蓋每個指定交易日；重新從現金、股數、費用與應收帳本核對淨值。所有買入必須有更早的訊號日期。策略與 0050 必須有相同日曆、本金、成本及成交政策才計算超額報酬。
- 股票股利缺少必要事實就中止；整張政策留下的零股仍列資產並占名額。中止案例不得顯示全期報酬，已完成日期可供診斷但不能代替全期結果。
- 逐筆模式目前提供證據預檢：固定版本缺完整且已驗證的普通盤／所需零股時序，回傳「缺資料中止」。不把日資料模式改名為逐筆成交驗證成功。

## 可重現與效能

一次來源檢查直接核對完整遞迴依賴清單，避免反覆呼叫每層舊研究的 inventory。每次在起始和報告發佈前讀取實際檔案內容雜湊；不以修改時間或檔案大小代替驗證。即使預檢或全部重用快取，也確認期間來源未變。

每案使用資料、程式、執行環境及設定識別，存入 `.cache/backtest-tool/runs/<digest>`。逐案完成便原子保存結果與收據；中斷後沿用完整且雜湊一致的案例。快取不是新的獨立實驗。`--fresh` 強制重算並逐欄比較封存結果；禁止覆蓋不同的歷史結果。整張案例必須先通過四個原有混合成交對照。

報告有 `ready`（僅預檢）、`completed_daily`（完整日資料估算）、`blocked`（中止）狀態。整批只要任一案例中止，狀態即為 blocked，其他完整案例仍可查看與下載。完整日資料批次標為 exploratory，永遠不自動取得實盤資格。

每個完整案例匯出所有買賣和每日資產 CSV，以及完整原始帳戶 JSON。報告附來源識別、結果與匯出檔雜湊、實際重算／重用數與秒數；工作台讀取時再次核對所展示檔案。

新增其他策略、不同期間或本金應建立新的已審核 recipe 與其資料識別，不能只改標題沿用這份封存資料。
