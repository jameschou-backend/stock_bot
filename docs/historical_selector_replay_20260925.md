# 歷史股票池修正、完整帳戶重播與驗收

本輪修正的是「歷史資料已補回，卻沒有真正進入選股及帳戶」的問題。另發現原行情整理以目前市場的上市日截斷資料，漏掉部分上櫃轉上市股票的前段歷史，已在新的研究資料版本修復。原始封存版本保持不變，方便逐項對照。

期間固定為 2022-01-03～2026-09-09，本金 100 萬元複利再投入，最多五檔，閒錢保留現金，0050 為獨立基準。這輪只測整張成交，不代表允許零股的實際策略已完成驗證。沒有啟動排程或下單。

## 實際修復

- 按交易日套用已證實的普通股身分、上市／下市、市場轉換及停復牌區間。缺行情不會讓應有股票數縮小，已知不具交易資格的日期不會成交。
- 加入原股票池遺漏的 49 檔；原始 35,664 筆行情中，641 筆異常列隔離，不用填價或零成交補洞。股票池從 1,974 檔擴充為 2,023 檔，仍不是完整歷史全市場。
- 恢復 9 檔有已核對轉板證據的歷史前段，共 6,133 筆：1752、3652、4736、5236、5306、6446、6472、6589、8476。
- 5236 舊還原價檢查欄整欄缺值，明確使用另行抓取的 FinMind 還原價；其他八檔只用常數單位對齊接回前段，不改舊後段行情，不把同一來源複製為第二來源。
- 新入選路徑所需的股利與漲跌停快照按固定候選清單增量補齊。準備資料共保留 107 次 FinMind 請求計數（49 次補股還原價、9 次轉板還原價、49 次累計成交資料）；零自動重試、共用 5,400 次／小時上限。此數不含另外執行的日常 pipeline。
- 完整重算四組選股器與十個帳戶，保存每日資產、持股、全部成交及未成交原因。缺必要結算或身分證據會阻擋帳戶，不假造退出，也不把未完成結果顯示成零報酬。

規則依 [計算前固定的規格](prereg_historical_selector_replay_20260925.md)，本輪沒有再搜尋策略參數。固定前 20 日成交金額排序、既有領先訊號及大盤趨勢條件、訊號至少隔日執行、12% 收盤停損與 63 日持有期限；帳戶沿用既有公司行動與資金／名額預留引擎。

## 驗證與效能

- `AI_ASSIST_ENABLED=0 make test`：3,259 項通過，30 項既有警告。新增涵蓋轉板前段保留、不覆寫原價、單位換算不變性、缺錨點阻擋，以及 UI 拒絕錯誤來源／未完成證據／不實收益。
- 完整十帳戶首次執行 77.014 秒；第二次重播 114.531 秒（同時執行防偷看稽核）。兩次均離線，無模型重訓、無網路補資料、無資料庫寫入。數值是本機實測，不是效能承諾。
- 兩次的四組選股訊號、準備矩陣及十個帳戶逐欄一致；原股票池的正常／壓力帳戶也重現原本修正公司行動後的基線。
- 三組修正選股器固定 114 個月界／樣本端點，各做未來截斷及擾動，總共 684 項，全部通過；耗時 1,004.194 秒（約 16.7 分鐘，屬一次性稽核）。擾動包含未來價量與未來交易資格；只比較截止日前的選股決策。完整證據封存在發布檔指向的驗證報告。
- UI 必須核對來源 SHA、帳戶自行重算摘要、十案完整性及同一份 manifest 的兩種驗證，才會顯示報酬。驗證快取綁定各來源檔的身分與修改狀態，來源變動即重驗；明細按需載入，避免每個操作重讀全部歷史資料。本機結果載入首次完整核對 16.109 秒、來源未變的再次載入 1.545 秒（不含瀏覽器繪圖時間）。
- 日常 `make pipeline` 已執行；TWSE origin 原先受限制的部分使用本機明確拒絕的驗收保護，沒有繞過限制或向該來源重試。流程返回成功不代表全部 ingest 都成功。另以 `make pipeline-build` 驗證現有資料可重跑，API 的 `/health`、`/picks`、`/models`、`/jobs?limit=10` 均以 curl 驗證 HTTP 200。

防偷看測試證明固定快照上的程式因果性，不代表原始資料的修訂版本在歷史當時已可取得；後者需要發布時間與原始版本檔案。

## 仍不能宣稱完成的外部證據

- 3717、5292 的上市日期差異沒有與上述九檔相同的轉板來源證明，保留為未確認，不能用現在的 ISIN 日期猜歷史市場。
- 原有歷史零股缺口、行情來源衝突、受限制的官方文件，以及全市場完整歷史名冊／發布時點，這輪並未取得完整證據。整張日資料回測不能替代歷史零股逐筆成交。
- 日成交量只是成交容量上限，不能證明特定盤中時間、特定限價或排隊位置有足夠可成交量。

因此 `strict_data_ready=false`、`live_qualified=false`、`unseen_validation=false`，維持研究用途。不要將本輪完成的程式修復解讀為所有外部歷史資料已完整，或已核准投入實盤。

## 操作與重現

本機介面 `http://127.0.0.1:8502/` → 側欄「新版回測」，直接載入本輪結果，避免一併載入全部較早的研究。原工作台「策略驗證」上方也有相同面板。切換正常／壓力情境，預設查看本次修正全部套用帳戶；勾選明細後可下載每日資產、全部買賣、委託與未成交、每日持股。較早的報告收在歷史紀錄區，避免與最新版混用。

發布索引：`artifacts/forward_simulation/historical_selector_replay_20260925.json` 及 SHA sidecar。完整原始資料與帳戶位於索引所綁定的本機 `.cache`，沒有假裝把未納入 Git 的大檔發布到遠端；換電腦需取得同版本來源後才能驗證。

```bash
# 新目錄，不覆寫已封存的執行。
python scripts/research_historical_selector_replay.py \
  --output .cache/historical-selector-replay-20260925/new-offline-run \
  --execution-inputs .cache/historical-selector-execution-v2-20260925

python scripts/verify_historical_selector_replay.py \
  --left .cache/historical-selector-replay-20260925/final-v7 \
  --right .cache/historical-selector-replay-20260925/new-offline-run \
  --output .cache/historical-selector-replay-20260925/new-offline-verification.json
```

準備程序保留累計請求計數，重跑先驗證既有快照；缺證據時明確報錯，不偷偷連網填補回測。
