# 賣出補位與未成交占位拆解（2026-09-24）

本輪找到主要敏感處：日模型允許舊部位完全退出後，同一天換入下一檔。固定其他條件，禁止這種補位對壓力績效的影響，遠大於禁止未成交買單釋放名額。本輪沒有證明當天補位不可能，也沒有證明舊高報酬已可實現；需要賣出、撤單及新買單的實際回報時間。

## 比較方式

2022-01-03～2026-09-09，共1136市場日；100萬元複利、458候選、成交金額排序、最多3檔、閒錢現金。12%收盤停損及63市場日期限不變；正常每邊45bps滑價，合併壓力每邊90bps、進出場再延一市場日、零股限最後揭示對手量。佣金0.1425%最低20元，個股賣出稅0.3%、ETF0.1%；同一資金背景的0050公平配對。

R開啟：開盤前持股占名額到收盤，即使當天全部賣完。F開啟：正股數買單真正送入成交引擎就占名額到收盤，即使完全沒成交。部分成交、部分退出、未交付股票權利都依原帳本持續占位。名額或資金檢查已拒絕而未進成交引擎的買單不另占位。

重要：R擋住當天買單後，該訊號依原單日進場規則失效，沒有新增隔日排隊重試。因此這是禁止當天補位的政策比較，不能解讀成同一批股票單純延後一天買。所有其他進出場規則不變。規格見[事前文件](prereg_slot_reuse_20260924.md)。

## 首個差異能追到哪裡

在原資金背景的壓力帳戶中：

1. R的首次資產差異為2023-03-06。舊模型把2606剩餘50股零股賣完，再買8171共5029股；R仍把2606算成當天占位，因此8171被擋住。此後總共少了26個原部位、增加26個不同部位，整段報酬差不等於8171單筆獲利。
2. F的首次資產差異為2026-05-22。日模型先把2455判為漲停零成交，接著買2891共20689股；F保留2455名額，因此2891被擋住。少1個原部位、增加3個不同部位；沒有證據顯示當時可在買2891前確認2455已撤單。

另一資金背景的R也在2023-03-06首次出現差異，但2606剩餘49股，後續部位變化數不同。F單獨在該背景沒有改變帳戶；當R已開啟後，F的首次影響則是2026-07-15擋住2377，不應混成同一事件。

補充的事後描述統計：原資金背景R單獨開啟擋住19筆新買入嘗試，其中10筆相關名額釋放只涉及零股賣單；另一資金背景為18筆，其中8筆只涉及零股。這說明小額零股尾數可能影響整個後續組合，不代表可以直接放寬名額或假設零股一定成交。

## 對實際執行的意義

目前應優先驗證「賣出確認後才補位」，以及「撤單成功／委託終結後才釋放未成交名額」。不能拿日末已知的漲停、零成交或最後對手量，假設在當天更早就知道結果。日模型中的trade sequence只是計算順序，並非交易所時間戳。若要改成允許少量零股尾數另行管理，須先固定資產占比、剩餘風險與最大股票數規則，再獨立比較；本輪沒有偷偷放寬這些條件。

研究用過的歷史不能重新當未見測試集。完整歷史市場身分、公告修訂及零股撮合序列等限制延續；live_qualified=false、unseen_validation=false，沒有宣稱可以穩定贏0050或替換正式策略。
