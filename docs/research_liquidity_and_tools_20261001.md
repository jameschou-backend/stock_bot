# 流動性條件實測，以及兩篇 AI 投資工具貼文核對

研究日期：2026-10-01。**成交值中位數條件有小幅改善，但不足以把選股變成高勝率；新增市場廣度條件反而較差。兩篇貼文提供工具與操作流程的參考，沒有提供能讓本策略獲利的新增證據。**

本次新增五組固定描述比較、兩次離線重算，另核對既有法人、籌碼與題材研究，以及貼文、官方產品說明和 AI-Trader 原始碼。沒有更換正式策略、安裝外部套件、啟動排程或下單。

## 新比較的範圍

依 [事前規格](prereg_liquidity_screen_20261001.md)，沿用 2024 年起全部候選訊號，行情封存到 **2026-09-09**。只比較進場索引 +63 已有行情可觀察的成熟母體：14,673 筆，其中 14,489 筆結果已知、184 筆待核對。最後成熟進場日為 2026-06-10。

買賣規則保持次日普通交易高低中點代理、原比例稅費滑價、收盤跌 12%／63 日到期。每筆獨立假設成交、不受現金或名額限制，**不是重跑原資金帳戶**，沒有新帳戶報酬或最大回撤。過濾條件以訊號當時可得資料判斷；之後結果僅作評估。

本次仍用原始收盤 × 成交股數估計成交值，沒有把它改稱實際成交金額。原封存 quotes 沒有交易所成交金額欄位；FinMind 雖有 `Trading_money`，不能在本次未取得並核對時假裝已使用。

### 流動性中位數：小幅改善，有取捨

中位數條件排除的 2,858 個已知結果，勝率 **30.30%**，平均單筆仍為 **+1.48%**；其中有 1,992 個虧損，也有 866 個獲利，含 63 個翻倍。它有助於減少低勝率訊號，卻不是把一批「必虧股」刪掉。

按訊號年度分開，原始／中位數條件的勝率與平均：

|訊號年度|原勝率|中位數條件勝率|原平均單筆|中位數條件平均單筆|
|---|---:|---:|---:|---:|
|2024|32.93%|33.76%|-0.38%|-0.36%|
|2025|36.07%|37.36%|+5.44%|+6.03%|
|2026 成熟訊號|35.18%|36.03%|+9.58%|+10.37%|

方向三段相同，但 2024 平均仍負，不能稱為所有行情都有效。兩條流動性條件一起加，只比中位數少兩個已知訊號，幾乎沒有新的區分力，不值得因結果稍高就偏好更複雜的規則。

若重點是盡量保留飆股，較溫和的「訊號前 20 日平均」只漏掉 **13／386** 個翻倍結果，但勝率增益也只有約 **0.21 個百分點**。本輪不按這些已知結果再調高／調低門檻。

### 市場廣度：這個固定條件不支持加入

原始訊號已要求 0050 位於 120 日均線上；此組再要求資料池內過半個股在各自月線上，且比例較五日前未減少。它刪掉 55.04% 的虧損，卻刪掉 **65.03% 的翻倍訊號**，留下者勝率及平均均下降。

2024 的小幅改善沒有延續至 2025、2026；同季度／月線乖離分組後方向仍負。不能由此推論「大盤越弱越好」，也不能否定其他市場風險控制；本輪只否定把這個額外條件直接列為目前訊號的必要門檻。

## 與既有研究交叉比對

以下是本次重新閱讀的既有封存結論，不是今天新跑的績效，也不是最新資料庫覆蓋狀態。不同母體與成交口徑不可直接排名。

|方向|既有證據|對本次設計的意義|
|---|---|---|

|題材有營運證據|[題材策略](research_theme_catalyst_20260927.md)：衛星特定增補名單一般帳戶 +35.71%，同期間 0050 +175.43%，現金比率高、候選少；對照部分未完成。|公司受惠證據不足、披露未知與信號過少須分開；不能說已證明題材條件有效或無效。|

## 效能、重現與限制

- 兩次研究本體各約 3 秒、0 次市場資料請求；不含完整測試與每日管線驗收，也不是完整資金回測耗時。重用封存資料，不重新抓全市場或訓練模型。
- 兩次 `report.json` 與 `signals.parquet` 逐位元組一致。五組固定比較各執行兩次，全部十個試次保存，沒有只留較好的條件。
- 新增四個針對性測試，驗證單日爆量不冒充持續流動性、缺值不壓縮交易日、排除 0050／不合格身分、截斷與改寫未來不改過去。另在真實資料 2025-12-31 截斷重算所有特徵，完全一致。
- 完整 `make test`：4,234 項通過，保留 36 個既有警告；每日管線成功；本機四個必要 API 端點均 HTTP 200、有效 JSON。見 [驗收紀錄](../artifacts/forward_simulation/liquidity_screen_20261001/acceptance.json)。
- [完整結果與來源雜湊](../artifacts/forward_simulation/liquidity_screen_20261001/report.json)、[逐筆條件及原結果](../artifacts/forward_simulation/liquidity_screen_20261001/signals.parquet)、[全部試次](../artifacts/forward_simulation/liquidity_screen_20261001/trials.json)。
- 研究期間都已被看過；中點成交是理想代理，同股與時段結果相關，未知資料未補值。`portfolio_backtest=false`、`unseen_validation=false`、`live_qualified=false`。

重現時指定新目錄：`python scripts/research_liquidity_screen.py --output .cache/liquidity-screen-reproduce`。外部貼文與產品會更新，上述判斷限本次實際讀到的文字及所列程式版本。
