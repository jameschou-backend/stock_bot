# 原勝出版本的規則差異配對 — 2026-09-14

先重現五項研究的 capacity_control / capacity_combined 與 benchmark_control / benchmark_combined，帳戶必須逐欄相同。每組再只改「開盤前固定現金、股數及名額」的決策流程，合计八次完整帳戶。

沿用原候選、成交金額排序、12%／63日出場、100萬元複利、單股股數精度、零股日資料成交模型、成本及各自成交延遲。此次不加入限價、不改整張、不讓零股長期卡住名額。一般及合併壓力沿用舊定義，不使用上次逐筆版不同的壓力設定。

唯一改動的流程：當日開盤前，以前日現金及持股占位依原排序逐筆預留目標預算，每筆仍按原公式計算股數。各張買單實際扣款不得超過其預留額；整股、零股共享同一預留額。當日賣款、股利支付及未成交額不分配給後面的新買單。0050 基準同樣只用前日現金，日內最多一筆分渠道委託。

此流程包含現金和名額的共同事前承諾，不宣稱各自的個別效果；不修改原封存程式。新增封存 plans，不改原 account 格式。中性模式必須完全重現舊帳戶。

此為**日資料成交假設下的配對診斷**，不是逐筆驗證、不是新樣本外，也不因勝過0050就取得實戰資格。舊策略未記錄事前限價和精確委託時間，不能把隔日收盤价当成前日已知限價。缺歷史零股盤別與成交序列時，嚴格原規則逐筆驗證狀態保持未完成，報酬欄留空。

只讀原快取及隔離副本；先零網路執行。缺資料即停止該情境並記錄具體缺件，不填零成交，也不把不完整淨值當結果。若準備所需資料，最多新增100次FinMind／100次官方HTTP、共用既有額度；不自動重試、不覆寫旧快取、不重新訓練。

同時記錄舊帳戶當日流入依赖、盤別成交筆數及所需日期。已成交帳本缺件清單只代表舊路徑的最低需求，不代表改變成交後的新路徑只需這些資料。
