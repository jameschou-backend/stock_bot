## 終止掛牌與轉板分開

來源為 [TWSE 終止上市公司](https://openapi.twse.com.tw/v1/company/suspendListingCsvAndHtml)、[TPEx 終止上櫃公司](https://www.tpex.org.tw/zh-tw/mainboard/listed/delisted.html)、[TWSE 最近上市公司](https://www.twse.com.tw/company/newlisting?response=html)、[TPEx 最近上櫃公司](https://app.tpex.org.tw/HTML/RecentlyListing/LatestList.html)。保存 API 原始回應、參數與取得時間，驗證逐年回應與分頁列數；上市日期採正式開始買賣日期，不採申請日期。

- 2022–2026/9/9：25 筆 TWSE 終止上市、35 筆 TPEx 終止上櫃。
- TPEx 的 9 檔終止後仍有行情，全部找到同日 TWSE 掛牌且備註「櫃轉市」，例如 1752 南光在 2022/1/19。
- TWSE 的 23 檔終止後仍有行情，其中 6423 億而得在 2026/1/22 同日轉上櫃，兩市場日期相符。
- 餘下 22 檔仍需釐清價格時間衝突、代碼沿用與其他市場身分，沒有刪行情或自動加入歷史選股母體。
- 25 筆 TWSE 終止記錄中，有 19 筆另外找回先前上市開始日期；原 DB 主檔尚未覆寫。TPEx 最近掛牌資料只涵蓋目前提供的 22 筆，不能冒充完整歷史起始名冊。

上一輪 TWSE 的 22 檔統計用了 DB 中的終止日期；6423 的 DB 終止日期為空，沒有被算入。本輪改以已保存官方終止日期比對後為 23 檔，再以另一市場來源確認 6423 是轉板。這是查核口徑補正，不表示新增一檔壞價格。

## 重現與效能

程式：`scripts/research_adjustment_continuation.py`。原始資料與 SELECT 快照在 `.cache/readiness-continuation-20260914/`；正式本輪研究輸出在 `audit-v3/`，獨立重現在 `audit-verified/`。`audit-v1/`、`audit-v2/` 保留較早稽核階段，不作最新結論。

```sh
python scripts/research_adjustment_continuation.py \
  --output .cache/readiness-continuation-20260914/audit-next
```

輸出位置必須不存在，避免覆寫既有證據。若缺 DB 快照，`--prepare-db` 只執行有界 SELECT；缺官方來源則明確失敗，本程式沒有網路抓取入口。來源、解析程式與輸出均保存 SHA256，程式執行期間變更來源會阻擋。

離線重現 11.04 秒，輸出 Parquet／JSON 的 SHA256 全部一致，0 次網路、0 次 DB 寫入。蒐集新名冊及公告時，另有 15 次有界官方 HTTP 嘗試（含 1 次參數錯誤、1 次 TLS 串流失敗），未關閉 TLS；網頁檢索與驗收 pipeline 另計。研究階段沒有 FinMind 資料請求。未成功來源未混入結果。

工作台新增「歷史資料修補進度」，摘要會核對本機原報告 SHA256；來源報告缺失或變更時明確顯示不能核對，不把研究完成當成取得實盤資格。

驗收：`make test` 2,554 passed、29 warnings，71.04 秒；`make pipeline` 在 `INGEST_PRICES_SOURCE=finmind SPONSOR_INGEST=off` 下成功。既有 `make api` 服務的 `/health` 為 ok，`/picks`、`/models`、`/jobs?limit=10` 回傳有效 JSON 列表。瀏覽器實際顯示 302 區間、2,027 檔、457／458 比較、10 筆轉板與 22 檔待核對；封存來源守門指紋仍通過。日誌為本輪快取目錄下 `make-test.log`、`pipeline.log`、`targeted-tests.log`、`reproduce.log`。新增警告是 Pandas 空欄 concat 的未來行為提示，沒有測試失敗。
