# 同一個股策略：三檔與五檔比較（2026-09-29）

固定原有選股、排序、進出場和成交假設，只將持股名額由三檔增加為五檔，結果較差。五檔全期 +132.52%，最大回撤 -52.80%；大甲四次訊號仍無成交。這輪沒有調整正式交易設定。

## 同口徑績效

五檔相較三檔多出 86 個買入事件，但平均股票市值占淨值只從 67.98% 增至 70.57%；因名額滿拒絕的訊號由 36,015 減為 35,218。這些是重複出現的訊號筆數，不是不同股票數。資金路徑與後續入選股票都改變，不能理解為三檔原持股加上固定兩檔。

三檔總成本 1,565,149 元、五檔 798,251 元。五檔成交較多但資產規模較小，不能用絕對成本較低判斷效率較好。

這個結果不支持直接把三檔改成五檔。單純增加名額仍會滿倉，且沒有候補或換股規則；也揭露三檔歷史高報酬對少數交易與進場順序敏感。

## 固定規則與資料補件

- 使用同一份 37,993 筆個股訊號及原排序；五檔每次入場預算約為當時淨值 1/5，仍受現金及成交量限制。沿用殘餘小部位釋放名額規則，因此活動名額不等於所有殘股名稱總數。
- T 收盤訊號、T+1 執行；維持 12% 入場基準收盤停損、63 交易日持有上限，觸發後隔日賣出。
- 維持各成交渠道當日最高與最低價中點代理、每邊 0.45% 滑價、佣金 0.1425% 且每渠道最低 20 元、股票賣出稅 0.3%，整股與歷史零股各自驗證容量。不是隔日開盤價回測，中點無法事先知道或保證成交。
- 全期五檔帳戶 1,867 個交易日，兩次獨立離線重播完整一致；現金、股數、公司行動、交易成本、容量與名額資源稽核通過。原三檔與 0050 帳戶保持凍結並核對雜湊；沒有重新改選勝出參數。
- 新增來源嘗試 240 次：140 FinMind、91 官方零股、9 公告（含失敗）；均在預算 300 次內，FinMind 使用既有 5,400/小時限流。有的來源可命中共用快取，嘗試數不等於付費 HTTP 次數。
- 補入茂迪 2020 減資、宏觀與大樹 2021 配股及潤泰全 2021 配股條款。茂迪官方停牌日與減資倍率已核對；畸零按面額折現 7 元支付日未證實，期末仍為不可再投資應收款。
- 其他配股畸零現金仍沿用三檔版的配股交付日假設。潤泰全交付日使用公司預告 2021/11/22，歷史資料相符，但沒有找到獨立最終上市通知。這些未驗證項目明列於公司行動條款，不能稱全部實務核帳完成。
- 全部日期已研究過；新增一個名額假說，準備中斷也保留。兩次重播只是可重現性，並非未見資料驗證。歷史母體完整性、實際成交與畸零現金支付日仍未完全驗證，`live_qualified=false`。
- 最終 `make test`：4191 passed、36 warnings；`make pipeline` 成功，`make api` 後兩個埠的四個端點均通過 curl JSON 驗收，臨時 8001 API 已停止。第一次測試因沙箱不允許本機 MySQL 連線失敗，使用連線權限重跑通過。
