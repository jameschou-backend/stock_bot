control3、control5 必須重現已凍結的 liquid_universe 帳戶；0050 沿用凍結帳戶。

整零股容量、開盤現金／名額鎖定與殘股限制都保持不變。

- stagnant：持有年齡至少20個交易日（執行日索引減入場日索引），前一日可得的
  20日漲幅小於3%，且20日報酬落後0050，提出全部退出。
- stronger：活動名額已滿，沒有原停損／期限退出正在等待；持有至少10日，
  20日報酬落後或持平0050；當日待執行的新訊號相對20日報酬至少高出10個百分點，
  才退出其中相對報酬最弱一檔。新候選取原排序，未持有者。
- 已觸發停損／期限的持股不覆寫原因；退出訊號鎖定直到賣清。
- 不追加候補、不改買入排序、不因釋位強制成交新候選。當日賣出仍不能重用
  當日名額或資金；stronger在此是「強訊號釋位」，不是保證當天換入。
  此隔離有意保持買進訊號完全相同，用來識別退出規則本身的效果。
