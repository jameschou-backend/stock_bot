# 情境出場帳本：已知畸零股毛額與未核實付款日

股票股利的不足一股權利，和交易所1～999股零股不同。本輪新增持有的富邦金2881，2024年發行人通知已明示未併湊的不足一股按面額折現至元；但未核實集保實收淨額及該筆現金付款日。不能套用其他公司「畸零款抵劃撥費」的零元條款，也不能把整數新股交付日當成現金付款日。

這是依新公司行動證據擴充帳務表示，沒有更改出場條件、進場候選、成本或門檻；不修改原已封存的帳本引擎。處理如下：

- 除權日按原有持股及精確配股率鎖定權利，整數新股依已核實的2024-10-15交付。
- 畸零股現金毛額依公告計為 `floor(不足一股的部分 × NT$10)`；金額在除權日即可由既有持股推得，不用未來股價。
- 毛額另列現金應收，付款日保持未核實，整數股交付當天不提前釋放現金。持股售完也不刪除這筆應收。期末資產包含此項估值，不能當成已領取或已核實淨額；未核實集保／郵匯費另列限制。
- 已明示畸零款抵集保費的4123、1815、2890、2885等公司仍沿用各自核實條款，不套面額現金收入。

新 `FractionalCashActions` 將畸零毛額拆成獨立權利，利用原引擎已支援的「付款日未知現金應收」入帳。相容的journal kind為 `cash_dividend`，但公司行動明標 `distribution_type=fractional_share_cash`、實際毛額、面額與付款核實狀態；其 `cash_per_share` 只是讓既有帳目公式對齊的有效率，不是發行人公告的每原股現金股利。以 `action_id` 末尾 `-fractional-cash` 可追溯原公司行動與期末應收，不能重複將它當成普通股現金股利。

合成測試核對取整、除權資格、已知與未知付款日、整股交付不重複付款、資料不互相污染及原控制組完全相同。正式比較還須逐筆現金／股數／NAV稽核與全部離線重現。報告的來源雜湊驗證只保證使用的資料版本一致，不表示上述未核實費用或付款時間已成為已知事實。

證據及範圍見 [2881查證](exit_corporate_sources_2881_20260910.md)。

## 同輪其他未完整核實的權利

2736 若符合相同公告毛額條款，套用相同獨立應收表示；2880 的面額折現僅作估值假設，尚未取得逐戶實收公式及付款日。報表逐案列未核實金額，不把小額推定描述為已核實收入。華南金普通現金股利使用公告的整元底數，缺少全體戶號及尾數順序，未加計最多可能多分的一元。

2880 的 2024-08-30 發行物是已上市的新股權利證書，2024-09-30 才換成普通股。本帳戶不模擬證書交易，依已確認的普通股交付日期加入可售持股；期間的待轉普通股權利仍以普通股收盤價代理估值。這是明示的資產交易範圍限制，並非宣稱 8/30 沒有可交易證券。公司行動及各案摘要保留實際證書發放日、普通股可用日和估值基礎。

這項限制除影響權利價差，也可能因待轉股權持續占用名額，改變後續候選能否買入。估值亦可能影響每日 NAV 與預算，所以其收益不能宣稱為實際帳戶的保守下限；同規則套七案也不代表偏差消失。比較表必須逐案標示是否持有這筆權利。日期證據見 [2880 查證](exit_corporate_sources_2880_20260910.md)。本補充只因新增持股揭露帳務範圍，沒有依各案收益調整出場參數。
