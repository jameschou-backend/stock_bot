# 全部選股訊號為何多數虧損

結論：虧損比例確實偏高。校正近期訊號尚未觀察滿期的問題後，可判定的 14,489 筆中，9,501 筆虧損，占 65.57%。同股不重疊時勝率仍只有 34.66%，並非單純被重複訊號拉低。主要問題同時包含買後沒有續漲、上漲後回吐，以及市場轉弱時集中失敗；不能只歸因於賣太晚。

本次僅分析 [既有全部訊號報告](research_independent_signals_20261001.md)，沒有調參、重跑新策略或更改正式交易規則。分析對象是突破、出量、相對強勢的 `liquid_universe` 全部候選訊號，沿用收盤跌 12% 觸發隔日賣出／持有索引 +63 到期出場；不是其他已研究出場版本，也不是原三檔帳戶實際成交清單。

## 先校正近期樣本偏差

行情固定截至 **2026-09-09**，不是截至本報告日期。原報告包含 2024-01-02～2026-09-08 的全部訊號，已出場勝率 32.94% 在其分母下是正確的，但不能用來公平比較近期買點：虧損可以提早停損，贏家則通常要等滿 63 個交易日才出場。

本次先依「進場日起，資料是否已覆蓋最長持有期限」決定成熟樣本，不依盈虧選樣。最後符合的進場日為 **2026-06-10**。

|樣本|全部訊號|可判定已出場|獲利|虧損|尚未出場|資料待核對|已出場勝率|
|---|---:|---:|---:|---:|---:|---:|---:|
|完整觀察期|14,673|14,489|4,988|9,501|0|184|34.43%|
|觀察期尚未完整|1,207|652|0|652|547|8|0.00%|

第二列的 0% 不能解讀成近期訊號全部失敗；547 筆尚未結束，可能改變結果。以下主要比較均使用第一列的 14,489 筆已知結果。184 筆未知結果保留，未補值、未假設成功或失敗；即使全部判為成功，成熟母體勝率亦僅約 35.25%。

重複訊號檢查：

|計數方式，均限制完整觀察期|已知結果|資料待核對|勝率|平均單筆扣費報酬|
|---|---:|---:|---:|---:|
|全部訊號|14,489|184|34.43%|+3.93%|
|每股依時間只取 2024 年起第一筆|1,182|19|37.99%|+3.86%|
|同股上一筆退出後才接受新訊號|3,713|56|34.66%|+3.56%|

第三列是按時間抽取原結果，非重新模擬資金；未知或未結束持倉阻擋後續同股訊號，避免猜測可再進場時間。不同股票仍共享行情，同股不同時期也不保證獨立，不能把筆數當成獨立樣本數。

## 1. 超過一半虧損訊號，買進後沒有明顯續漲

以下以最終虧損的 **9,501 筆**為分母，依持有期最高還原收盤相對買入調整中點的漲幅分類：

|持有期最高收盤漲幅|虧損訊號數|占全部虧損|
|---|---:|---:|
|低於 0%|2,165|22.79%|
|0%～未滿 5%|2,928|30.82%|
|5%～未滿 10%|1,589|16.72%|
|10%～未滿 20%|1,586|16.69%|
|至少 20%|1,233|12.98%|

**5,093 筆（53.61%）未達收盤 +5%**，是值得研究的「進場後沒有續航」問題；**2,819 筆（29.67%）曾達 +10%**，則有獲利回吐的問題。這些是事後分類，不代表進場時已能知道哪筆屬於哪一類。

最高收盤統計不含退出當日收盤，也不等於盤中最高成交價。未達收盤 +5% 不能寫成盤中從未漲過 5%；曾達 +20% 也不代表可事先在最高點全部賣出。

## 2. 越偏離月線，勝率越低；直接刪掉卻會傷到飆股

使用訊號當日已可得的還原收盤及 20 日均線，固定以 10%、20% 分組。沒有搜尋最漂亮的門檻。

|訊號收盤高於 20 日均線幅度|訊號數|勝率|平均單筆扣費報酬|其中獲利者平均報酬|扣費翻倍訊號數|
|---|---:|---:|---:|---:|---:|
|未滿 10%|2,875|41.29%|+3.72%|+26.57%|36|
|10%～未滿 20%|6,191|36.15%|+4.18%|+35.90%|139|
|至少 20%|5,423|28.82%|+3.76%|+49.52%|211|

最高乖離組勝率低，成功時漲幅也大。刪除此組會刪掉 **211／386（54.66%）個扣費翻倍的訊號結果**，不是 211 檔不同股票。三組平均報酬並未隨勝率一起單調增加。2024、2025、2026 各自比較時，最高乖離組勝率均最低，但平均報酬高低的順序會改變。

因此可確認「過度延伸與較多失敗相關」，尚不能推出「限制乖離即可改善帳戶報酬」。這是需要兼顧失敗成本和保留大贏家的取捨。

## 3. 爆量也不是越大越好

量比為訊號日成交量／前 20 個交易日平均量，皆為原選股保存的當時特徵。

|量比|訊號數|勝率|平均單筆扣費報酬|
|---|---:|---:|---:|
|1.5～未滿 2 倍|3,462|36.63%|+5.00%|
|2～未滿 3 倍|4,319|35.29%|+3.68%|
|3～未滿 5 倍|3,730|33.49%|+4.71%|
|至少 5 倍|2,978|31.80%|+2.09%|

本批資料不支持「再提高爆量門檻就會提高勝率」。這些單變量分組未控制乖離、市場環境與股票特徵，不能解讀成因果，也不能由量價直接推論大戶出貨、散戶承接或法人是否仍持有。

## 4. 市場環境與持有中風險也是原因

以下按進場訊號月份分組，全部已具備完整觀察期。這是該月訊號之後整段持有的結果，不是帳戶當月報酬。

|訊號月份|已知結果|勝率|平均單筆扣費報酬|
|---|---:|---:|---:|
|2024-07|718|10.72%|-11.84%|
|2025-01|158|2.53%|-15.48%|
|2025-02|521|6.53%|-13.76%|
|2025-06|182|60.99%|+18.55%|
|2025-07|423|57.92%|+16.49%|

同一天集中虧損退出也很明顯：2024-08-06 有 **419 筆／257 檔**；2025-04-08 有 **148 筆／83 檔**。原篩選雖要求入選時 0050 在 120 日均線之上，但本版持有中只處理成本停損或期限，沒有另依市場轉弱出場，也沒有自高點回落的保護。

這支持研究持有期間市場轉弱及集中風險，沒有證明某個特定總經事件造成全部損失，也不能事後用虧損月份標記「當時禁止買」。

## 5. 停損損失比門檻大，且獲利仰賴少數大贏家

- 8,110 筆觸發收盤跌 12% 出場，平均扣費 **-15.30%**。12% 是相對入場日還原收盤的觸發值；實際試算買點是中點，賣在下一交易日，跳空、價格尺度差與成本均會使損失超過 12%。
- 6,379 筆持有到期，4,988 筆獲利、1,391 筆虧損。到期組的高勝率是已通過途中停損篩選的條件結果，不能據此說取消停損更好。
- 9,501 筆虧損中，9,293 筆毛報酬已為負；208 筆原本毛報酬非負、扣成本後轉負。成本使結果更差，但不是多數失敗的主要來源。

成熟、結果已知的訊號中，贏家平均 **+37.95%**、輸家平均 **-13.92%**，全部平均 **+3.93%**，中位數 **-11.24%**。所以低勝率不必然等於負期望，但此處只是歷史、等單位、理想成交下的平均，不能代替實際帳戶結果。

事後將報酬最高的 5% 訊號（725 筆）拿開，剩餘平均為 **-2.26%**。這 725 筆占全部正單位報酬加總的 **46.57%**，說明收益對大贏家敏感。這只是獲利集中度診斷；不能預先知道誰是前 5%，也不是重跑「刪除贏家」策略，更不是實際資金貢獻分解。

## 判讀

目前證據不支持把全部問題歸因於持股名額不夠、同股訊號重複或成本太高。真正需要區分的是：

1. 進場後始終沒有續漲的失敗訊號，能否用當時可得資訊降低損失。
2. 已進入上漲波段後，能否減少回吐並保留重新轉強的參與機會。
3. 大盤／族群持有中轉弱，是否需要降低同時承受的風險。

以上是本次診斷支持的假說，並未宣稱任何新規則已提高績效。單純追求高勝率、提高爆量門檻或砍掉高乖離訊號，均可能刪掉原本需要捕捉的大贏家。

- [完整診斷 JSON](../artifacts/forward_simulation/signal_loss_diagnosis_20261001.json) 含原始檔案與本次診斷程式雜湊、全部年／月分組、量比、乖離、重複訊號及集中度。來源檔封存，不修改原回測。
- 重現：`python scripts/diagnose_signal_losses.py --output .cache/signal-loss-diagnosis-reproduce.json`。輸出路徑必須尚不存在，避免覆蓋先前證據。只重算描述統計，不執行新回測或新增參數試驗。
- 檢查涵蓋原來源雜湊、訊號唯一性、全部分組數量、完整觀察期分類、未知結果保留、加權平均恆等式，以及讀取期間輸入不變。
- 兩次離線診斷輸出逐位元組一致；完整測試 4,230 項通過、36 個既有警告，資料管線成功，四個 API 皆回傳 HTTP 200 及有效 JSON。驗收後關閉本次啟動的 API，沒有修改 `.env` 或重新開啟排程。詳見 [本次驗收紀錄](../artifacts/forward_simulation/signal_loss_diagnosis_20261001_acceptance.json)。
- 固定母體為原始有限歷史股票池，並非完整歷史全市場；交易採次日普通交易高低中點及原比例稅費滑價，沒有逐筆成交、股數捨入、最低手續費、真實零股容量或現金配置限制。
- 同股／同時期結果相關，未宣稱統計顯著；高低中點不是預先可掛單成交價格；最高收盤與獲利集中度均是事後結果。
- 所有期間已被研究，不能當作全新樣本外驗證。平均單筆報酬不能直接與 0050 全期累計報酬比較，不能連乘成本金複利，`live_qualified=false`。
