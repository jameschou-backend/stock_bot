# 指數規則連續資金帳預註冊

本檢查在執行連續期間結果之前固定。不是新參數搜尋，也不是未見資料；保留較早期間 200 日主規則八種情境全數落敗的結論。

- 範圍：2016-01-04 至 2026-09-09，初始本金只在第一天投入 100 萬元，中間不重設、不額外入金。
- 原封不動使用 `IndexExposureReplay` 與 `audit_index`，目標 75% 00631L、其餘現金；0／200／180／220 日四組。200 日仍是主規則，0 日仍是曝險對照。
- 每組八種原成交壓力，32 策略帳戶；同成本 0050 的一般及滑價加倍兩組，共 34 個新帳戶，獨立重跑一次。零網路請求、零 DB 寫入。
- 使用封存早期與近期行情；重疊的原始 OHLCV 必須一致，還原價格基準須符合既有比例核對。年度接點保留前日現金、持股、委託、最高淨值及所有權利。
- 0050 沿用原先整張、開盤前現金預算、收盤代理成交和成本帳；股息除息日產生應收，付款後才可再投資，拆分轉換股數。缺公告時間時不提前折減除息參考價；已知拆分仍調整股數單位。這項保守規劃口徑另外明示，檢查近期重設本金對照是否仍重現。
- 驗收：早期帳戶前綴須與已封存帳戶逐日／逐筆一致；完整連續帳戶兩次相等，獨立重建資金與來源。任何差異必須解釋，不默默改換基準。
- 穩健篩選：八種情境皆勝過同成本 0050、最大回撤不低於 -50%、一般與全壓力 252 日滾動勝率至少 60%、2016–2025 十個完整年度至少六年勝出。主規則另要求 180／220 日鄰近參數的八情境累積勝出和回撤限制。既有較早／較近期分段失敗不因全期間過關而抹除。
- 比較兩段重設本金報酬乘積與實際連續帳戶，但乘積只標為非可交易診斷，不列為資產曲線。未清倉持股按末日價格估值。
- 不採用、不中斷既有暫停狀態、不下單。限價推算、股息付款日來源、未觀察到真實逐筆成交等限制保留；`live_qualified=false`。
