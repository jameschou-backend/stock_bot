# 現金帳戶的一次強勢加碼

在計算新加碼帳戶收益前固定。本輪僅以已完成的support_risk2為底座，沿用舊技術
規格的上漲10%、突破前20日高點、每批一次、額外預算10%及計畫風險2%，
不依剛才結果選擇表現最好底座，不調參，不加入型態篩選。
原資料期間、454候選、100萬元複利、5個部位、整張及閒錢現金不變。

先做不成交的可行性紀錄：完整重現已封存帳戶，僅計算當時是否有加碼訊號及
可用資金，不計算假想加碼收益。可行股數不等於完成加碼回測或可實際成交。

原候選買進處理完後，依原event_id排序檢查既有部位。原入場還原收盤至前日
收盤漲幅至少10%，且前日收盤嚴格突破此前20日最高價，並滿足原5,000萬元
事前均成交額，才可新增加碼指令。當日新建、已提出出場、無實體股、尚有
未交付股份或實體股數含不足一張零股時不加碼；不假設那些股可立即清算。

額外買費含在前日NAV的10%預算內；加碼後以事前參考價估算的單檔部位
不得超過前日NAV的1/5。僅用開盤已有現金扣去已用與已鎖住的委託預算，
不能用當日賣股、股息入帳或其他委託預算兩次。0股不消耗一次機會；
正股數委託未用預算保留至當日結束。

計畫停損採原入場還原收盤×88%與既有只上移支撐的較高者。以訊號日的
停損／收盤比例換算到執行前參考價；全數既有股份的市價，加新股買進總付款，
減全部股份按計畫停損出售的淨收款，不得超過前日NAV的2%。費率依情境，
不用初始買費再次計價；這仍是計畫損失，不保證跳空或無成交時的最大損失。

訊號後最早下一市場日執行；額外進場延遲情境同樣延後加碼一天。等待期間
不替換成新訊號、最多保留一個待執行指令；屆時只可縮小原股數，不能放大。
已出場或開始出場、股份權利狀態不符時取消。當次0成交後，只能在後續新訊號
再次成立時重試；部分成交即消耗本批唯一機會，不保留追加餘單。
加碼不重設入場錨點、支撐、63日期限或已提出的出場指令。

8壓力情境均保留，原對照核對後可重用。新增完整帳戶各離線跑兩次，新增買進
有獨立資金／股數／訊號紀錄，逐日現金、原委託鎖定、每批股數、配股與最終
成交都需獨立重建。沿用8情境全勝0050等歷史門檻；仍不是未見驗證。
先前歷史已被研究、日資料排隊及實際券商核帳限制不消失。排程保持停止，不下單。
