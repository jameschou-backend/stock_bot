# 回測四項補齊紀錄

本輪維持本金100萬元、複利投入、閒置現金，不重啟排程、不下單。0050是獨立比較帳戶。原封存版本保留供重現，新增證據和新策略各用獨立版本。

## 使用方式

工作台「策略驗證」先顯示本輪補齊進度，分別列公司行動、新族群帳戶、成交序列和歷史可得時間。只有完整通過帳務核對的案例顯示全期淨報酬；缺資料案例可看原因，不提供中途期間的漂亮收益。新族群帳戶可以下載全部買賣及每日資產。

「新族群帳戶」的預檢／背景回測使用本機來源和固定條件，不會觸發抓資料。嚴格PIT模式遇到目前分類回推歷史、歷史名冊或公告修訂缺證據時保留阻擋。背景工作沿用單一工作限制及30分鐘上限。補件前的原封存工具另留在下方，結果不會被覆寫。

## 四項範圍

1. **公司行動**：補2881／2025、2880／2025及2880／2026官方配股、交付與上市證據。原8組帳戶全部完成，重跑8組JSON逐位元一致。未知畸零款仍是應收，不是可支出的現金。詳見 `backtest_corporate_completion_20260925.md`。
2. **成交序列**：依每個完整帳戶的實際委託股日列需求，區分普通盤與零股；普通盤使用既有Sponsor來源按缺件補抓。日表／收盤／最後買賣報價、供應商逐筆檔或官方格式樣本，均不自行升級成已核實可成交。來源、股日、格式、獨立核對及缺件分欄保留。
3. **歷史可得時間**：加入官方2023-07-03的47家公司產業異動證據；它不能代表完整產業史，也不等於FinMind供應鏈分類史。公告首次本機觀測與官方原始發表時間分開記錄，修訂版本不足仍阻擋嚴格PIT。
4. **新規則的資金回測**：相對強勢，以及相對強勢加同行成交占比升溫，兩者採相同可判定母體、T日成交金額排序，T+1最早執行。搭配0050、整張／零股、一般／加嚴條件共12組。新增帳戶包含配股、股利、費稅、資金、名額、出場和每日NAV；事件命中率不再當作帳戶報酬。

## 防偷看與效能

- 新訊號不讀事後事件標籤或標籤是否成熟；末端訊號保留，T+2排不進期間者另記排程原因。
- 全量特徵以每個訊號日一次取列取代逐股重建寬表，使用包含程式、依賴版本、原始資料SHA的因果訊號快取。
- 公司行動資料延到資源層授權、撮合前才準備；已有持股的每日公司行動仍照常驗證。資料齊全時與原引擎逐欄相同。
- 資料準備與回測分離。準備使用共用FinMind限制器，失敗不反覆重試；每批持久記錄請求上限。正式回測和離線重跑均禁止網路。
- 原／新案例均檢查資金不可超用、同日賣款不回用、失敗名額與未花預算鎖至收盤、股數及每日資產恆等式、同政策0050。來源變更即拒絕沿用結果。

## 實際結果

原8案與新12案均已完成日資料帳戶；合計含12個股票策略設定和8列匹配基準，並非20個不同策略。以下為可買零股、2022/1/3至2026/9/9的扣費累積報酬，不是年化：

| 固定條件 | 原成交金額策略 | 新RS加同行成交升溫 | 同條件0050 |
| --- | ---: | ---: | ---: |
| 一般成本 | +552.49% | +48.16% | +242.34% |
| 合併成交壓力 | +200.57% | +93.73% | +239.83% |

原策略一般條件曾贏0050，但加入成交壓力後落後；新增同行條件的8個股票策略設定都輸同政策0050。壓力條件同時改變延遲、深度及滑價，會改變持股路徑，因此新策略壓力組較高不代表高成本有利。完整年度、回撤、成本、資金使用與整張對照見 [族群帳戶研究結果](research_sector_accounts_20260925.md)。

原8案離線重跑逐位元一致。新12案正式離線計算167.309秒，經工作台背景工作再計算172.377秒；兩者均不抓行情。來源準備另記273次FinMind與120次官方行情請求，不含普通盤逐筆補抓和另外核對公告，不能誤稱整輪工作沒有使用API。

## 仍有來源缺口

20案已知委託路徑需要917個普通盤股票交易日（181檔），本輪分兩批補抓286及501個股日，787次FinMind呼叫全部成功、未重試；合計6,555,288列、86.45MB。連同既有資料，917個必要股日均有通過本機格式檢查的檔案。

這不代表917個股日均已取得獨立核實的完整撮合場次：該項接受數仍為0，也不能證明自己的排隊順位。零股仍缺1,303個股日（204檔），歷史母體、分類區間、公告原始發表與修訂版本也未完整取得。日資料帳戶與已知路徑清單不涵蓋所有可能的逐筆成交路徑；逐筆結果改變持股後，還可能增加需求。因此不能把本輪稱為完整歷史逐筆回測，嚴格模式繼續阻擋。

完整股日清單、付費官方來源的可用期間和格式、已查到及尚未查到的證據，見 [資料補件紀錄](backtest_data_completion_20260925.md)。本輪沒有購買其他資料服務，排程維持暫停。
