# 休市順延事件的條款對應

玉山金與華城 2024 年原訂除權日是 7/25，已封存的 TWSE 除權資料與交易日曆將事件移至 7/26。上一版補件只掛在實際交易日，底層在移動日期以前，仍用原始事件日查詢配股條款，因此兩組回測仍中止；沒有發布或採用不完整績效。

新入口 `scripts/research_all_entry_accounts_rescheduled_distributions.py` 沿用所有已封存補件，另以 `skills/all_entry_rescheduled_distributions.py` 建立兩個原訂日期索引。每個索引的比例、普通股交付日、畸零款規則及來源均與已驗證的有效日條款完全相同。原本的日曆移動與正式 action ID 保持不變，不新增第二筆權益，也不改現金股利。

模組固定核對銀行補件、公司補件與原始日曆文件的雜湊及其所有來源。測試以真正的條款載入器、休市日曆及畸零款處理器重現舊失敗，確認新對應只在 7/26 產生一筆股票權益、保持交付日與現金股利，並讓未支付畸零款維持應收。資料對應可重跑；衝突條款與未經證實的日期移動會拒絕。

帳戶引擎、候選名單、進出條件、資金規則、費用與滑價均未改動。ADX 與 CMF 需以新入口重跑，並核對缺件前 134 個交易日完全一致。
