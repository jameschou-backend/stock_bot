# 剩餘資金配置實測：0050、現金與趨勢切換

2026-09-10。本金NT$1,000,000，2022-01-03至2026-09-09，共1,136個交易日。三組固定同一個股候選與loss12出場，只改剩餘資金配置。規則先寫於[事前規格](prereg_cash_allocation_20260910.md)，沒有依結果調整參數。

## 配置改變了什麼

現金組少賺NT$1,689,057.57，但最大回撤由35.89%降至25.52%，降低10.37個百分點。趨勢組比原配置少NT$48,848.17，最大回撤則增加1.92個百分點至37.81%。不能只因2022年跌幅較小，就認定趨勢切換在全期間較安全。

這裡的0050提供大盤曝險，並非反向避險。原配置平均約30.15%資產在0050；現金組平均約25.09%資產留在現金；趨勢組平均約16.89%現金、9.91%0050。趨勢OFF共11次實際賣出0050，這次沒有OFF指令因容量或限制而留下未成交數量。合成測試另涵蓋未能成交的情況。

所有組別仍使用完整458個候選、最多3個個股部位、前一日淨值三分之一的預算公式。股價跌12%或持有63個市場日開始出場，訊號在次一市場日執行；沒有加碼。配置影響本金、股數、出場容量及後續名額，實際個股部位是58、59、61批。因此這是整個帳戶政策比較，不能把期末差額全歸因成0050的單獨貢獻。

0050子帳本的扣成本淨損益分別為NT$1,226,851.28、0及523,530.49，公式為0050買賣淨現金流＋已付股利＋期末0050市值＋尚未支付權利。已核對沒有重複計入股利。這是金額帳務歸因，不是選股超額報酬。

## 成交可行性與限制

個股進場要求前20日平均成交額至少5,000萬元，本次實際成交個股最低約1.174億元。普通盤限制當日成交量與前20日均量較小者的1%；零股限制當日零股量5%，並檢查報價、漲跌停及整數股。不借款、不放空。

| 配置 | 零股成交筆數 | 超出最後對手報價數量 | 缺對手數量 |
|---|---:|---:|---:|
| 剩餘資金買0050 | 279 | 68 | 0 |
| 剩餘資金留現金 | 135 | 68 | 0 |
| 趨勢向上才買0050 | 306 | 88 | 0 |

上述68／68／88筆仍只符合日量模型，不能宣稱每一筆實盤一定能成交；最後一筆委託深度也不是整天可成交深度。另有固定當前公司名冊的存活者偏誤，以及反覆使用同一段歷史的研究偏誤。這些結果尚不能當作可靠的預期獲利。

沿用父研究已標示的公司行動限制：股利採毛額，未扣個人所得稅、補充保費、郵匯費；2880權利證書不模擬交易，至普通股交付日才出售、期間以普通股代理估值並占名額；部分畸零股淨額與付款日未核實，保留應收、不提前動用。詳見[出場研究](research_exit_scenarios_20260910.md)及結果JSON內limitations。

## 效能、來源與重播

本輪沿用封存行情與160份股利快取，只新增2次FinMind漲跌停資料、2次FinMind股利資料，以及27次交易所HTTP請求，沒有重新訓練或重抓全市場。共4次FinMind請求，使用共享額度控制，沒有402或等待。新增股利快取後合計162份。

四帳戶資料準備及首次模擬為68.20秒；來源就緒後完整離線重播為9.32秒，0個API請求。這兩個時間不包含輸入複製、完整來源雜湊、程式開發及既有資料查證時間，不是整項研究的總耗時。

原0050對照及原loss12帳本逐欄一致；四帳戶的現金、股數、費用、每日NAV、出場及配置決策均離線一致。來源清單封存4,154個檔案，父研究與來源未修改。畫面首次完整驗證約4.86秒，快取後讀取約0.30秒；點選不同配置不重跑研究或呼叫API。

工作台「策略驗證」新增「剩餘資金：買0050，還是留現金？」區塊，可比較淨值、年度報酬、資產比重，查看並下載各配置所有買賣CSV。完整工作台首次載入約9.18秒，再次載入約1.61秒；新區塊單獨切換約0.33秒。主要成果保存在`.cache/cash-allocation/`，輸入快取在`.cache/cash-allocation-inputs/`；快取不納入git。

重現命令：

```sh

python scripts/research_cash_allocation.py --offline-replay
```

## 研究決定

依提高報酬、可承受較大波動的研究目標，保留原「剩餘資金買0050」作為後續對照；現金組保留為降低回撤的比較版本。這輪不採用120日趨勢配置，也不調整均線參數追逐這段歷史。沒有把任何版本自動升級成正式策略，下一步可信度仍取決於更嚴格成交驗證及未見資料／前向紙上追蹤。
