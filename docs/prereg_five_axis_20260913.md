# 五項研究：資料重建、進場、排序、配置、營收預期差

2026/9/13，執行本輪比較前固定。所有衍生輸出獨立置於`.cache/five-axis-20260913`；舊封存、正式策略與前向帳本不改寫。沿用100萬元複利、閒錢保留現金、loss12/63市場日出場、原成本与合併成交壓力。已反覆使用的2022/1/3至2026/9/9歷史一律不稱未見測試。

1. **完整生成重建**：核對父來源，對全1974公司輸入矩陣隔離158筆日期衝突，重算全部月度族群及訊號，與原458候選逐欄比對。此作業完成不等於歷史母體完整：另盤點缺少的50筆下市紀錄，沒有可信上市區間與還原價者不得硬加。資料資格與既有名冊上的重建分開標示。
2. **進場**：基準隔日；`limit3`為固定訊號價上方2%以內、最多等待3個市場交易日；`retest3`另要求前一日已回測訊號日前60日高點（前日最低≤突破位、前日收盤≥突破位），才可於下一日嘗試。等待中前日還原收盤低於突破位，或有未處理的公司行動換價即取消。日級限價驗證採當日最高價與零股成交參考價均不超限的保守條件，不能把觸及最低價視為排隊成交。首次部分成交即視為完成本次進場，其餘數量不補造。合併壓力的額外延遲仍保留。
3. **排序**：只改同日候選順序。`capacity`依前20市場日平均成交金額由大到小；`capacity_vol`再除以前20日還原收盤報酬波動（缺值排最後），相同分數以股票代碼和事件ID固定排序。不稱為已量測價差或成交機率。其餘條件一致。
4. **配置**：`group_one`限制新進場訊號族群成員與既有持倉的訊號族群成員不得重疊；舊持倉不因重新分群強制賣出。`slots5`改為最多5檔、每檔前日資產1/5；`staged`先建一半部位，進場5個市場交易日後，只有前日還原收盤高於初次進場價、未觸發原出場、且資金足夠時嘗試一次補足原目標股數，未成交不算加碼。公司行動後原目標股數不能直接沿用，故取消該次加碼。額外測`joint`＝limit3＋capacity＋group_one，其他門檻不變。
5. **基本面**：跨候選股票計算季節性營收預期＝去年同月營收×前3個月營收合計的年增倍率；預期只用目標月以前的月份。超預期門檻固定10%。另取候選股票損益表，測最近可用季毛利率較去年同季改善及稅後淨利為正。月營收日期以其實際營收年月核對，營收月結束後15日／30日、季底後120日／150日各作假設公布延遲交叉，非供應商真實公布時刻。缺資料另設同覆蓋對照，不把缺資料算不達標。歷史版本／精確公布時間未驗證時，只能輸出時間假設診斷。另使用既有首次觀測公告帳本建立可前向保存的預測；首次批次不能冒充精確公告事件，今日取得的修訂資料不能冒充當時可用。

每個獨立變因均配原成本與合併壓力，報告費後總報酬、最大回撤、逐年、交易成本、筆數、未成交原因與同成本0050。不得看績效後變更規則或選好看的子期間。進場排序只用前日及更早資訊；當日行情只能約束既有委託的模擬成交。

資料準備最多400次FinMind（含一筆2330格式探測）與600次交易所HTTP嘗試，共享限流不變；成功快取可續跑，失敗明確保留。回測不重訓模型，重播不聯網。未完成的資料資格必須呈現，不能以完成程式取代完成實證。
