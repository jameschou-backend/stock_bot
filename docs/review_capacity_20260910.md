# 部位容量與同日排序：實測判讀與驗收

本輪沒有提高原方法的累積試算報酬。固定6個部位降低了最大回撤，值得保留作風險配置候選；固定3個部位的大盤校正排序沒有改變實際買入事件，對完整殘差動能選股的檢驗力不足。

規則在新收益計算前固定於 [研究規格](prereg_capacity_20260910.md)，先準備並封存分數，再跑20組方法與4組0050。首次分數準備後僅補報表的期末清算欄，再封存程式；沒有更改規則或根據結果調參。完整數值見 [結果](research_capacity_20260910.md) 與 [機器摘要](research_capacity_20260910.json)。

增加部位的主比較是622.51%減706.00%，少83.49個百分點；最大回撤改善11.05個百分點。平均個股曝險從68.48%降到64.82%。兩方法共同買入31個事件，6部位另買37個、3部位另買5個，代表後續持倉路徑也變了；不能簡化成把同一籃股票各減半。

## 排序沒有換到不同的股票

官方版本有440個原領先事件，趨勢通過368個，可完整評分287個；舊價格版本依序為439、367、286個。兩版本均有66個同日多事件日、16日改變排序。全部五情境中，新舊子集排序買入的30個事件完全相同，沒有任何獨有事件。

新排序比同子集原排序少4.65個百分點；延遲一天的差額縮為0.33個百分點。差異來自同日先後交易扣費後，每筆按當時NAV及剩餘可轉出的0050市值配置的金額不同，而非成功挑到另一批股票。例如2024-10-16的1560、4908處理順序互換，1.141548與1.078562的預算也對調；第二笔雖有NAV／3=1.136688的額度，仍受剩餘0050僅1.078562限制。2025-02-03的6770、6139也對調順序並受同一資金上限影響。因此差額不能全稱手續費損失，也不能據此判定完整殘差動能選股無效，不宜將這個方法當成新選股策略上線。

兩版本排除的81個事件全在2025-06-25～12-30。必要窗口缺價均指向0050的2025-06-11、12、13、16、17；相關股票在這五天本身有報價。固定147個連續市場日收盤的規則，使其後較長時段無法評分，這是市場代理與窗口的可用性限制，不能說81家公司資料品質差或基本面差。

匹配子集因此少了原策略6個實際買入事件。子集原排序2025年收益29.15%，全池原排序68.68%；2026子集全程持有0050。兩者147.04個百分點的全期差額應歸於候選池篩選及後續路徑，不能全部算成新排序的好壞。本輪保留缺口，不以補前值制造可觀察的每日報酬。
