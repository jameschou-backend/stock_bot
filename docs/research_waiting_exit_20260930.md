# 買入後等待5天、10天及弱勢確認：完整帳戶比較

研究期間2019-01-02～2026-09-09，100萬元複利、原版三檔、閒錢現金。進場沿用37,993筆原始訊號；本輪只測等待多久仍未啟動就出場。母體為封存2,076檔個股，並非完整歷史全市場。

## 固定規則

事前設計見 [prereg_waiting_exit_20260930.md](prereg_waiting_exit_20260930.md)。買入日算第1天，依還原收盤價計算：

- **等5天**：至少觀察5個收盤，至今最高漲幅未達5%、當下漲幅未達3%，下個交易日開始賣。第5天起每日檢查。
- **等10天**：相同條件，但至少觀察10個收盤。
- **5天＋弱勢確認**：另需跌破當時MA20、且從買入日收盤起的表現不優於0050同期，才賣。

原12%停損訊號與63日期限優先（12%也沿用入場日還原收盤作基準，不是含費成交成本），不能為了等滿天數延後停損。曾漲達5%者不再屬於「從未啟動」，仍依原出場規則處理回吐。本輪沒有加入移動停利。

賣出後依原資源限制及當時有效新訊號買進，沒有候選則留現金。這是釋放名額後重新選股，不保證當天立刻換滿；不追買過期訊號，也不封鎖原股以新訊號再買。

## 通常買入多久才開始漲

下表使用原126次持股，其中123次已出場且完整價格路徑可核對、2次仍持有、1次資料不完整。從首筆成交日收盤算第1天，觀察到第一次出場訊號；不是成交均價、扣費損益或盤中最高漲幅。

|首次達到漲幅|曾達到的次數|達標者中位日數|前5天達到|前10天達到|
|---|---:|---:|---:|---:|
|+5%|80|第5天|43|61|
|+10%|68|第8天|24|40|
|+20%|53|第12天|11|20|

這是「已知後來達標者」的等待分布，不能解讀為隨便買一檔、等中位天數就會上漲。出場前未達標者沒有被當成達標者統計。

另將所有37,993筆訊號都以預定T+1收盤為起點，看60個交易日後的固定窗口；36,199筆結果可判定，其中2,811筆符合既定急漲定義（至少+50%且領先0050至少20個百分點）。這些事後急漲訊號首次達+5%、+10%、+20%的中位時間分別為第5、9、15天；只有384筆在前5天已達+20%。訊號重疊，並非2,811個獨立事件。

第5天符合未啟動條件且60日結果已知的23,943筆訊號，13,463筆在60日後為負（56.23%），但6,946筆曾達+20%（29.01%）。但60日報酬包含已觀察到的前5天，不能直接當作預測後面下跌的證據。

### 排除已發生報酬後，判斷力如何

為避免把前5天已經落後當成預測能力，改由決策當日收盤開始，觀察剩下期間至原固定60日終點。下表只列結果完整的訊號，仍非獨立樣本、亦不是扣費帳戶報酬。

|第5天狀態|筆數|之後下跌比例|之後曾再漲20%|之後報酬中位數|
|---|---:|---:|---:|---:|
|符合未啟動條件|23,943|49.58%|34.61%|+0.09%|
|其餘訊號|12,256|51.66%|43.17%|−1.09%|
|未啟動且弱勢確認|2,800|48.71%|33.11%|+0.45%|

因此，單純5天沒動不能說成「後面更容易跌」；它降低了後續遇到+20%的頻率，但仍有約三分之一後來上漲20%。弱勢確認也未顯示更高的後續下跌比例。這是同一歷史樣本的事後診斷，不能據此重新調門檻冒充新驗證。

原126次持股若改看固定60日窗口，114次可判定、20次符合急漲定義，與上一輪以訊號日為起點的標籤不同。原策略可能已提前退出，後續上漲不等於原帳戶已賺到。

## 沒啟動與獲利回吐不是同一問題

原123次完整且已出場的路徑中，81次在原出場訊號收盤相對入場日收盤為負；其中38次早已漲過5%，26次早已漲過10%。這些是收盤訊號路徑，不是扣費已實現虧損筆數。等待規則最多處理尚未啟動的部分，不能解決曾經上漲後的獲利回吐，也不能用事後「最後沒漲」直接排除進場。

原持股在首次出場訊號前曾達+20%的53次中，5天規則會提早觸發21次、10天規則9次、弱勢確認5次。這比較的是同一批原持股的訊號路徑；完整換股後買到哪些股票與是否買回仍需另看帳戶，不能直接當成新帳戶少賺21筆。

這張表只回答早退條件是否碰到慢啟動股票，不是把原帳本刪單後推算績效。原策略也可能在後續上漲前已停損；「後來急漲」不等於該筆原交易一定獲利。

### 5天版為何沒有改善

5天版買入207次持股（原版126次），帳戶累計成本由1,565,149元增至2,634,400元。成本為多年複利下累計手續費、滑價與稅額，不是本金費率，也不能將全部績效差都歸因於成本。

它沒有買進原版最大獲利來源青雲5386。2026-02-03、04、05、09、10、11的青雲買單皆記錄名額已滿；2月11日持有方土昶6265、旺宏2337、聯合再生3576。也就是提早釋放過名額，仍可能先被其他訊號占走，並非五天規則直接將青雲剔除。

原版青雲淨獲利歸因8,083,749元，占帳戶總獲利85.11%；5天版最大來源為創意3441，1,736,314.90元，占30.14%。5天版的獲利集中度較低，但整體報酬與回撤仍較差。這是實際帳戶獲利拆解，不能把某檔歸因直接扣除就冒充「未買該股票」的重跑結果。
