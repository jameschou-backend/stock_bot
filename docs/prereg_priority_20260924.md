# 進場優先順序與漏買贏家：事前比較規格

2026-09-24，使用者要求依優先順序開始優化，排程不啟動。本輪先加兩市場完整性守門，再作隔離研究；不變更正式選股／紙上帳本。

## 固定對照

沿用五軸研究的排除行情衝突後458筆候選、2022-01-03至2026-09-09日曆、100萬元複利、最多3個股部位、閒錢保留現金、12%收盤停損與63市場日期限。各方法同一批候選，只改同日先買誰。

1. control：既有候選順序。
2. capacity：既有前20市場日成交金額排序，重現舊結果。
3. group_strength：在**原始訊號日**，個股20市場日還原報酬減去當時已凍結價格群組成員報酬中位數，差距由大至小排序。這是在各群組既有領先股之間排序，不重新選群組成員，也不宣稱群組就是新聞產業鏈。群組報酬至少80%成員有效，個股及群組都必須有正值端點；不足者列最後，記錄缺值，不能用事後價格補值。相同分數依股號、事件ID，沒有另加第二因子。

正常與combined壓力兩情境共6帳戶。壓力沿用每邊90bps滑價、零股最後揭示對手量、進出場各延後一市場日；正常每邊45bps。佣金、稅、原整股／零股量限制完全沿用。兩情境的新排序皆用同一原始訊號日分數。

## 漏買贏家的診斷

從**已保存的capacity_combined**帳戶，以逐股淨損益歸因事後選出最大1檔與3檔贏家。分別移除這些股票的所有候選，對control及capacity作同一排除，正常／壓力共8帳戶。重新跑現金、持股、公司行動與可買名額，不直接從原總報酬扣掉獲利。這是事後集中度診斷，絕不能當可交易策略或未見驗證。

共14個策略帳戶，另重用兩份已封存0050基準。輸出淨報酬、年化、最大回撤、成本、買賣筆數、逐年、滾動252市場日超額報酬分布。窗口重疊，不作獨立勝率／顯著性證明。任何缺執行來源的個案明確阻擋，不輸出完整收益、不從比較分母悄悄刪掉。

## 資料與效能界線

輸入與程式均驗證／保存SHA256；新資料輸出獨立目錄，不覆寫父研究。只用父研究封存快取、禁止網路與DB寫入、不訓練模型。先驗證父研究行情、帳本、公司行動與行情修復證據。完成帳戶要通過現金／持股稽核並離線逐欄重現。

完整歷史上市區間、還原價版本與歷史零股撮合證據仍有缺口；此處只作相同封存樣本的條件比較。所有輸出固定 live_qualified=false、unseen_validation=false。若新排序正常報酬較高但壓力結果變差，不作採用建議；即使兩者改善，也必須標示2026集中與既有資料限制。
