- 使用 `.cache/five-axis-20260913/rebuild/signals.json` 的全部 458 筆舊候選，逐笔使用 `.cache/chip-inputs/raw/broker` 封存的當日分點逐價表所有已揭露列。這是既有候選樣本，不是全市場，也不是最新 2026 HTML 的全部 POC 候選。
- 按股票、日期、分點代碼先合併所有價位，買賣單位為股。驗證股票日期、非負整數股數及市場買賣總量平衡（沿用 0.1% 容差）；缺資料或不平衡一律 unknown，不填零。
- 官方文件註明分點揭露可能不平衡，也不含鉅額。沿用平衡檢查是本研究的保守納入條件；不平衡不能斷言供應商出錯，平衡也不能證明全市場交易完整。本研究的成交量分母僅為該份表已揭露買量。

## 固定訊號特徵

1. 當日最大的五個**正淨買超**分點，平手依代碼；不足五個列 unknown。
2. `top5_net_share` = 這五個分點的合計淨買股數 / 當日表中已揭露分點買進股數。這是揭露交易量占比，不是流通股集中度，也不保證與官方全部成交量相同。
3. `top5_directional_ratio` = 這五個分點的合計淨買 / 合計買進加賣出。買賣相抵愈少比值愈大；不能直接稱為當沖比例或籌碼沒有賣掉。
4. 使用者五個明確分點逐一列買／賣／淨買及當日正淨買名次，不追溯挑選績優分點。
5. 五日持續性沿用既有封存結果：當日五大正淨買分點中，至少三個在五日累計淨買且至少三日淨買。完整市場日缺失仍保留 unknown；不更改旧算法。

固定比較：

- `named_positive`：五個明確分點中至少一個在完整當日表有正淨買；反組只代表未觀察到該事件，不證明每家都零交易。逐分點同樣列事件/非事件，但不依結果选最佳券商。
- `concentrated_directional`：`top5_net_share >= 0.10` 且 `top5_directional_ratio >= 0.30`，與相同原始資料覆蓋下的未通過者相比。
- `persistent5`：既有五日持續性通過，僅與五日資料同樣完整的未通過者相比。
- `combined`：集中且低抵銷，並通過五日持續性；只在相同五日完整樣本中比較。

這些指標全由訊號日或之前的資料生成。分點當日資料官方標示盤後約 21:00 更新，最早翌交易日使用；實際歷史首次發布／修訂版本並未證實。禁止以當日收盤價模擬使用盤後分點資訊買進。
