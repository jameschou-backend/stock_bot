# 有效收盤風控與錯日行情隔離

本規格在本輪績效計算前建立。延續現金版100萬元複利、2022/1/3至2026/9/9、458個候選、3個名額、loss12/63日出場、相同成本。舊研究、原DB與前向帳本不改寫。

1. 三個已發現日期（2026/6/9、6/11、6/17）重新取得FinMind全市場日資料，嚴格檢查回覆日期、唯一代碼與來源指紋。DB有而新來源缺少的列列為衝突，不能以供應商缺列單獨判定終止上市。比對2017/9/18、2017/12/18、2018/5/18的OHLCV，保存吻合證據與隔離清單。
2. 建立新的研究視圖，只將上述衝突股票日期的原始行情移除、還原收盤設為缺值，不填造價格，不修改股數或過去訊號。固定458候選重播僅驗證帳戶路徑，不能證明月度族群重建不受影響；需另查污染股票是否在當期族群。
3. 對照沿用舊trend60與shock規則。新版本只有指標窗口改成最近60/20/5/63個有效0050收盤觀察；當天缺價仍為UNKNOWN、不新增；不前填或以復牌價格回填停牌日。缺價中斷恢復計數，仍須5個有效且連續市場日支持升水位。波動為有效收盤間報酬的標準差乘sqrt(252)，不宣稱為停牌期間逐日波動。
4. 門檻、水位、執行時序與下單方法皆不調整。只比較原版／隔離版中性control及combined，再比較隔離版兩個風控模式的舊窗口和新窗口，配對既有同成本0050。缺成交資料明確阻擋，有界補抓至多20次FinMind及100次交易所嘗試，不重訓模型。所有資料完成後離線逐欄重現。
5. 這是已看過歷史問題後的修正與敏感度研究，不是未見樣本外績效。不因數字改善自動切換正式策略。仍需獨立還原價、歷史名冊、事件可用時間及真正前向驗證。
