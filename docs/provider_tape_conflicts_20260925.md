程式 `scripts/reconcile_provider_tape_conflicts.py` 限制在原 42 個身份、最多 42 次 adapter request，已成功的請求不重抓，原封存檔案不覆寫。新舊資料逐列順序與內容一併比較，同一時間的成交順序變動也會被識別。

結果及新來源存放於 `.cache/board-conflict-resolution-20260925/`；最後報告為 `report-final.json`。可用以下命令離線重新核對：

```sh
python scripts/reconcile_provider_tape_conflicts.py --verify \
  --output .cache/board-conflict-resolution-20260925/report-final.json
```

這次核對沒有改變舊帳本或報酬。重新下載成功不代表成交時序完整，更不能證明自己的委託能成交。
