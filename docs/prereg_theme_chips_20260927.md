# 題材與籌碼集中：固定研究規格

登記於2026-09-27，新籌碼組合結果產生之前。既有期間已反覆研究，不稱全新樣本外驗證。本輪只研究普通股，0050是結果比較基準，不持有ETF。

## 可識別的問題

舊新聞稽核已發現供應商日期與原文不符（prereg_event_groups_20260909.md），不能把該批資料當可靠的歷史題材訊號，也不能把未蒐集到新聞當沒有題材。因此分成兩項：

1. 全市場固定抽樣：持股集中是否增加急漲機率？加在已登記的相對強勢條件上是否仍有增量？
2. 九檔案例：將已核對的公司公告日期與同時可取得的籌碼並列。手工挑選的公司材料只能證明這些材料的存在，不能當完整新聞母體，也不能算題材策略勝率。題材四組若缺乏可核對的負例與覆蓋，必須標示尚不可識別，不產生假統計。

## 輸入與時序

- 沿用 stock_launch_20260927 兩轮一致的封存行情、固定21交易日觀察點、1974家現有普通股公司快照、價格品質檢查及2022–2024／2025–2026切分。排除九檔指定贏家後的母體是主結果。
- 20日急漲標籤：訊號日T之後，T+1收盤到T+21收盤漲至少30%，且比同期0050多20百分點；60日門檻50%／30百分點。缺價、未成熟、版本衝突均未知。
- 重新按市場交易日曆每週最後交易日抓FinMind全市場持股分級，暖身從2021-11月起，至封存行情截止日。不是按贏家挑股票。最多260次請求，4個並行，共用5400/h設定的限額，不重試；每個日期不可變保存及雜湊，續跑只驗證已完成日期。空日保留缺口。
- 集保是週末持股狀態，非買單／意圖。觀察日期加8日後才允許用於T盤後，另用15日作延遲敏感度；不是歷史首次發布時間證明。T+1起評估價格結果。
- 嚴格校验15級距、總人數、股數、差異調整、原始百分比；違規週保留原因、後續不能跳過壞週向前補齊。四週間須5筆有效資料，跨度21–35日、相鄰週相差不超過10日。可用日期後14日仍無新資料即過期。
- 千張以上為>1,000,000股級距；小戶代理是<=100,000股，不能分辨剛好100張，亦不等同最終實益所有人。持股比例用股數除集保總股數，不把總計或差異調整當投資人。
- 五個週點間任一次集保總股數變動超過1%，整個四週變化列未知，避免拆併股或分母改變製造集中。仍未排除所有帳戶移轉、級距跨越與公司行動。

## 固定条件與比較

- 集中C：四週>千張持股比例增加至少0.5百分點、<=百張比例減少且千張級距股數增加。另0及1百分點做鄰近門檻敏感度，0門檻仍要求嚴格增加。不得挑最好門檻取代0.5。
- 相對強勢R沿用：近20交易日比0050多10百分點。
- 在同一籌碼已知母體呈現全部、C、R、C且R；並列C且R、C不R、不C且R、兩者不符合四格。這是籌碼×價格強度，不冒稱題材四格。
- 報告觀察數、命中數、未達門檻數、未知數、平均／中位個股價格報酬與相對0050報酬。比較C且R與不C且R，按整個觀察日重抽1000次，日期至少5個才提供區間；同股票跨日／60日重疊、研究多重嘗試未完全校正，區間限描述用途。
- 九檔原有回溯事件及同日同產業流動性對照，補T-20、T-10、T-5、T的集中度，不改事件錨點，不只報支持假說的案例。補原文日期可核對的材料；公告日期加一個日曆日才算可用，事後材料不能回填前日。

## 成果與驗證

封存來源、規格、程式、逐週稽核、觀察表、九檔事件、對照及統計。截斷未來／變更未來籌碼不得改變過去訊號；未知不可變成false，分母跳變、發布延遲須有測試。離線重跑兩次比較所有CSV。先做線索統計，不把個股結果相加成帳戶報酬，尚不含稅費、滑價、成交限制或組合資金配置；strategy_net_return=null、live_qualified=false。
