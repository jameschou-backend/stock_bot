# 真實歷史訊號的未來資料隔離檢查

本檢查只驗證選股函式的時間因果性，不計算新報酬、不改規則，也不改前向帳本。使用既有封存的2021/1/4至2026/9/9、1,975欄矩陣及原公司名冊，訊號期間2022/1/3至2026/9/8。

事前固定檢查點：2022至2025每年3/31、6/30、9/30、12/31；2026的3/31、6/30及9/8。非矩陣交易日取該日前最後一個交易日，共19個切點，不按收益或個股表現挑日期。

1. 完整來源重新產生訊號，對比封存的全部接受／拒絕候選；來源與原訊號程式SHA256必須吻合。
2. 每個切點做「截斷」：僅保留當日及之前的行情，另保留下一個已知交易日的全空白列，供標記隔日委託日期；不能提供該日價格或量。
3. 每個切點做「竄改未來」：保留原矩陣長度，將切點後已存在的價格及成交量，按固定的日期／股票交錯倍率大幅改動，缺值仍保持缺值；切點之前完全不動。
4. 兩種結果的接受／拒絕候選、截至切點的0050趨勢，以及當時已固定的分群組成／選取證據，須與完整來源相同。比較完整欄位；分群排除後續每日新增的leader_rejections，事件後續確認結果不納入「當時已知」比較。不因結果不符調整容忍度或切點。
5. 任一不一致即記錄失敗與比較雜湊，不宣稱通過；本機輸出另存，禁止覆寫既有前向帳本或舊研究來源。

這不能證明供應商當年就公布了現在的資料版本，也不能解決固定現存公司名冊、價格修訂、成交深度、盤中資金先後與反覆研究偏誤。通過也維持live_qualified=false。此檢查不依賴FinMind新請求或ML重訓；群組重建屬必要的訊號重算。
