# 公司行動參考價索引

31 組每日候選使原財務引擎的查價成本放大：每個候選的計畫與委託參考價都會掃描整張 16,575 筆公司行動表。這與選股或成交假設無關。

`skills/all_entry_reference_index.py` 建立新的私有衍生類別，只索引 `(stock_id, event_date)`。原有公司行動重新排程優先權、重複事件錯誤、開盤參考價缺件錯誤，以及 0050 分割參考價規則均保留。原模組、類別及來源檔不被改寫；新入口預設載入補齐同儕資料的候選 v3。

以全部真實事件座標加未知日期、0050 分割日期，共 16,584 個座標逐一對照，回傳值及例外型別／訊息完全一致。測量同一股票日期 2,000 次查詢，原查詢約 2.47 秒，索引約 0.00032 秒；這只代表該函式的速度，不代表整段回測加速比例。

原慢版 full-v2 在確認無進行中的外部資料請求後停止。已完成案例及原始來源保留供帳本對照；中斷中的動能組不發佈績效。正式結果須由索引版完整重跑，並再次核對資金、交易與應收權益。
