# 0050 補買排除的核帳修正

原成本 baseline-v3 在完整重播666日後被舊核帳拒絕：2025-04-10補買0050的一股零股資料超出來源的法定價格界限，依既有政策整單零成交。既有7656股、現金193.98元均保留。舊核帳把全部買單都視為首次建倉，因此誤拒絕既有持股。

新私有核帳只允許0050的benchmark補買排除，必須沒有新cohort、沒有同日公司行動，前一個估值日與排除日均有相同event及相同股數。原零成交、現金不變、委託與日誌錨點、資料缺失獨立重建檢查全部保留。其他個股首次建倉檢查不變。

不修改報價、資料排除政策、價格、成本、訊號、資金或持倉；修正核帳後用新目錄重播受影響的0050。原失敗帳戶及所有試次保留。正式入口為`research_top3_validation_v3.py`，不得覆寫前版已封存的程式／帳本。
