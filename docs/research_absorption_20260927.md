# 法人賣超、價格守住：廣母體實測

2026-09-27。**這輪沒有支持把「法人賣超但價格守住」單獨升級為選股策略。後段20／60日平均結果均落後同期0050，發布延遲改為3天後更弱；與價格已守住、但沒有明顯賣超的股票相比，60日結果也較差。保留研究，`adopted=false`、`live_qualified=false`。**

這不是認定法人賣超必然不好，或市場不存在吸籌，而是目前這個可重現定義沒有展示穩定優勢。沒有把少數成功個股當成所有候選有效的證據。下文的事件平均與比例成本試算，均不是100萬元帳戶報酬。

## 先固定規則，再取資料

預註冊 [prereg_absorption_20260927.md](prereg_absorption_20260927.md)，commit `9ab43c3`，在取新資料與評估之前完成。封存行情期間2022-01-03～2026-09-09，每21個交易日固定一個觀察日，共55日；不要求先出現第一根、兩倍量或突破。

母體為現有1,974家公司快照。依當時掛牌日期、連續120日有效行情、過去120日無單日絕對變化超過15%、20日平均成交額至少5,000萬元等既有品質／流動性條件判斷。**不是已補齊下市公司的歷史完整股票池**，industry也不是歷史題材成分。

共31,610個股票－日期觀察，每筆計算lag1／lag3兩份特徵，共63,220列。排除使用者指定十一檔後，主分析31,113個觀察、1,448檔股票，兩個lag共62,226列。指定股另列案例，0050只作獨立基準，00631L不進入個股候選。

訊號日T，主版本特徵截止S=T−1；敏感度S=T−3。五日外資（含外資自營商）＋投信淨買股數，除以相同五日成交股數。自營商自行／避險另留欄位，不加入主訊號。這是交易淨額比，**不是持股集中度，也無法辨識誰在承接**。

| 組別 | 固定條件 |
|---|---|
| 全部可判定 | 價量與法人資料完整，可判斷下列條件 |
| 明顯買超 | 五日淨額比至少+3% |
| 明顯賣超 | 五日淨額比不高於−3% |
| 價格守住 | 五日不跌、不落後0050，期間每個收盤不低於起始價格98% |

六組使用相同可判定資料母體；缺日期／分類／價格不能視為沒有賣超，淨買零則是已知值。T日尚未公布的法人不參與訊號，T+1才安排參考進場。候選、排序與配對先建立，再接上未來結果。
