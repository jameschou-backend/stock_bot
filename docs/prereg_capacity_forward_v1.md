# 成交金額排序前向版本 v1

2026/9/13，第一個新委託交易日前固定。此版本是可執行委託規則的前向模擬，不承接歷史日收盤回測的績效資格。

- 三份獨立100萬元起點：成交金額排序、原訊號強度排序現金對照、0050。只可在原比較起點尚未開盤、沒有成交或權益的情況下複製原始證據。舊帳本不變，新帳本取消繼承的個股委託後重新依事前完整候選排序建立。
- 沿用固定族群先行突破訊號。成交金額排序只用訊號日已封存的前20日平均收盤×股數；對照仍依原priority。相同分數依股票代號、事件ID。全部候選及未選原因逐日封存；最多3檔、每檔前收盤NAV三分之一、閒錢現金、無槓桿、不預支未成交賣出。
- 買入委託只能在下一市場日開盤前建立，限價為訊號日原始收盤，整股／零股分單，ROD。盤中不追價、不用新的同日資訊改排序。收盤取消未成交餘量，不自動次日重買。停損12%及63交易日出場沿用前向帳戶既有語義，未成交出場次日繼續，跳空可能超過停損幅度。
- 只根據真正取得的兩次間隔15至90秒、各不超過15秒舊的報價模擬；可見深度和區間成交增量各限10%，保留0.1%不利滑價、交易單位、最小20元手續費及稅。當日沒有觀察不補填成交。這仍不是券商成交證據。
- 對照與排序版使用相同整戶收盤回撤停止新增規則，暫定20%，是尚待使用者選定的模擬風險值；不冒充已同意的實盤風險。觸發後鎖住新買單，必須另行人工解除且當前風險已低於門檻；原出場继续。可隨時主動暫停新增，不強制清倉、不取消賣單。0050獨立買入持有基準不套用此個股策略水位條件。
- 每日流程先過期委託處理、明确FinMind行情pipeline、封存訊號、更新公司行動來源、核對收盤、保存出場、保存新買入計畫。失敗保留已完成步驟並可續跑；內層entry_block不得算作成功。任何來源、行情或股數不明不得變成成交；可核對的出場不依賴新候選生成成功。
- 三帳本共用一份資料及行情請求；公司行動每批合計上限12次FinMind，共享5400/h配額保留6000/h餘裕。交易所行情每次最多24組兩次觀察；缺資料不繞過限流。
- 實盤資格持續為false。歷史上市區間／存活者偏差／還原價資格、前向期間、券商回報仍須另證明。參數或共用引擎變更，需另開新版本，不覆寫過去訊號或帳戶。
