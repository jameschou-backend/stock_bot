兩個必要事件已由公司正式股東會議事錄及證交所 LT185 上市公告核對。MOPS API 回傳安全性拒絕頁後已停止該來源請求；本補件不使用該錯誤頁、搜尋摘要或轉載新聞作為入帳依據。

聚陽公司網站 2024 年股東會議事錄第 3 頁確認配股比例、面額及畸零處理，表決通過。證交所 2024-10-09 公告確認普通股 4,837,132 股於 10/18 開始買賣，並記載公司已在 10/4 發布交付公告。

臺企銀投資人網站 2026 年股東會議事錄第 37–38 頁確認每千股 70 股、面額 10 元及畸零處理，表決通過。證交所 8/27 公告確認 680,264,330 股新股權利證書於 9/2 上市；9/7 公告確認同數普通股於 9/10 開始交易，同日證書終止上市，並記載公司已在 8/28 發布交付公告。

帳戶延用既有「只交易普通股」限制：2834 配股保留在獨立的股票應收權益，普通股與權利證書交付日期分別記錄；9/2 不增加可賣普通股、可用現金或可重用席位，9/10 才交付。期間估值為普通股收盤價代理，未建模證書本身的交易機會、行情或排隊，不能因此宣稱實際成交已驗證。這與既有 2880 權利證書限制相同；最終報表須揭露受到此限制的帳戶。

原始 PDF、抽取文字、人工檢視頁面及 HTTP 回執保留在 `.cache/all-entry-accounts-20261011/corporate-evidence/{1477,2834}/`；上市原表及回執在 `required-listings-v1/`。補件文件綁定全部原始證據指紋，載入時重新檢查日期、股數、比例及現金限制。

入口 `scripts/research_all_entry_accounts_distributions.py` 增加 `--distribution-completion docs/all_entry_distribution_completion_20261011.json`。每次須使用新的輸出目錄，失敗舊結果繼續保留。這些公告只處理已持有股票的權益與交付，不參與歷史選股。
