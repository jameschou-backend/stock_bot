# 觀察名單的 K 線與持股比例圖

入口：`/terminal/holder-stability/`。點觀察名單的股票名稱，或上方光聖／旺矽案例，可查看還原日 K、原始成交量與 600 張級距持股比例。網址可用 `?stock=6442#stock-chart` 重開個股。

圖表只讀取 `holder_stability_600_20261102` 的 112 檔固定觀察股，截止 2026-10-30，可切換 60／120／240 個市場交易日。這些控制項不改名單、歷史比較設定、原 POC 或封存研究結果。

- 三張圖共用日期與游標，可點擊、移動滑鼠，或聚焦圖表後按左右方向鍵、Home／End 查看同日價量和持股資料。
- K 線採研究來源的還原 OHLC；成交量由原始股數除以 1,000 顯示張數。還原價不是當時掛單價。
- 持股比例合計 600,001 股以上三級，無法單獨識別恰好 600,000 股。週資料從觀察日後 8 或 15 個日曆日才呈現，預設沿用研究的 8 日假設。歷史首次公告時間並未完整核實。
- 持股曲線採階梯線；沒有把未來一週的比例倒填進歷史。最新可用快照失效時保留未知，不退回更早的有效值；超過假設可用日 14 個日曆日也標為未知。
- 當期比例有效但四週比較資料不足時，比例仍可顯示，四週變動顯示未知。缺行情的交易日保留原位置，避免兩張圖日期錯位。

## 資料與重現

新增的獨立圖表檔為 `artifacts/forward_simulation/holder_stability_charts_20261102.json.gz`，SHA-256：`e9b230f77b09076a0ae0b660550c752980f63169e93b1d1531ea35338feacca0`。它綁定原研究報告的 SHA-256，包含原行情 bundle、持股週資料與產製程式的來源雜湊；產製過程禁止網路、沒有資料庫寫入。

讀圖不需要原始 `.cache` 資料。要獨立重建時，需保有原研究來源：`.cache/scanner-20261030-close/inputs-v1` 與 `.cache/holder-stability-600-20261102/run-a/weekly.parquet`，再指定全新的輸出位置：

```sh
python scripts/prepare_holder_stability_charts.py --output .cache/holder-charts-replay/new-chart.json.gz
```

產製器拒絕覆寫既有圖表或校驗檔；來源雜湊不符即停止，不抓新資料補替。相同來源與環境可產出相同 gzip 位元組。

本機唯讀 API：`GET /research-terminal/api/holder-stability/stocks/6442?sessions=120&holder_lag=8`。範圍只接受 60／120／240，延遲只接受 8／15；非觀察名單股票回傳 404，來源缺漏或校驗失敗回傳 503。瀏覽器切換股票會中止舊請求，逾時或失敗會隱藏舊圖，避免將前一檔誤認為目前股票。

驗收涵蓋 112 檔與原研究的值核對、兩種延遲、未來快照不影響過去、未知與過期快照、快取後來源被改動、股票切換競態、圖表斷線及實際瀏覽器操作。此功能維持研究用途，沒有新增交易資格或下單行為。
