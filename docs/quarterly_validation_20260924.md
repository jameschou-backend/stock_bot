# 財報欄位、TTM與可用時點修正（2026-09-24）

已修正計算與資料接入；尚未取得全市場歷史首次公告版本，也尚未將財報改善列為選股超額報酬。保留舊表供稽核，新增版本表，沒有把今天拿到的財報倒填過去日期。

## 修正內容

| 項目 | 原問題 | 現在定義 |
|---|---|---|
| 欄位 | `TotalLiabilities`、`NetIncome`、`PurchaseOfPropertyPlantAndEquipment`與實際來源不符 | 使用`Liabilities`、`IncomeAfterTaxes`、`PropertyAndPlantAndEquipment`；異常schema明確失敗 |
| ROE／ROA | 以單季淨利或不一致權益口徑當成TTM | 連續四季合併稅後淨利，除以當季與去年同季合併權益／資產平均；百分比 |
| 現金流 | 直接加總累計值會重複計算 | 現金流來源先按年累計差分回單季，Q1重新起算，再加總連續四季 |
| 自由現金流 | 將FCF除1000標示為每股 | `fcf_ttm`為營業現金流減購置不動產、廠房及設備支出，單位新台幣元；不含無形資產等其他投資支出 |
| 每股自由現金流 | 股數分母未核實 | 只有明確來源的期末流通普通股數才計算；本次兩檔分母未補，均留空。股本不是股數 |
| 可用時點 | 報表季度末加固定60天 | UTC首次取得時間加台北日期次日才能用；未證明公告日，不假造歷史可得性 |
| 修訂 | 更新會覆寫歷史數字 | 同期間新版本追加，未改資料不改首次取得時間，舊版本保留；取最新已知報告，舊季晚修訂不取代新季 |

缺季度、缺分母或缺欄位的指標保留空值，不補零、不對ROE任意裁切。來源含同欄位衝突版本、非有限金額、非季度末、未來報告期或不符符號的購置支出會明確拒絕。`quarterly_v2`比例與模型既有百分比欄位一致；舊研究快照未改。

## 官方抽查與實際資料

欄位參照[FinMind基本面文件](https://finmind.github.io/tutor/TaiwanMarket/Fundamental/)。以[台積電2024合併財報](https://investor.tsmc.com/sites/ir/financial-report/2024/TSMC%202024Q4%20Consolidated%20Financial%20Statements_E_0.pdf)第6、7、10、11頁核對：報表單位千元，FinMind值為元，乘1000後下列六項完全相符。

| 官方項目 | 換算為新台幣元 |
|---|---:|
| 2024年底資產 | 6,691,938,000,000 |
| 2024年底合併權益 | 4,323,575,865,000 |
| 2023年底合併權益 | 3,483,262,847,000 |
| 2024年四季合併稅後淨利總和 | 1,172,431,759,000 |
| 2024年累計營業現金流 | 1,826,177,068,000 |
| 2024年累計購置設備支出 | 956,006,536,000 |

由此獨立重算，台積電2024Q4 ROE TTM為30.036018%，FCF TTM為870,170,532,000元。這是本研究的合併口徑ROE，並非公司股東口徑ROE或EPS。台泥亦通過三表取得及計算，但未完成逐項官方報表外部核對，不能宣稱所有公司皆已驗證。

本機舊摘要表原有0筆。正式新流程以1101、2330兩檔驗收，寫入28筆，首次觀察為2026-09-24，最早可用日2026-09-25；另外將相同封存原始資料再次送入MySQL，新增0筆、原觀察時間不變。原始回應Parquet及SHA256保存在`.cache/quarterly-observations/`；本機資料不是異地備份。

## 用量、效能與驗收

每批最多180次請求／60檔，每檔三表；按最久未檢查公司輪替，進度與財報可用時點分表。顯式指定股票超過批次預算直接拒絕，失敗不自動重試，仍走共用FinMind限流。本次來源探測6次＋實際入庫6次＝12次FinMind呼叫；資料庫重播0網路。來源取近三年起始日至今，保留四季TTM與去年同期分母所需暖機資料；這不是全歷史財報回補。

資料庫migration 018已在本機重跑兩次；獨立測試覆蓋累計轉單季、TTM缺季、單位／分母、未來資料擾動、可用日期、修訂追加、冪等、批次額度與輪替、欄位漂移。`make test`：2617 passed、29 warnings、62.42秒；詳見`artifacts/forward_simulation/quarterly_validation_delivery_20260924.json`。手動pipeline兩次成功；API重啟後health、picks、models、jobs四個curl均成功。另以真實2026-09-24行情讀取1983列，3.374秒完成，三項財報特徵在可用日期前均為空。pipeline重跑不是全歷史特徵重建；單位與時序另由專門測試和實際入庫核對。
