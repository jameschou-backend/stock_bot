# 上海商銀權利證書與普通股分開核對

MA20／60 金叉雖已完成青雲補件回放，仍持有 5876／2026-07-28 配股事件。舊條款在 8/20 證書交付時直接增加普通股庫存，不能通過本輪共同帳戶的發布檢查；該版本不列入有效排名。

此次只沿用「交易普通股、權利證書不交易」的帳戶範圍，與已核對的 2880、2834 限制相同。證書本身可能在市場買賣，但本研究沒有驗證其可交易行情與成交映射，不借用普通股成交帶模擬證書買賣。

公司正式公告 PDF 第 2–3 頁確認 1% 配股、面額 10 元、8/20 交付新股權利證書；證交所 LT185 原始表確認 48,616,031 單位證書於 8/20 上市，同批普通股於 9/11 開始交易，證書同日終止上市。使用既有封存原始來源，沒有重試拒絕存取的網站。

更正回放保留原有比例及畸零毛額／付款日未知限制。7/28 至 8/19 列配股待交付權益；8/20 至 9/10 另列不可交易的證書單位；9/11 一次轉成普通股。期間以普通股收盤價估值，不增加買入資金。現金股利沿用自己的支付日期，不跟著股票換發日延後。

這次增加獨立的逐日單位帳：分別列待交付、證書庫存、普通股換發；從除權前普通股數量出發，逐筆重算買賣後普通股結餘，逐日對照持股。檢查不得提前交付、證書單位不得用於普通股賣出、普通股只能換發一次，未確認畸零款不能拿來交易。發布工具會重新計算這份單位帳；只改日期、只加通過旗標或套用普通股行情，都無法通過。

新入口為 `scripts/research_all_entry_accounts_certificates.py`，在前一完整補件入口參數外，加入 `--certificate-completion docs/all_entry_certificate_completion_20261011.json`。必須使用新的輸出目錄，舊失敗與未通過驗證版本保留。6446 的證書事件尚未套用這份專屬更正，若持有仍會阻擋發布排名。
