# 2026-09-25 華新科、國巨與族群確認研究

已把同行價格與成交條件加入急漲研究。**5/11 的華新科與國巨都有其他被動元件成交轉熱的跡象，單看個股兩倍量會漏掉；但把族群確認全面加為硬篩選，尚未提高整體辨識力。** 本輪使用目前產業鏈名冊回溯，不把它稱為當時已保存的訊號或可交易淨報酬。

固定設計見 [prereg](prereg_surge_sector_20260925.md)。舊研究觀察表與價格快照均未修改。新增三種比較：相對強勢＋同行價格擴散、相對強勢＋同行成交占比增加，以及同時要求兩種確認。

## 華新科當時多了什麼可觀察的依據

2026-05-11 收盤，只用當日以前的價格。FinMind 目前「被動元件」分類中，本機名冊有 51 家公司；每個案例排除自己，剩餘 50 個同行全部通過本輪資料完整性檢查。

| 個股過去 20 日領先 0050 | +13.46 個百分點 | +17.37 個百分點 |
| 當日量／此前 20 日均量 | 1.83 倍 | 1.01 倍 |
| 原先強勢＋突破＋兩倍量 | 不成立 | 不成立 |

同行成交規則固定為近 5 日占比至少為此前不重疊 20 日的 1.2 倍。分子、全市場比較分母皆排除目標股，避免華新科或國巨自己放量就被當成族群證據。上表是原收盤乘成交股數的成交額估算，**不是資金淨流入或法人買超**。兩檔排除的金額不同，故各自的同行成交占比也不同。

在上一輪相同未來窗口（5/12～6/9），華新科價格 +133.42%、國巨 +96.90%。這只是回看已知案例；新規則不是事前提出，不能用這兩檔成功就認定已找到有效策略。若當時按新判斷行事，最早也只能在 5/12 考慮委託，不能回填 5/11 成交。

## 全母體加上族群，有改善嗎

使用 47 個目前產業鏈類別、對應固定名冊中的 1,920 家公司。主比較限定在同行特徵都有資料的**同一批股票觀察**，所以基準與前一份研究略不同。

前段有 17,809 個共同觀察，17,760 個結果可判定、470 次急漲；後段有 10,673 個共同觀察，10,132 個可判定、588 次急漲。急漲仍定義為訊號隔日收盤後 20 個報酬區間，個股至少 +30%，且領先 0050 至少 20 個百分點。

| 固定規則 | 前段 2022–2024 急漲率 | 後段 2025–2026 急漲率 | 後段命中／已知結果訊號 | 抓到後段全部急漲的比例 |
| --- | ---: | ---: | ---: | ---: |
| 全部共同觀察 | 2.65% | 5.80% | 588 / 10,132 | 基準 |
| 個股相對強勢 | **5.63%** | **10.66%** | 213 / 1,999 | **36.22%** |
| 原先強勢＋突破＋兩倍量 | 5.73% | 11.79% | 27 / 229 | 4.59% |
| 相對強勢＋同行價格擴散 | 3.48% | 6.57% | 22 / 335 | 3.74% |
| 相對強勢＋同行成交升溫 | 5.22% | **11.35%** | 59 / 520 | 10.03% |
| 相對強勢＋上述兩種同行確認 | 2.78% | 8.18% | 9 / 110 | 1.53% |

「相對強勢＋同行成交」在後段比相對強勢單項多 0.69 個百分點，但以同一日期區塊配對重抽 1,000 次，差值 95% 區間約 **-2.89～+4.83 個百分點**，仍包含沒有改善。前段則低 0.41 個百分點，亦無明確改善。因此不能把 11.35% 大於 10.66% 當成已證實更好。

兩種同行條件都加上，選中數和涵蓋率大幅減少，兩段命中率也都低於原始相對強勢。這是本輪固定定義的負面結果；不為了命中華新科，把六成改成五成或再選另一個量門檻。

## 被動元件子集

只用「被動元件」那一群確認，不借公司在其他類別的結果補足條件：

| --- | ---: | ---: |
| 相對強勢 | 4 / 85（4.71%） | 20 / 129（15.50%） |
| 相對強勢＋同行成交升溫 | 0 / 18（0%） | 10 / 35（28.57%） |
| 相對強勢＋兩種同行確認 | 無訊號，不能算命中率 | 無訊號，不能算命中率 |

後段被動元件的成交升溫條件看起來有線索，但只有 35 次已知結果，而且前段 18 次沒有命中，不能因已知這一波被動元件行情就選它作為通用條件。也需注意供應商分類包含 MLCC、電阻、電感、材料、代理與跨業公司；同屬此分類，不代表同一產品缺貨、漲價或同等受惠。

## 消息如何加入，避免把事後故事當前兆

本輪量化訊號尚未把新聞算分；官方來源與日期另記於 [消息來源核對](research_surge_sector_sources_20260925.md)。華新科 2026/4/9 的官方 3 月營收公告，早於 5/11，揭露年增 11.1%、工作天恢復及通路補庫存，並稱 AI 伺服器與電源管理需求穩定。該文沒有宣布漲價；不能把「需求改善」改寫成當時已知的調價事件。

下一步應使用有產品分類、首次發布時間及修訂紀錄的事件，而非單靠「被動元件」標籤。對一則 MLCC 缺貨消息，要分辨公司是否生產相關規格、消息是需求增加還是原料成本上漲、營收或訂單是否真的受惠，並保留同時有消息卻未上漲的對照。這些新增事件條件尚未計入本次命中率。

## 覆蓋、資料界線與交付

原始名冊含 1,974 家公司，目前分類覆蓋 1,920 家。供應商分類另外有 437 個代號不在本次固定普通股名冊，完整列於 JSON，沒有猜測其掛牌身分。原始兩段合資格觀察中，前段 205 筆／後段 226 筆沒有分類；838／655 筆有分類但同行判定資料不足，均保留揭露，不當成不會急漲。共同觀察內仍有前段 49／後段 541 個未來結果待判定，不填成失敗。

同行需要至少 3 家、資料完整者至少占當時已掛牌同行的 80%；全市場估計成交額每天覆蓋至少 95%。改變目標股自己所有價量、刪除未來或放大未來資料，不能改變該目標當時的同行特徵。缺整欄同行不能縮小應有檔數，0050 僅作基準，不當普通股。

**目前成分不是歷史當時保存的成分。** 供應商欄位 date 不等於分類首次公開日，不能把近期資料倒填成當年可用資訊。所有輸出固定 `membership_point_in_time=false`、`live_qualified=false`、`portfolio_returns_computed=false`。結果也不包含費用、零股成交、資金配置或帳戶報酬；兩段歷史都不是未見資料。

- 入口：`python scripts/research_surge_sector.py --output .cache/<新目錄>`，拒絕覆寫既有研究。
- [完整 JSON 紀錄](../artifacts/surge_sector_20260925.json)；主結果位於 `.cache/surge-sector-20260925/`。
- 保存 30,993 筆原始觀察加新條件、159,928 筆同行觀察、1,044 筆被動元件觀察、144 列分段／年度規則統計，以及 50 筆兩檔案例的逐日特徵（4/2～5/11）。同行長表以 Parquet 壓縮，約 10.8 MB；案例及比較表可直接讀 CSV。
- 研究全程本機離線，0 次 FinMind、0 次 DB 寫入、不重新訓練模型。正常 pipeline 驗收另計，不混為研究的 API 用量。
