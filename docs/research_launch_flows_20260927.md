# 十檔急漲案例：法人、連買與均線差異

2026-09-27。主結論：**法人買超不是十檔急漲共同的必要條件，集中也不能代替法人連买；均線位置與斜率的區分比單看連買更一致，但仍未證明可賺到超額淨報酬。**

本輪分析台達電、禾伸堂、國巨、華新科、華邦電、南亞科、南亞、聯電、群創及昇達科。沒有改變既有選股或實戰資格，沒有下單或啟用排程。

## 兩層證據與時間範圍

1. **回溯急漲案例：**2022-01-03～2026-09-09，十檔共58個月度、27個季度事件。月度為T+1至T+21收盤漲至少30%、並超過0050至少20百分點；季度為60日漲50%、超過30百分點。同股冷卻horizon+1日。日期是用後續漲幅定位，不能稱為當時已知買點；包含續漲、低檔反彈與相互重疊行情，85個不是獨立樣本。
2. **不依漲幅選樣的第一根：**沿用先前固定規則的6,357個價量事件，其中十檔102個，全部包含失敗。主條件比較排除這十檔，剩6,255個。先計當時可知特徵，再接上原封存20／60日結果，沒有更改進場或急漲定義。

均線使用同一套還原收盤，法人使用FinMind原始股數。主要比較截至T−1的法人，均線以T收盤；T日法人另列為出量當天的同步反應。最早也只能在資料可用後的下一交易日操作，當日法人不能用來假設當日尾盤已成交。歷史第一次發布及後續修訂仍未驗證。

## 排除十檔，條件是否改善結果？

均線可覆蓋全部6,255個第一根事件。法人原始資料是以前策略選過的280檔，加上本輪補的台達電、禾伸堂與聯電；這283檔不是完整或隨機全市場。排除十檔後只有2,464／6,255個事件法人可判斷，其餘保留未知。十檔102個第一根事件的當日、前日與5／20日法人窗口都有資料。

下表比較同一條件已知母體的「符合／不符合」，用次日收盤至共同終點，全部為**未扣成本、未配置資金的個股價格統計**。不同列的資料母體不完全相同，不能互相比最高數字挑策略。

2025–2026多頭且上揚組的20日急漲比例45／595＝7.56%，非多頭組64／1,270＝5.04%；60日平均為+11.79%對+6.33%，方向也相同。不過多頭組相對同窗口0050仍落後約0.47／4.36百分點，而且它只涵蓋20日109個急漲中的45個，不能當成所有行情唯一的必過條件。

外資連買在2022–24短期有較好描述性結果，到了2025–26沒有延續；投信連買也沒有穩定改善。即使只在均線多頭組內比較，2025–26前五日外資與投信同淨買的20日均漲幅為+0.47%（48個已知），未同買為+6.08%（200個）。因此不支持把「三大法人／外資投信同買」直接加成必過門檻。這不是法人賣超造成漲幅的證明，也不能從負面條件反推做反向交易。

條件在T與T−1的完整敏感度、20／60日、早／後期、條件真假及未知數都在 `statistics.csv`。本輪未用結果挑最佳連買天數、買超張數或均線長度；自營商分項作進出描述，沒有事後新增自營商門檻搜尋。

## 資料處理、限制與重現

- 分類依[FinMind法人資料文件](https://finmind.github.io/tutor/TaiwanMarket/Chip/)：外資加上外資自營商，自營商自行買賣及避險分項合計；分項缺失則合計未知。自營商避險買超不能直接當成主觀多頭意圖。
- 初版遇到13檔歷史的合併Dealer／興櫃口徑，明確停止，尚未產生結果。修正後保留2,171個不支援的stock-day並將全部法人特徵標為未知，沒有混入上市櫃五類口徑或刪掉補0。原始資料保留。這是落實原規格的市場範圍，沒有看結果改策略條件。
- 買賣股數必須非負整數、分類唯一。缺交易日不能跨越計算連買或滾動合計；零淨額與缺值不同。連買長度上限20，顯示至少20；前面缺日造成無法判斷精確連買長度時為未知，但最近三日都確定淨買仍可判定連買至少三日。
- 補資料3次請求，0重試，走共用FinMind限額；研究本身兩輪均離線、無DB寫入。沒有新增排程，沒有繞過TWSE來源暫停。
- 規格先提交 `77e5108`；兩輪完整研究各49.071／49.470秒，8張CSV一致。3個截點各截斷／改寫未來，共6組、每組價量及法人特徵檢查通過。試驗帳登錄兩輪全部固定比較。
- 歷史修訂、還原價版本、現有公司快照存活者偏差與當年名冊、法人子集選樣仍限制推論。60日窗口、同股和日期會相依；沒有以小樣本p值宣稱新因子有效。
- 本輪沒有新帳戶淨報酬、最大回撤或扣費勝率，既有實戰資格不變。
