# 五檔策略：次日限價與逐筆成交實測

結論：工具已能把目前五檔策略套入事前固定委託、逐筆穿價量與完整帳務重播。
但**本輪固定「前日參考價限價」的執行方式沒有跑贏0050，不採用為實戰策略**。
這不是已找到可穩健獲利策略，也不能宣稱所有回測漏洞均已消除。

## 這次改好的部分

- T收盤產生訊號，T+1即可委託，沒有多延一天。所有股數、限價及現金保留在讀取當日逐筆前固定。
- 只算09:01之後、13:25之前嚴格穿過限價的成交量；同價不假設排隊成交。
  每股每天只能使用一次成交量。買單當日未成交就取消；賣單未成交仍保留持股與曝險。
- 沿用五名額、前日資金鎖定、餘股保留估值、餘股名額釋放及5%曝險限制。
  不足一張的嘗試也依原資源規則保留名額與預算，修正了新接合層原先漏鎖預算的邊界問題。
- 獨立核對實際來源的前日價格、前20日均量、訊號日期、現金、成本、整張數量及逐筆雜湊。
  缺資料時停止該組，不把半段回測當成完整報酬。
- 畫面可選「策略驗證 → 五檔次日限價實測」，查看一般／壓力與0050，下載計畫、成交和核對帳本。
  來源不變時重用驗證快取，避免每次切換組別都重算回測或重抓資料。

## 為何日線報酬無法保留下來

同一批454個訊號中，兩帳戶共有57次相同進場事件；原日線另有34次進場，逐筆組另有32次。
這不是「少兩筆交易」而已，早期成交不同會改變後續名額、資金與持股。

| 例子 | 本輪可核對的差異 |
| --- | --- |
| 3105穩懋，2026-01-09 | 前日限價內的穿價量不足，未買到；原日線帳戶該股全期貢獻約75.37萬元。 |
| 4958臻鼎-KY，2026-03-27 | 逐筆帳戶當時已滿名額；同年7月另一訊號又遇到整張預算不足。 |
| 6488環球晶，2026-04-28 | 逐筆帳戶當時已滿名額，原日線帳戶有買進。 |
| 2888新光金，2024-09-04起 | 出場首日沒有成交，首次整張成交在2024-09-24，間隔13個市場交易日。 |

一般組有24個出場事件的首次成交晚於首次賣出嘗試，最長13個市場交易日。
因此「出場訊號已觸發」與「已賣出」現在明確分開；沒有把未成交部位刪掉。
以上是帳戶路徑對照，未做單獨因素的因果歸因，也未據此回頭調參。
