# 公司行動條款核對與恢復結算 — 2026-09-12

先前公司行動檢查可以找出差異，但資料源修訂或單純整數分割，即使人工已核對條款也會一直被擋。本次新增有來源版本依據的人工核對紀錄，並讓新收盤檢查採用核對後的條款。核對不會自動產生成交、股息或股數，也不會修改既有權益。

## 使用方式

工作台「策略驗證」→ 選擇策略／0050帳本 →「依公告核對條款／處理資料修訂」。

1. 輸入代號、除息／恢復交易日、交付日及每股股息或分割比率，附公告連結、標題、含時區發布時間、相關文字與核對人。
2. 先按預覽，畫面列出將保存的版本及仍未解決的問題。修改表單後須重新預覽。保存只增加一筆核對紀錄，不入帳。
3. 如當日可登錄，下載自動計算的權益草稿，檢查後在既有公司行動區匯入；實際交付紀錄仍另行登錄。過去除權息日、已有當日成交、舊委託未取消或重複權益，均受原引擎限制，不產生可匯入草稿。
4. 當資料和帳本一致、沒有其他阻擋，再使用原本的收盤結算操作。來源完整性仍需人工核對。

公告真偽及全文正確性未自動認證。這是明確標示的 user-reviewed 證據，保存相關文字與SHA256以供回查，不把HTTPS連結當作已確認的官方事實。

## 生效與失效規則

- 僅處理現金股息、無碎股且交付日等於恢復交易日的分割／反分割。股票股利、減資、面額變更、混合事件等仍不支援。
- 核對綁定該帳本、股票、日期、權益種類及當時觀察到的來源內容；重新抓取相同內容不失效，條款改動或來源刪除則失效。舊來源與舊核對紀錄保留，新核對明確記載 supersedes。
- 保存前重新比對帳本尾端雜湊與來源內容。預覽後有新成交、其他帳本事件、來源過期或修改，均須重新預覽。完全相同命令重送不增加事件；不同內容不可冒用同一編號。
- 現金股息可解除政策／結果不一致、缺日期等來源差異，但核對後仍重新檢查除息前股數、帳本每股金額、總額與交付日。漏登或舊帳不同仍阻擋，不直接覆寫。
- 分割的來源參考價不直接轉為比率。還檢查停牌期間是否錯記成交、分割後是否整數股，以及新股交付。交付前原股數不增加、估值仍受阻；同日混合現金權益也不放行。
- 缺資料、來源過期或schema錯誤不能藉人工條款豁免。完整官方公告覆蓋及券商證據仍未完成，`coverage_complete=false`、策略未取得實盤資格。

例如0050官方2025-06-17公告同時提供四倍比率、停止交易期間及6/18換發／恢復交易資訊，因此核對應依完整條款，不能僅由兩個參考價格的商數推算。[TWSE公告](https://www.twse.com.tw/zh/ETFortune/announcement?company=A00005&date=20250617&fund=0050&seq=1&type=other)

## 驗證與實際狀態

新增15項測試：現金核對及應收漏登、分割未交付、碎股、來源修改與刪除、相同內容刷新、預覽期間帳本改變、舊權益不符、資料缺漏與過期、停牌成交、混合權益、不合法證據、禁止倒填、扣費NAV中性，以及先預覽再保存的UI流程。

- `make pipeline`：兩次成功重跑。

CLI先將含 terms / evidence 的JSON交給預覽，再把輸出的 command 保存：

```bash
python scripts/portfolio_forward.py corporate-preview --report terms.json > preview.json
python scripts/portfolio_forward.py corporate-resolve --report preview.json
```

停牌期間的每日估值及缺失收盤仍未修復；即使恢復交易日能完成結算，缺少共同期間每日NAV仍會使前向比較無法通過。

不正確的舊權益／成交仍須另設有會計依據的修復流程；本次不提供任意沖銷或重寫歷史帳本。也沒有新增策略回測報酬或證明可實戰。
