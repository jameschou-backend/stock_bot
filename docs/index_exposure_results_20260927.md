# 指數曝險與固定趨勢的完整現金帳戶實驗

200日趨勢＋75%正二，在八種成交壓力下的**全期累積**報酬都高於同成本0050。
但鄰近參數、逐年和滾動一年門檻沒有通過，不能宣稱已有穩定優勢或實戰資格。
固定75%正二對照也贏過0050，主要收益不能全部歸因於趨勢判斷。

2022/01/03–2026/09/09，100萬元複利。單一00631L、整張成交、閒置現金、
不借款，固定目標75%；0050僅作訊號及比較帳戶，不買作閒錢停泊。
00631L是單日兩倍曝險商品，75%資金配置不能解讀為75%市場風險。

所有訊號均早於執行日，股數先規劃且延遲時不向上增加；依官方分割公告換股除外。
費用另計0.1425%、最低20元，ETF賣出稅0.1%，股數不超過當日量與前20日均量
較小者的1%。已計成本不代表已重建盤中真實排隊與成交。

壓力末值3,473,437元，包含現金845,637元與持股2,627,800元。
一般24筆買賣、費稅滑價65,294元；壓力19筆、91,573元。未強制末日清倉，
報酬包括未實現部位，不是全部已落袋損益。

200日版本比不判斷趨勢的75%正二對照，多出5.68及3.55個百分點，並降低回撤。
這個歸因只適用同一固定歷史與規則，不是未來績效承諾。

穩健性仍不足：

- 主規則正常／全部壓力的滾動252日超額勝率為53.56%／50.62%，均低於60%門檻。
- 2022–2025四個完整年度，正常僅2年贏0050，全部壓力僅1年；2026是未完整年度。
- 180／220日沒有保持八情境全勝，不能只挑200日版本的數字作結論。
- 32組帳戶的月超額報酬區間下界全部未高於0。主規則正常的年化超額／追蹤誤差
  0.221，配對6個月區塊、2000次重抽的95%區間為[-0.430,0.980]；壓力0.179，
  區間[-0.489,0.890]。這是描述統計，未修正整段研究選擇偏差，DSR仍不可確認。
