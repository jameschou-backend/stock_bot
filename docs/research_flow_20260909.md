# 投信與放量實測結果（2026-09-09）

本輪完成四種規則、兩種成本，共八組固定對照。結論：這組月頻「接近新高 + 投信 / 放量」沒有勝過同期間 0050，新增條件也沒有提高全期報酬。這不等於證明所有動能、法人或基本面策略都無效；本輪還沒有加入營收、季報、產品出貨及量產事件。

## 這次排除了哪些錯誤

官方公司名冊包含 1,974 檔四碼普通股；其中 1,972 檔有本輪還原行情，3718、7835 沒有，未虛構價格。快照共 4,489,978 筆行情。用正式上市櫃日期遮蔽 258,657 筆上市櫃前行情，指標暖身同樣受到限制；名稱含 `-DR` 的存託憑證亦排除。

例如官方資料中的 3592 瑞鼎上市日是 2022-01-07，7610 聯友金屬上市日是 2025-09-09。前輪用了更早行情；本輪不再允許那些資料進入排名或回看窗口。7610 在本輪終點尚未累積 252 個上市交易日，因此不會通過一年高點條件。

因此不能把前輪接近新高的 +245.39% 與本輪 +49.44% 當成只換了一個選股參數：股票身分、存託憑證、正式上市櫃期間與當前名冊均有變動。先前的高回測報酬不能直接視為可實現收益。

## 法人覆蓋、成本與持倉診斷

- 本機投信快照 3,651,119 筆。全股票有效報價日中，85.86% 有法人列、66.97% 有連續 20 日資料；缺失較集中在較早年份及上櫃。逐年逐市場完整數值保留在 JSON。
- 真正通過價格條件的月末候選共有 9,712 個「股票 × 信號日」，其中 154 個（1.59%）缺完整 20 日法人資料，投信組未放行。缺資料與沒有買超分開處理，但仍不能完全分離資料可用性與投信條件的影響。
- 投信淨買賣股數的絕對值大於同日成交股數：0 筆；這是單位／異常檢查，並不代表全部來源已逐筆對帳。舊 ingest 曾把缺分類補零、歷史可能有修正版本，這輪不能反向還原缺失分類。
- 年化單邊換手約 10.18、9.76、8.67、2.19 倍，依當日收盤 NAV 估算，已包含期末平倉。累積支付成本分別約為初始資金的 103.1%、100.1%、68.8%、24.5%；這是多年加總，不能當作每年費率，也不能再從已扣費報酬重扣。
- 四組平均持股數為 9.83、8.99、6.93、1.73。投信與放量一起限制後，平均 82.6% 現金，回撤降低很大部分與低投入比例一起出現，不能直接叫作更準的選股。
- 價格對照前三大獲利來源為 5314 世紀、6150 撼訊、8937 合騏，合計占全部正損益的 8.52%。投信組為 2383 台光電、3163 波若威、3030 德律，占 10.73%；正損益比例不同於占淨利比例，虧損股票仍計入總績效。
- 使用當前產業分類觀察，價格組曾有單一產業占約 83.8% NAV，不能將其表現全歸因於一般選股因子；此分類尚非歷史產業分類。
- 四組期末均無未平倉部位。價格組及放量組分別有 20、6 個缺還原報價的持股日，按最後可得價格估值；投信兩組為零。持有期間還原價單日變動絕對值超過 50% 的紀錄均為零，仍不等於還原價全部正確。

## 效能與重現

初次從 MySQL 匯出法人是一次性準備，SQL 約 10.5 秒；所有輸入保存 SHA256，之後重跑只讀 Parquet。最初八組含逐股損益核對約 36.2 秒；移除已出清部位的重複遍歷後為 7.1 秒（含載入及檢查 3.3 秒，不含首次資料匯出和最終 JSON 寫檔）。八組的完整績效、分段與滾動比較均逐項確認相同，沒有為追求速度改變交易規則。

```sh
# 只需首次準備：官方公司名冊 + 本機法人資料，沒有 FinMind 請求
python scripts/research_flow.py --prepare-inputs
# 固定快照離線重跑
make research-flow
```

已有輸入 manifest 時，準備命令只驗證雜湊，不再次讀 DB 或抓資料。缺檔／雜湊改變須明確處理，沒有自動換資料源。新環境仍需前輪價量快照及三個修補檔，詳細步驟見 `scripts/research_rules.py --prepare-inputs`。

本輪研究查詢 FinMind **0 次**；依專案規範執行日常 pipeline 驗收的請求另計。UI「策略驗證」已新增兩種滑價下的四組對照、現金比例、分段與滾動比較，以及摘要下載。頁面讀取不啟動回測。

## 限制與下一個研究問題

當前公司名冊仍有存活者偏差，轉板前的舊板別行情也被保守排除，尚未建立含已下市股票的完整歷史資格表。還原價尚有與官方資料的對帳問題；股息採合成還原單位，未包含最低手續費、整股／零股限制、實際資金容量及所有漲跌停成交細節。歷史已被使用，這不是未見測試集。沒有策略被切換為實盤合格。

本輪不支持繼續將條件疊得更嚴。下一個有區辨力的問題是：有可追溯時間的營收加速／本業改善，能否讓價格訊號提早或提高有效性；以及排名略降就整批更換，是否傷害原本仍持續成長的部位。兩者應各自事前登記、各自對照。產品出貨／量產事件仍需原始公告時間與後續驗證，不用今天的消息倒填過去。
