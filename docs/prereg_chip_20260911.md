# 籌碼研究預先規格（2026-09-11）

本規格在新籌碼條件的報酬計算前固定。沿用封存 technical 研究的458個候選、280檔股票、2022-01-03至2026-09-09、100萬元複利、三個名額、閒置0050、63交易日／12%停損、原整股與零股容量、全部原稅費與滑價。只用訊號日收盤後可得資訊，次一市場日執行。候選已反覆研究，有存活者偏誤；不稱為未見樣本或可實現績效。

## 固定比較

- control：完整原候選。
- trust：最近5日投信淨買／5日成交股數至少1%，5日中至少3日淨買，且大於此前不重疊20日淨買／成交股數。
- foreign：與trust相同，改用外資（含本機既有外資自營商合計）。
- price：訊號還原收盤不超過20日均線10%。
- trust_price、foreign_price：上述單因子交集。
- holder：大於400張的持股比例較四個週觀測前增加至少0.5百分點。排除total及差異調整，15級比例總和須在99.5%至100.5%。觀測日加7日才可用、最多陳舊21日；另固定14日延遲敏感度。週距須21至35日。
- margin：融資餘額較20市場日前減少，需完整21日；不將減資、除權造成的單位變動認作去槓桿，前後還原因子變動超過2%視為不可判讀。
- holder_margin：holder與margin交集；holder14_margin為公告延遲敏感度。
- sbl：真正借券賣出餘額較20市場日前下降，同樣完整21日及公司行為防護。借券成交明細不能替代此欄。
- broker：訊號當日分點先按券商代碼加總不同成交價，再取前五大正淨買股數／全部分點買進股數至少10%；全體買賣股數須相符（容許0.1%差異）。此為單日集中度，不宣稱主力身分或持續吸籌。
- group_flow：使用原候選當時固定的價格族群及已封存成交值占比證據，最近5日均值高於之前20日。不是用今天的產業鏈名單回填歷史。
- sell_full、sell_half：保留完整原候選；外資＋投信最近5日淨賣／5日成交量小於等於-1%，而此前20日淨買為正，觸發次日全出／每個部位僅一次減少當時可交易股數的一半（向下取整）。原停損／到期出場優先且不得延後；減碼未成交部分後續重試。

缺資料是unknown，不能當零。進場篩選的unknown排除，並各加一個「相同資料可得樣本、無訊號篩選」帳戶對照，避免把覆蓋差異誤認為優勢。出場缺資料沿用原退出規則。所有訊號值與拒絕原因保存。研究中不改門檻，不依結果剔除差的年度。

## 交叉檢查

1. 完整帳戶逐日對帳；control與原封存帳戶必須完全相同。若新路徑缺公司行為或交易證據，該組明確停止，不能假設免股利／可成交。
2. 每組報淨報酬、年化、回撤、費用、股票部位數、年度結果、0050及同覆蓋對照。
3. 同458候選事件研究：次日還原收盤到第63市場日還原收盤，扣股票／ETF各自比例稅費及雙邊滑價，比较0050；末端不足63日不混入完整期間。此是訊號診斷，未模擬最低手續費、資金名額、成交量、停損或精確股利現金，不冒稱帳戶報酬。
4. 每個篩選，對相同可得資料中通過／未通過的事件比較，按進場月份以連續3個月區塊重抽2000次；同時報樣本數與各年度。區間僅探索性，未修正多重試驗，也不消除候選事後挑選偏誤。
5. 固定對control、trust_price、holder_margin、sell_half使用相同20組每日候選隨機排序（種子20260911起），沿用完整帳戶引擎，報相同種子的淨值差及胜出比例。這只檢查名額路徑敏感性，不證明統計顯著。若資料證據不足，保留失敗原因。
