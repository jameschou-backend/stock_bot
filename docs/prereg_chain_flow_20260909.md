# 族群資金觀察：2026-09-09 研究規格

在取得完整 25 日比較結果前固定以下定義。本次為盤後描述與資料驗證，不測試或宣稱交易績效；不調整生產選股模型。

- 比較日取本機最新完整交易日，抓最近 25 個本機有交易紀錄的日期。日期若缺供應商資料即報錯，不跳過補成連續。
- FinMind `TaiwanStockIndustryChainMoneyFlow` 一次一天；總計列與子產業分開，禁止加總不同產業鏈占比，因成分股重疊。
- 最近 5 日平均成交占比，對照前面不重疊的 20 日平均占比，報告百分點差及倍率。資料本身為成交金額分布，不代表淨流入。
- 公司名單採 `TaiwanStockIndustryChain` 現行分類並明示更新日；總計成分先去重。歷史流向也是現行分類回溯，不能當作當年已知族群。
- 用當日 `TaiwanStockPrice` 原始成交金額計算最大一檔占比、扣除最大一檔成交金額；用收盤高於開盤的家數比例觀察當日盤中擴散，不當成含息報酬或前收盤漲跌。
- 最近 5 日投信與外資分開列：完整分類的淨買股數 × 當日收盤價，只是金額近似值；不混入自營商或當成真實法人成交金額。缺一日或類別就不產生完整 5 日數值。外資含 Foreign_Investor 與 Foreign_Dealer_Self，任一類別缺少則該日未知。
- 各族群法人近似金額／成交占比須揭露可用成分覆蓋。成分成交金額與供應商族群總額差異超過 2%，或成分行情覆蓋低於 95%，不出「資金確認」判讀；保留差異供排查。法人完整股票覆蓋低於 90% 同樣列為資料不足。
- 訊號欄位僅為描述：成交占比是否增加、當日收紅是否過半、完整成分的法人估計合計是否正值、最大一檔占比是否超過一半。沒有最佳門檻搜尋，沒有合成買入分數。
- 研究涵蓋全部供應商產業鏈總計，並預先觀察記憶體 IC、光通訊設備、伺服器、散熱，以及無線通訊設備。無線通訊分類含衛星但不是純低軌名單，不強行映射。
- 新聞只讀上一輪已保存的分析，保留供應商日期與首次取得時間。產業鏈關聯及同名題材不是訂單或獲利證明。

預算：初次至多 25 次產業鏈流向＋1 次成分＋1 次當日價量＋5 次法人，共 32 次請求；另有前置 API 探查 1 次只取到近期變動成分的查詢。已取得資料重用日快取，額度不足立即中止並保留完成檔案。後續每日新增流向、價量、法人通常約 3 次，分類快取依有效期更新；初次準備與正常更新須分開報告。

新聞抓取沿用一天一筆全市場新聞、近兩日一小時快取、較舊日期一天快取、最多 14 天一次、錯誤不自動重試的既有路徑。不在本次自動回補全部歷史、不啟用定時排程。
