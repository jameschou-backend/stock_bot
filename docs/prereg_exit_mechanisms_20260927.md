# 完整現金帳戶上的出場機制比較

先固定這份規格再執行結果。沿用454個歷史身分修正後候選、前20日成交金額排序、5個名額、100萬元複利、整張成交、閒錢現金、餘股保留及全部資源鎖定。候補兩日與波動率縮倉均未採用，不疊加。期間2022-01-03至2026-09-09。

七種機制使用既有純函式 `decide_exit` 的原參數，不掃描新閾值：

1. `loss12`：既有對照，收盤訊號跌12%或滿63個市場日退出。
2. `fixed63`：僅滿63日，移除12%價格停損。
3. `trail20_12`：漲20%後距持有期高點回落12%，或滿63日。
4. `weak20`：連續兩日低於20日均線且20日相對0050報酬為負，或滿63日。
5. `market_weak`：0050連續兩日OFF且個股20日相對報酬為負，或滿63日。
6. `trend126`：63日仍符合既有強勢條件則逐日延長，最多126日；沒有額外價格停損。
7. `adaptive`：既有12%停損、漲20%後回落12%、個股／大盤轉弱、強勢延長四種判斷，最多126日。

以上用還原收盤價訊號，並非保證以停損價成交。每次只讀實際退出日前一市場日，訊號一旦觸發便維持待賣；延遲壓力再加一天，不隨行情反彈取消。配股未交付仍保留應收，交付後繼續執行原出場。既有趨勢、還原價、現金股利稅費與日線成交估計限制全數保留。

7機制×8種滑價／進場／出場延遲情境，共56帳戶；每一機制全數揭露，包含失敗或資料阻擋。loss12八帳戶須逐欄重現已發布餘股帳戶。每個完整帳戶重建出場訊號、觸發及成交時間，另驗證資金、股數、名額、整張限制。每次執行均記錄trial registry；兩輪離線重跑完整比較。禁止缺資料就跳過持股、猜股利付款日、覆蓋失敗結果或以部分帳本報完整收益。

候選通過歷史篩檢須：八種情境均超過同成本0050、八組最大回撤均不超過50%；正常與全壓力情境的252日滾動超額勝率均至少60%，2022～2025至少三個完整年度有正超額。這是已研究過歷史的比較，不是未見樣本；即使有機制通過，也不自動給實戰資格或將其回測報酬當作可保證收益。若有候選通過，參數穩定性及完整候選統計校正仍須另驗。
