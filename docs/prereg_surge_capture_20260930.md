# 現行選股的急漲涵蓋與漏選歸因：固定研究設計

2026-09-30，於本輪統計前固定。僅診斷既有帳戶，不搜尋或採用新策略。

- 範圍：封存 2019-01-02～2026-09-09、2,076 檔個股名冊；0050 僅為比較基準，排除 ETF。這不是已證明完整的歷史全市場。
- 主定義：任一市場交易日收盤至 60 個交易日後收盤，上漲至少 50%，並領先同期 0050 至少 20 個百分點。另固定列出 20 日 +30% 與 120 日 +100%，同樣要求超額 20 個百分點，不挑最好看的定義。
- 每日掃描全部名冊，不先用策略的流動性、分群或訊號門檻篩掉失敗案例。當日市場身分不合格另計；未成熟、期間缺價／身分中斷、雙價格版本不一致、異常跳價另列未知，不能當成沒漲。
- 使用兩版還原收盤。期間每一天須有正價且個股身分合格；每日報酬兩版差超過 0.5 個百分點、任一版單日絕對變動超過 20%，或整段報酬差超過 2 個百分點，列價格待核對。0050 只要求起訖有價及兩版期間報酬一致，不把分割停牌期間填假成交價。
- 同一股票、同一定義：依日期貪婪選最早合格起點，下一事件起點須晚於前事件終點；所有每日標籤另存，避免把連續重疊窗口視為獨立飆股。這是非重疊觀察窗，起點不是事後精準最低點；短暫衝高後回落可能不符合固定終點定義。不同定義不得相加成獨立事件總數。
- 使用 `stock-universe-2019-20260929/signals-v2.json` 的 liquid_universe 訊號。重建每一日的原品質、60 日新高、20 日正報酬且勝過基準、1.5 倍量及大盤 ON 條件，須與 37,993 筆封存訊號完全相符。分群已取消，不沿用舊分群版的漏選結論。
- 訊號範圍為觀察窗起日（含）至終日前一市場日（含），因訊號最早隔日執行。首訊號距起點、已漲幅、終點剩餘漲幅分別列出；前 1/3 窗口內的訊號另計早期涵蓋，不宣稱能買到起點價。
- 與已封存三檔／五檔帳戶逐筆連結；分開列有訊號、有買進、有持倉、實質持倉（窗口內任一天個股市值至少占淨值 1%），以及未成交原因。小殘股不可冒充完整參與波段；原因可重複並存，不能把出現過 slots_full 全當作唯一原因。
- 保留全部正式訊號的 20／60／120 日已知、未知、達標／未達標數，檢查涵蓋與誤選的取捨。「未達急漲門檻」不是虧損；另列負報酬。每筆實際持股列進出日期、原退出原因、買賣現金差（不冒充含公司行動的淨損益）、退出後價格變化。個股全期淨貢獻另含股息、期末持股／應收並與帳戶淨利核對。
- 所有未來價格僅用於標籤與事後診斷，不重新產生買賣。沿用已知樣本，`unseen_validation=false`、`live_qualified=false`；本輪沒有新策略報酬。研究程序禁止網路，保留來源／輸出雜湊，兩次獨立重算須一致。
