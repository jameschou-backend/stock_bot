# 整張開盤＋零股日行情估算：固定規格

結果前登記，2026-09-28。沿用 opening-entry 的 454 筆訊號、100 萬複利、五個個股名額、閒置現金、原停損與 63 日出場。新增零股，不重新選參數；保留原整張版作對照。

T 收盤選股，T+1 08:59 計畫，整張參與原開盤成交估計；餘數 1～999 股獨立於 09:00 送盤中零股限價 ROD，保留整個盤中零股時段。高價股不足一張也可買，賣出與配股殘股同樣支援零股。整張未成交部位不得改拆零股追加。買進按當日官方漲停上限加兩通道成本預留資金，總股數不能看到當天開盤或零股行情才決定。當天賣款不能增加早上買進預算，名額仍維持原規則。

零股不是普通盤開盤。已有官方盤中零股日行情，缺完整撮合序列。本輪僅做日行情估算：零股買價上限為當日合法漲停價，賣價下限為當日合法跌停價；僅當整天零股最高价严格低於買限價、或最低價嚴格高於賣限價時，才計入全日量。碰到邊界或跨越不確定即不計成交，不拿整張量補足。估計買在零股當日最高價、賣在最低價；這是事後核帳的保守價格界線，不可用來決定當日是否下單、股數、排名或資金。

每次零股子單最多 999 股，容量為官方盤中零股全日股數的 1%（壓力 0.5%），向下取整。不同通道獨立最低佣金、稅與每邊滑價 45 bp（壓力 90 bp）。未成交買單當日失效，退出訊號維持鎖定並隔日重新計畫。日模型不保證排隊成交，也不是所有可能路徑的數學下界。
