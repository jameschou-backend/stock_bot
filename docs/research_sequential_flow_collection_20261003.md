# 法人原始資料補足：運算結果前的資料收集補充

原五項規則不變。第一輪離線原始回應盤點（685份、約3,831萬列含重複版本）發現原訊號1,329檔中1,255檔至少缺一個需要的訊號前日期；既有1000次準備上限明確停止，沒有發出新请求、沒有計算法人績效。

為公平涵蓋全部原訊號，本次收集上限改為「每個原訊號股票至多一次，共1,329次」。每檔區間只依已封存T−1及T−3所需5日窗口的缺口起迄，不讀報酬或勝負。實際計畫1,255次，4個並行工作、0自動重試、共用FinMind6000/hour配額的90%保護上限；每份成功來源立即存檔，重跑不重抓。

不同原始版本衝突一律未知，不以新資料覆蓋成有利結果。缺分類不填零；DB舊匯入曾將缺分類與無法解析數字填零，因此不用DB聚合欄位做這次研究。這是資料涵蓋的調整，不是策略門檻調參，且不代表歷史首次公開時間已核實。
