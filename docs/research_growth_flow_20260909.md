# 研究目標：以成長事件、量價及法人訊號尋找超額報酬

2026-09-09，依使用者本次確認：最終目標是找到扣除成本後能勝過大盤或 0050 的策略；可以承擔較大波動，可以不用預測模型。這份是下一階段研究設計及資料盤點，不是已回測的新策略，也不改寫前輪實驗結果。

## 成功標準

主基準固定 0050 買入持有，另列台灣加權報酬指數作市場參照。兩者都要處理配息／還原口徑；若沒有可信加權報酬指數，不用不含股息的價格指數冒充。不得在看到結果後挑較容易贏的基準。

比較同一起訖、資金投入、現金與費稅假設下的終值、年化報酬、最大回撤、換手及滾動 12／36 個月勝過 0050 的比例。滾動窗相互重疊，不能當成獨立樣本。觀察多空年度、產業集中、最大獲利股票貢獻，辨識是否只是較大市場曝險、單一產業行情或一兩檔股票造成。

「持續勝過」不定義為每一天或每一年必贏。歷史探索勝出後仍須成本壓力測試、固定規則的新向前紀錄；現有歷史已研究過，不重新切分成假裝未見的測試集。尚未有任何候選通過實盤驗證。

## 兩條策略路線

### A：營運成長已開始反映

假說：營收／本業獲利成長加速，價格維持強勢，配合持續買盤或突破放量，可能比只按漲幅選股更有效。

| 層次 | 要觀察的證據 | 設計要點 |
| --- | --- | --- |
| 營運成長 | 近三個月合計營收對去年同期成長、增速是否加快；季度營業利益率及本業獲利變化 | 用相同月份比較季節性；排除低基期或一次性處分收益造成的假轉強。不能只看本益比低或「公司很好」。 |
| 價格趨勢 | 股價相對 0050 強弱、接近歷史高點、均線與區間突破 | 衡量市場是否已開始反映改善，並記錄距高點／均線多遠；不把已漲很多直接等同剩餘上漲空間大。 |
| 投信／外資 | 多日買超持續性、淨買股數除以同期成交股數 | 投信也是三大法人之一。分開評估投信與外資，不把自營商避險買盤合成「看好」。絕對張數不利於不同大小股票比較。 |
| 成交量 | 成交量相對前期均量放大，配合突破收盤與收盤位置 | 放量上漲、放量下跌、沖高回落分開；分母使用事件日之前的資料。 |

第一個對照保留修復資料後的價格規則，再依序測「加成長」、「成長＋投信」、「成長＋量價」、「成長＋投信＋量價」。共同股票池、持有／出場、成本與時間口徑固定；如此才能知道新增條件是否有貢獻。外資先作獨立診斷，不一開始與投信任一條件成立就合併。

不把所有條件一次設成必須成立，也不先指定一套湊成 100 分的權重。少量明確假說比大範圍調參更能辨認效果。訊號週期、門檻、持股數及退出規則在資料驗收後另作事前登記，產生下一輪績效前鎖定；不由本輪好看股票倒推。

### B：產品出貨、量產或虧轉盈的成長轉折

這裡「出貨」解讀為公司產品交貨／營收認列。假說是可查證的營運事件可能先於完整財報反映，因此不能把「目前 EPS 必須為正」當成這條路線的共同入場限制。

事件按證據分層：公司已公告的訂單、量產、交貨或新產能進度；管理階層對未來的預期；第三方推測。至少保留股票、原始來源連結、首次公開時間、系統首次觀測時間、事件類型、預期時程、已實現／尚待實現、後續確認或延遲。缺少原始來源的題材列為待查，不當成已證實訂單。

公司預告出貨不等於收入已認列；收入增加也不等於本業獲利增加。用之後公布的營收、毛利／營益率、存貨及應收帳款追蹤事件是否兌現。這些未來結果只能用作後續驗證／出場資訊，不能倒填成當初已知的進場依據。

第一階段建立有時間戳的事件觀察帳及向前名單，不把今天看到的法說內容回填進十年歷史。文字工具可以協助擷取證據，但不能讓它憑新聞情緒直接決定買入，或根據已知未來股價標記「成功題材」。此路線與 A 分開評估，成熟後才檢查是否互補。

## 執行順序與效能

1. 先完成歷史交易資格、還原價格及公告可用時間的資料門檻；辨識錯誤單位、缺失月份及修正版本。已知缺陷不能靠增加模型或評分條件掩蓋。
2. 用現有法人及價量資料建第一條路線的有限對照；營收只在資料口徑能支持的期間使用。輸入一次載入及矩陣化，各實驗共用；輸入摘要與規則版本固定。前輪六組價格研究約 4 秒，不把這個數字當較複雜新研究的保證時間。
3. 季報先小樣本對帳，再按確實需要的公司／期間增量補齊；官方支援的全市場日期查詢優先。先估請求再回補，共享本機 5,400／小時額度（Sponsor 6,000 上限、保留緩衝）；不另裝繞過額度的查詢工具。
4. 事件路線優先收集候選的官方資料與向前結果。畫面每檔呈現「成長依據、事件與日期、量價、法人、仍待確認、失效條件」，而非只給一個看不懂的總分。

本次研究盤點只讀本機資料，使用 0 次 FinMind 查詢；依專案規範執行 pipeline 驗收的日常更新另計。未跑新的績效搜尋、未更換每日策略。這份文件完成研究目標與方法設計；資料修復、下一輪事前登記、對照回測及向前事件帳仍是後續工作，不能說已完成。
