# 單一連續帳戶回測

在「策略驗證 → 指數曝險與趨勢 → 2016–2026連續投入 → 查看連續帳戶交易與資產」選規則與成交情境，再按「再次驗證這組回測」。

期間固定 2016-01-04 至 2026-09-09、本金 100 萬、現金延續；規則限已公布的四組及八種壓力。不改策略、不更新行情、不下單。所有資料、程式與規則內容每次都核對雜湊；不只看檔案修改時間。

第一次計算所選帳戶；之後來源及程式版本完全相同且完成紀錄有效時可重用。勾選「忽略已完成結果，重新計算」可強制重跑。來源異動不會假裝沿用舊結果；需準備新的研究資料。現有工作尚未結束時不重複啟動，進度與完成檔可跨工作台重啟保存。

每次新執行重新稽核全部每日現金、股數、費用、委託和前日訊號，並逐欄比較已封存帳戶及所有判斷。快取命中也比較完整結果。重用計入 `reused_cases`，不虛增新試驗次數；新執行／失敗另登記。資料與完整源碼內容校驗仍需時間，快取不等於跳過資料檢查。

完成可下載完整帳戶。`live_qualified=false`、`strict_data_ready=false` 和所有資料限制仍保留；重現成功不是未來勝率或真實成交保證。

CLI：

```sh
python scripts/run_index_case.py --arm equal --mask 7 --fresh --output .cache/index-case-backtest/example-new.json
```

輸出路徑必須尚未存在。歷史研究發布檔不會被覆寫。
