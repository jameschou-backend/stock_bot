## 模組與可回測介面

- `skills/strategy_scanner/catalog.py`：策略與研究模組清單。每項有穩定 ID、版本、規則、資料需求、来源、適用情境、實作狀態。出場、配置、排名、執行假設各自分類，不灌成多個獨立選股策略。
- `data.py`：讀取指定封存資料包、驗直接輸入檔雜湊、批次載入全部股票。沒有逐檔 API 迴圈，也不從現有持倉反推候選池。
- `engine.py`：一次算共同歷史指標，再套用多個規則。每個股票×日期×已啟用策略都有符合／未符合／資料不足／不適用結果；不因現金或名額跳過。尚未移植的模組明示只收錄。
- `scripts/scan_market_strategies.py`：有限次離線掃描，輸出 `scan.json`、`entry-signals.json`、摘要、HTML 與輸入／輸出雜湊收據。`entry_events` 只匯出進場類規則的全部命中事件（排名／篩選明確拒絕匯出成進場事件），供後續同一帳戶引擎比較。這次不把歷史帳戶重命名成新策略績效。
- `presentation.py`／`ui/multi_strategy_scanner.html`：日期、個股、策略篩選與逐條理由。新頁獨立，不改原訊號日曆和封存回測。

`scan_market` 的依賴只有截至指定日的行情、市場交易日曆、具日期的股票資格、原完整候選帳與可選 POC 證據；沒有資金、部位、未來報酬或最佳策略標籤。`regime_fit` 只是當日情境是否符合事前描述，**尚不是已驗證的策略切換器**。不能看股票事後漲跌，再挑表現最好的一套回填歷史。

## 已固定的第一批規則

| ID | 規則及角色 |
|---|---|
| original_breakout | 原封存突破量增完整候選帳；保留原候選定義，不使用只含已成交股票的帳本 |
| original_red | 原候選＋訊號日收盤高於開盤 |
| poc_red_priority | 原紅 K 候選；POC僅是排序參考。未知 POC 不等於已上移，也不取消原候選身分 |
| poc_up_red | 另立研究規則：原紅 K 候選，且先前20日分成前後兩半的POC上移。資料不全顯示未知 |
| momentum | 沿用中期動能研究：21日前／126日前價格−1>0，收盤>120日均線 |
| risk_momentum | 同動能資格，以動能／126日年化波動作該策略自己的分數，不跨策略直接比較原始分數 |
| near_high | 收盤距252日最高收盤≤5%，MA60>MA120，63日報酬>0 |
| contraction_breakout | 前10日高低區間≤再前10日區間的75%；今日收盤突破前20日高點，量≥前20日均量1.5倍 |
| donchian20 / donchian55 | 今日收盤突破前20／55市場日最高價，通道不含今天 |
| bollinger_reclaim | 昨收低於昨布林下軌，今天收紅並收回今天下軌內；布林為20日、母體標準差、2倍 |
| ma_pullback | MA20連續兩日在MA60上；今日低點≤MA20×1.01，收紅且收盤>MA20 |

八項新的技術掃描（momentum至ma_pullback）共同要求20日平均成交值估算≥5,000萬元。這裡是`原收盤×股數`的日成交值**估算**，不是交易所精確成交金額；不可當成指定價位的可成交量。原封存候選沿用它自己的原流動性規則，不暗改成上述新門檻。

全部以還原價格比較跨日走勢、同日原價比較紅K；不填補缺失交易日、不用之後的資料補前面的洞。兩份調整價格單日報酬差超過0.5個百分點的觀測標為未知；這只是資料診斷，不宣稱两个來源一直獨立。當日行情／身分缺漏保留統計。

`first_signal` 指該策略連續符合區間的第一個交易日；前一日未知則首次也未知，不能因本次查詢只看一天就當成首日。預設匯出全部訊號，回測可另選首日事件；不強迫滿倉。

布林定義與限制參考 [John Bollinger本人規則](https://www.bollingerbands.com/bollinger-band-rules)：碰軌本身不是買賣訊號。本次加入「重新收回＋紅K」是本專案待驗證的組合，不是假稱作者推薦或已證明能贏0050。

網路沒有有限且公認的「所有策略」全集；清單收錄可溯源的研究家族與公開方法，新增策略必須有可計算條件、資料時點、版本及獨立驗證。題材、分點、營收意外、法人吸籌、持股集中等已有研究方向都保留在目錄；若尚缺完整時間戳、日掃描接口或資料，明列缺口，不用日線推測大戶身分或生成假訊號。型態辨識不可使用未來K棒確認過去的轉折點。
