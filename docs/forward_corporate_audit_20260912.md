## 零股資料的結論

官方盤中零股有獨立五檔買賣資訊；其報價與普通整股行情不能混用。[證交所交易制度](https://www.twse.com.tw/zh/products/system/trading.html)

既有歷史來源使用盤中零股日行情，其中的全日成交股數及最後揭示價量不能重建進場時的逐次撮合、排隊順位或可成交深度。本次沒有將這些資料變成自動成交，也沒有新接入盤中零股五檔API。[證交所盤中零股日行情](https://www.twse.com.tw/zh/trading/historical/twtc7u.html)

## 仍未完成與適用界線

1. 同一FinMind供應商不同資料集不算獨立官方驗證。完整TWSE/TPEx/MOPS/投信公告覆蓋、停牌期間及公告修訂時間仍待接入；人工核對不能省略。
2. 股票股利、減資、面額變更、分割/反分割的完整條款與碎股處理尚無自動核准流程。目前識別到便停結算；即使手填分割已交付，也不自動認定來源核對通過。來源修訂也需另行解決，不能用清空快取當修復。
3. 這是UI及CLI新增收盤的護欄，不是權限安全界線；直接呼叫保留的舊 Python 內部函式仍可能繞過新入口。既有收盤、計畫與舊回測不被重新認證；也沒有改寫舊帳本事件。
4. 尚未自動抓取完整零股撮合證據，未證明實際可成交，兩份帳本目前都沒有成交，因此沒有新的前向報酬可比。
