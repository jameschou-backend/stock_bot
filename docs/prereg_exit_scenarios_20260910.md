# 情境出場比較：先固定規格，再計算收益

2026-09-10，依使用者要求，對既有一百萬元、三部位、族群領先股策略加入情境出場。本文件在任何新情境的真實歷史收益計算前建立。不變更原本的進場訊號、排名、成本、容量或閒置資金配置，也不搜尋最佳百分比。

## 相同的比較條件

- 期間2022-01-03至2026-09-09，本金NT$1,000,000，整數股及零股。使用已封存的完整458個進場候選，不只重播原本成交的45個部位。提早出場會釋放名額，因此後續買到的股票與預算可能改變；這是整個投資組合的出場政策比較，不能解讀為相同45筆交易的純出場差異。
- 原始63交易日帳本及0050對照先完整逐欄重現。普通與零股成交、稅費、最低手續費、每邊0.45%滑價、每日量限制、公司行動、剩餘持股及末日應收均沿用原規格。未成交持股占用名額，停損不保證能立即成交或以門檻價成交。
- 賣出所得仍依原規則投入0050。大盤轉弱出場只降低個股曝險，並非整戶空手避險。把閒置資金改成現金須另外對照，不混入本輪。
- 原來源與舊帳本不修改。新零股日期、漲跌停和股利只按需抓取，使用獨立快取，共用FinMind每小時6,000次限額及5,400次保留額度控制；無模型重訓、無全市場重新下載。API失敗不得當成無成交。公司行動資料不足則停止該帳本、補證後原規則重播。

## 七組預先固定的規則

1. `fixed63`：原本持有63個市場交易日後開始賣出。
2. `loss12`：相對買入日還原收盤跌12%開始賣，否則63日賣。
3. `trail20_12`：曾較買入日還原收盤上漲20%後，從持有以來最高還原收盤回落12%開始賣，否則63日賣；啟動後不取消。
4. `weak20`：持股後連續兩個相鄰市場交易日收盤低於20日均線，且最新20日報酬落後0050，開始賣；否則63日賣。
5. `market_weak`：0050連續兩個相鄰市場日處於120日趨勢OFF，且個股最新20日報酬落後0050，開始賣；否則63日賣。
6. `trend126`：前63日不提早賣；第63日起只在趨勢強時逐日延長，最晚第126日開始賣。
7. `adaptive`：先檢查126日硬期限；之前依序檢查12%虧損、已啟動的12%獲利回撤、大盤弱且個股落後、個股兩日破線且落後；63日起趨勢強才逐日延長，最晚126日開始賣。風險退出不等待額外確認。

百分比均為價格訊號，基準是實際買入日的還原收盤，並非實際普通／零股成交價及費用後的個股損益。實際資產損益由原始價、整數股、現金及公司行動帳本計算。

## 時間、缺值與執行

- 今天要不要賣，只能使用前一市場日及以前的資料；買入日收盤訊號最早於下一市場日執行。使用當日實際普通／零股參考價另扣成本，不能以觸發門檻價假設成交。
- 還原收盤採已封存的官方參考價還原矩陣。持股最高價從實際買入日收盤開始，更新至訊號日。每日價格僅接受有限正數，缺資料不能以未來價或前值補出有效退出訊號。
- 個股MA20需要完整20個相鄰市場日。相對20日報酬使用相隔20個市場日的有效正數端點，兩檔任一端點缺失則無相對強弱訊號；中間無交易不改用20次有效觀察。破線兩日必須相鄰、兩日均有價和MA20，且都在實際買入日以後（包含買入日）。
- 0050趨勢沿用原進場定義：當日收盤嚴格高於最近120個有效收盤均值為ON，其餘有足夠資料為OFF，當日無價為UNKNOWN；缺市日不前填狀態。兩日OFF也必須是相鄰市場日。
- 「趨勢強」固定為：訊號日0050是ON、個股收盤不低於MA20、MA20高於五個市場日前的MA20、個股20日報酬高於0050。任何一項缺資料都不能延長。
- 第一次退出觸發後，保留觸發原因、訊號日及第一次可執行日；後續反彈不能取消，成交量不足／跌停則逐日續賣。原63日到期欄位保留，新退出欄位另列。股利配股晚交付也必須承接同部位的退出指令。126日為第一次開始賣的最晚期限，無法成交的殘餘不虛構消失。

## 檢查與交付

- 合成測試檢查控制組完全相同、因果時序、缺值、連續確認、部位狀態重設、不能成交仍保持退出、晚到股票股利與126日上限。
- 七組完整帳本與0050全部逐筆核對現金、股數、成本及每日NAV；首次準備後禁止網路重播，要求帳本完全相同。封存規格、程式、來源與結果雜湊，原帳本仍須通過原本驗證。
- 報告總報酬、期末資產、年化、最大回撤、逐年報酬、成本、買賣筆數及退出原因。列出實際觸发到成交等待、相對原策略的變化及零股最後對手報價深度不足的模擬限制。
