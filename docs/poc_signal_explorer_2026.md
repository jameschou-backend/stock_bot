## 操作

1. 選月份、交易日，再點個股看還原 K 線、量能及訊號位置。可搜尋研究資料庫的個股，也可點帳戶持倉看圖。
2. 「符合本版」排除紅 K 門檻不合格者；「全部原訊號」保留原始候選及排除理由。原序仍是相對 0050 強度，並不代表帳戶必買前三名。
3. 預設「歷史視圖」只顯示選定日以前的行情、成交、單股訊號與累計統計。未來日曆計數隱藏；POC 隔日查詢與執行結果的文字和顏色均隱藏。
4. 切「事後檢討」查看 POC 上移／未上移／資料不足／未評估、進場預約與實際回測成交的差別，以及後續 K 線。POC 數字為原始價，沒有當成還原價直接畫線。
5. B/S 為回測買賣日期標記，原始模擬成交價格、股數、費用、現金變化與原因見下方表格。整股、零股與部分成交分列。
6. 下方帳戶顯示所選日收盤資產、現金、應收款與持倉；2026 接續 2025 年末庫存和資金，沒有重新初始化為 100 萬元。

歷史視圖是研究介面的日期遮罩，不宣稱能復原供應商當時版本或消除所有資料偏差。資料庫名稱與研究期間屬封存範圍；切日期是瀏覽歷史，不是即時預測。

## 接入的規則與結果

候選沿用突破前 60 日最高還原收盤、放量、相對強勢、成交值與市場條件。`poc_red` 額外要求訊號當日收盤大於開盤，再以訊號前 20 日的 POC 上移優先。POC 只顯示該策略確實查詢的結果，不從其他策略偷補；永久品質未知時整日恢復合格原排序，缺必要原始資料則沿用原研究的停止規則。

三黑從進場日起算，須黑 K 且收盤連續遞減；與 12% 停損、63 日期限並存。收盤確認後隔日評估賣出。沒有加入後來表現較差的單純量縮出場。

以下屬 **2024/1/2 至 2026/9/9 全期**，只在事後模式呈現，不能誤讀為 2026 單年：

|---|---:|---:|

來源：[紅 K／量縮帳戶比較](research_candle_volume_account_20261003.md)、[POC 帳戶研究](research_volume_profile_account_20261003.md)。

所有成交均為封存回測模擬，使用日高低中點（HL2）事後代理及既有費用／量能限制；不保證隔日可成交於該價格。普通盤成交與歷史身分／行情證據尚未完整認證，仍 `live_qualified=false`。這次加 UI 不會改變資格。

## 重建

```sh
python scripts/export_poc_signal_explorer.py \
  --output artifacts/reports/signal_explorer_2026.html \
  --payload .cache/poc-explorer-20261003/payload.json \
  --receipt .cache/poc-explorer-20261003/receipt.json
```

模板：`ui/poc_signal_explorer.html`。新工具讀封存快取、驗證父報告與 58,085 個來源引用，再綁定 exporter／測試／模板。缺檔或 hash 不符直接錯誤；不連 FinMind、不寫 DB、不重跑回測。payload 約 30.8 MB，單股行情延遲展開；無外部 CDN。

舊頁 hash 保持不變，另存舊頁路徑；舊交付 receipt 不改寫為新結果。新交付索引：[poc_signal_explorer_2026.json](../artifacts/forward_simulation/poc_signal_explorer_2026.json)。
