# 餘股名額版：候補有效兩個市場日

績效計算前固定唯一變因：候選只在原預定成交日有效，對照候選可有效兩個市場日。沿用已封存454訊號、2022-01-03～2026-09-09、100萬元複利、整張成交、5個主動名額、退出後不足一張的餘股次日釋放名額、餘股超過前日NAV的5%禁止新買、閒錢現金、12%收盤停損及63日到期。資金與出場參數不改。

八組成本／進場延遲／出場延遲因素全部比較：原規則八帳戶須逐欄重現封存結果；兩日候補八帳戶重新執行完整成交及帳務。0050用已驗證同期間正常／加倍滑價帳戶。進場延遲因子先把首個可嘗試日推遲一個市場日，再由該日起算最多兩次；未延遲組仍最早訊號次日，不存在當日尾盤交易。

候補排序保留原引擎規則：每次開盤前可得的前20個市場日成交金額均值，由大至小，再按代碼、event_id。這是固定排序規則，數值隨前一日資料更新；本次不另外測訊號日凍結分數。原signal_date及event_id不改；實際entry_date、首個預定日與attempt_number各自記錄。任何首次正股數成交（含部分成交）即終止該事件，不加碼；沒有成交的候選只有次一市場日的一次機會。遇訊號之後、重試日當日或之前已發生的公司行動，取消重試；不得使用尚未發生的公司行動取消歷史候選。現有身分、流動性、漲跌停及成交容量限制仍適用。

候補不能使用當日賣出或股利新增的資金，當日賣出名額及未成交預算仍鎖到收盤。即使部分候選未成交也不把未知撤單當已完成。這是按日重新計畫的研究假設，不是券商委託／撤單已核實證據。到期未成交不能無限排隊；樣本結尾不足兩日另標截尾。
