# 盤中 15% 停損完整帳戶實驗（固定規格）

- 期間 2025-01-02～2026-09-09，本金 100 萬、複利、3 檔個股、閒錢現金；沿用既有訊號、排序、盤前名額和現金鎖定，不重訓或挑新參數。
- control：`MidpointExitReplay`，買賣各自交易市場日高低中間价，原 loss12 / time63。
- candidate：只增加高點回落 15% 盤中出場；保留 loss12 / time63。已有前日出場指令優先執行原規則，不取消已觸發出場。
- 因原 HL2 買進沒有時點，明確限定 **買進隔日起啟用**。初始高點為買進成交價與入場日收盤較高者，不用未知先後的入場日最高價。之後高點來自完整持有日的價格，遇官方除權息依已核對事件 ratio 換算。
- 當日 OHLC 只用來證明「任何高低先後均不會碰線」，或發現需要讀逐筆；可能碰線時用同時間戳分組的整股 tape 依序判斷。09:00～13:25 前有效；盤中反彈不取消。
- 整股成交只用觸發後時間群組與 1% 成交參與率、前20日均量上限，沿用 0.45% 滑價、費稅；跳空可賣低於停損線，跌停價印單不推定成交。
- **零股在觸發隔日才以自己的 HL2 / 成交量估計賣出**，不是同日盤中成交假設。新成交不釋放當日買進預算／名額。剩餘持股保持待賣。
- 此候選是「整股盤中＋零股隔日」且不含入場當日停損的明確變體，不冒充全交易市場皆即時出場。全市場即時版本仍需零股逐筆與入場時點。
- 補資料限本研究 150 次 FinMind 查詢、60 次官方零股日表查詢，跨重跑共享持久計數、共用既有每小時限額；先用快取，未知或矛盾資料中止帳戶，不跳過股票。官方來源仍遵守既有安全阻擋及精確端點授權規則。正式結果須離線兩次完全相同、control 精確重現、現金／股數／費稅／NAV 稽核通過。
