# 市場轉弱後如何處理持倉：固定研究規格

2026-09-10，本輪新比較報酬計算前固定。承接前輪120日均線進場試算，不再尋找均線長度或廣度門檻。歷史已使用過，全部為探索，不是未見驗證。

## 共用條件

- 共同比較2022-01-03～2026-06-23，領先事件截止2025-12-31，沿用凍結的兩價格版本、各自領先訊號、原始可成交旗標、上市遮罩與價格品質稽核，不下載新資料。
- 趨勢狀態只看0050訊號日收盤是否嚴格高於最近120個有效收盤的均值。當天無報價或觀察不足時為UNKNOWN，不填成多頭。保留完整逐日狀態及當日所依據的資料日期。
- 正常情境使用前一市場交易日的狀態指令；新增事件也在訊號後一交易日進場。延後情境將狀態指令及事件進場都再延遲一交易日，原63日持有計時維持從實際進場起算。
- 轉弱每天檢查，轉強每天檢查；不另加事後挑選的確認日數、冷卻期、停損或波動門檻。這輪先量測這種簡單切換的交易成本與反覆進出影響。
- 最多3個同時事件，每個新事件使用至多當日NAV/3的0050市值換股；閒置ETF賣出淨款支付個股買入成本。沿用63日到期、重疊與額滿拒絕及原領先日優先序。價格均為合成還原單位，沒有最小手續費或零股深度模型。
- 所有買賣扣每邊0.1425%手續費、股票賣稅0.3%、0050賣稅0.1%；滑價每邊基本0.30%、壓力0.45%。現金利息假設0，不視為無風險利率報酬。

## 六個固定方法與0050

1. `always`：原所有領先事件，閒置0050；重現已存在的對照。
2. `entry_only`：只在領先訊號日趨勢ON接受新事件；弱勢不清既有股票，閒置0050；重現前輪約706%壓力試算的規則。
3. `idle_cash`：新事件仍須訊號日ON；依已延遲的狀態指令，OFF時把閒置0050轉現金，既有事件仍63日到期。ON時現金先投入0050，再依事件換股。UNKNOWN不接受新事件，閒置資金維持最近已知ON/OFF配置，初始未知則持現金。
4. `exit_cash`：主要新假說。除了方法3，OFF指令也要求所有既有事件退出到現金。整籃任一股票無法成交，該事件的退出持續等待；已發出的股票出場指令不因後續ON取消，成交後不能憑舊訊號回補，需新的領先事件。
5. `mix_always`：初始50%資金執行方法1、50%持有0050，兩份資金各自完整模擬、以原始資金比例相加NAV和成本，不跨份再平衡；不能把每日收益直接平均成每天再平衡。
6. `mix_entry`：同上，初始50%方法2、50%0050；作為少操作的固定混合對照，不能事後按動態策略曝險配權重。

另列同起訖、同成本0050持有。混合配置的份額會隨收益自然漂移，不宣稱全期每日維持50/50。它們不算相互獨立的策略樣本。

## 出場與UNKNOWN

- 持股到期、已發出轉弱退出或期末，先處理退出，再處理ETF／現金配置，最後接受新事件。終日不再開新倉。
- 到期時若當下閒置配置為現金，整籃退出不需要0050可成交；若應換回0050，則需股票和0050都可成交。轉弱強制退出直接留現金，股票退出不受0050暫停交易拖延。
- OFF時ETF不能賣出需記錄拒絕／受阻，下一日依最新已知指令重試；ON恢復時ETF目標也跟隨最新指令，無法成交不得捏造清算。股票已發出的強制退出則繼續等待，不取消。
- UNKNOWN不觸發新的強制退出，但已存在的退出指令和原到期日仍有效。不能用期末狀態決定之前任何一天的配置。
- 期末所有可賣資產清算；不能退出者保留估值及未平倉標記。未來可疑價格保留原收益並列待對帳，不能事後刪除不利事件。

## 固定比較、檢查與判讀

- 六方法×兩價格版本×兩成本＝24組；官方價格＋壓力成本，六方法全套延後一天＝6組；合計30組，另4組0050。
- 主要比較exit_cash對entry_only、mix_entry及0050。報累積淨報酬、年化、最大回撤、各年收益、每次成交與退出原因、現金占比、換手、成本及估值異常。沒有因報酬漂亮就自動啟用策略。
- 以獨立合成案例验证狀態時序、弱勢未成交重試、UNKNOWN、到期和強制退出、期末未平倉及每日時價損益−費用的資金守恆。原always與entry_only對照必須重現前輪；混合曲線以完整獨立帳戶驗證。
- 相同歷史的不同價格／成本／延遲只屬敏感度比較，不能當多次獨立驗證。另報留一完整年度後的複利結果，只作集中度診斷，不能當可交易回測或新樣本外測試。
